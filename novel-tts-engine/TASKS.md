## 使用说明

### 筛选任务

- **按优先级**：查找对应优先级区块（P0/P1/P2）
- **按状态**：查看"进度追踪"表格中的状态分类
- **按负责人**：搜索负责人名称
- **按时间**：查看起止时间字段

### 排序任务

1. 按优先级：P0 → P1 → P2
2. 按状态：进行中 → 未开始 → 已完成 → 暂停
3. 按时间：起始时间升序

### 更新任务状态

修改"当前状态"字段，并在"变更记录"中添加记录。

## 附录

### A. 任务编号规则

- **T-XXX**：任务编号，从T-001开始递增
- **BR-XXX**：需求编号（待创建 requirements.md 后补充）
- **M-XXX**：里程碑编号

### B. 优先级定义

| 优先级 | 定义 | 响应时间 |
|:------:|------|---------|
| 🔴 高（P0） | 核心瓶颈，影响系统主要功能 | 24小时内响应 |
| 🟡 中（P1） | 工程化改进，提升可维护性 | 3天内响应 |
| 🟢 低（P2） | 架构优化，长期演进 | 1周内响应 |

### C. 状态定义

| 状态 | 定义 |
|------|------|
| 未开始 | 任务已创建，尚未开始实施 |
| 进行中 | 任务正在实施中 |
| 已完成 | 任务已实施并通过验收 |
| 暂停 | 任务因依赖或其他原因暂停 |

### D. 验收标准等级

| 等级 | 定义 |
|------|------|
| P0-严重 | 核心功能缺失或错误，必须修复 |
| P1-高 | 重要功能不完善，建议修复 |
| P2-中 | 优化项，可选修复 |
