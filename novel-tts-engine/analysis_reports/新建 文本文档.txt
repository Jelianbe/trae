## 前置研究：语言学与工程理论支撑

### 1. 中文称谓体系：为什么“核心词+修饰语”是理论正确的？

《汉语称谓研究》将汉语称谓分为亲属、姓名、排行、职衔、敬谦、通用及称谓使用等七大类别。百度百科进一步明确，社交称谓反映职位、职业等社会身份，如“教授”“医生”。这意味着：**中文角色称谓的底层结构是“社会身份核心词”，而非任意字符串的堆砌。** “黑甲骑士”“紫袍法师”“银甲将军”不是碰巧出现的形容词+名词组合，而是语言学定义的**社交称谓—职衔类**的标准构成方式。

你的“核心词集合+修饰语正则”方案，本质上是利用这一有限结构规律，而非穷举所有可能的字面组合。

### 2. 工程先例：BookNLP、HarvestText和说话人抽取模型

BookNLP是面向长篇小说的NLP管道，它的角色识别路径正是NER→共指消解→角色属性分类。清华大学的博士论文《小说人物网络的构建与分析——以〈白鹿原〉为例》训练了专门面向汉语小说的**说话人抽取模型SECN**，并明确指出小说角色识别需要结合NER、指代消解和说话人抽取三个任务联合处理。

HarvestText是一个专注弱监督的中文文本处理库，提供实体链接和命名实体识别功能，适用于小说分析场景。这些先例表明，你的工程方向与学术界的主流做法高度一致。

### 3. 无分类角色标注（TF-CRL）：只用LLM行不行？

EMNLP 2025的 TF-CRL 方法使用LLM为已识别角色生成开放式角色标签。这在学术上是先进的，但对你的项目当前阶段**不适用**：它需要首先完成角色检测，且LLM每次调用成本较高.在你已经确认上下文干预在真实场景下因缺少信号源而效果不佳的情况下，增加LLM调用并不能绕过“角色识别准确率低”这个根本瓶颈。

### 4. 会话级内存缓存：工业界公认的做法

AI Agent领域的短期记忆管理普遍采用“对话窗口+内存缓存+会话结束释放”的模式。Google ADK的`InMemorySessionService`是临时会话缓存，会话结束释放。RockBot在云原生AI Agents中使用滑动窗口的短期内存模型。这与我们确定的“纯内存缓存、Session级生命周期”方案完全一致。

### 3.1 修改1：重构 `_extract_descriptive_roles` 为“核心词+修饰符”模式

```python
# speaker_matcher.py — 替换原有的 _extract_descriptive_roles 方法

def _extract_descriptive_roles(self, text: str) -> List[str]:
    """
    提取描述性角色称呼。

    设计原理：中文社交称谓的结构是“修饰语+职业/身份核心词”。
    核心词（如“骑士”“将军”“法师”）是封闭的有限集合，修饰语（颜色、年龄、性别等）
    通过正则模式匹配。两者组合可覆盖所有未收录的变体（如“紫袍法师”“银甲将军”），
    无需穷举所有可能组合。

    参考文献：
    - 《汉语称谓研究》将称谓分为亲属、姓名、职衔等七大类
    - 百度百科定义社交称谓反映职位、职业等社会身份
    - BookNLP的NER→coreference→属性分类管道
    """
    
    # === 职业/身份核心词集合 ===
    # 基于百度百科称谓分类体系：社交称谓—职衔类、职业类、身份类
    # 来源：百度百科“称谓”词条、《汉语社会交际称谓语研究》
    ROLE_CORE_WORDS = [
        # 职衔类（军队/政治）
        '将军', '丞相', '元帅', '统领', '校尉', '大臣', '尚书', '宰相', '太傅',
        '总管', '掌门', '舵主', '堂主', '族长', '团长', '队长',
        # 职业类（军事/战斗）
        '骑士', '剑客', '法师', '护卫', '士兵', '斥候', '杀手', '刺客',
        '盗贼', '佣兵', '猎人', '冒险者', '剑修', '修士',
        # 职业类（生活/服务）
        '管家', '丫鬟', '侍女', '侍卫', '铁匠', '商人', '牧師', '主教',
        # 身份类（年龄/性别）
        '青年', '少年', '少女', '老者', '男子', '女子',
        # 身份类（宗教/学术）
        '道士', '和尚', '僧人', '长老', '弟子', '前辈',
    ]
    
    # 按长度降序排列，确保长词优先匹配
    ROLE_CORE_WORDS.sort(key=len, reverse=True)
    
    # === 修饰语正则模式 ===
    MODIFIER_PATTERN = (
        r'(?:'  # 非捕获组：修饰语部分
        r'[黑白红蓝紫金银铁铜青灰赤绛翠黛玄]|'         # 颜色/材质（《说文解字》色彩词表）
        r'[老小长少中青幼]|'                           # 年龄前缀（《称谓》年龄代称体系）
        r'年[老迈轻少幼]|'                             # 复合年龄前缀
        r'[男女]|'                                     # 性别前缀
        r'[圣魔暗光血龙鹰狼凤虎蛇鬼]|'                   # 奇幻气氛修饰
        r'[未知神秘恐怖危险]|'                           # 气氛修饰
        r'[白灰黑]衣|'                                  # 衣着描述
        r'中[年]'                                       # 中年
        r')?'  # 修饰语是可选的
    )
    
    results = []
    found_positions = set()
    
    for core_word in ROLE_CORE_WORDS:
        # 组合修饰语+核心词
        full_pattern = MODIFIER_PATTERN + re.escape(core_word)
        
        for match in re.finditer(full_pattern, text):
            start, end = match.start(), match.end()
            # 防止重叠匹配
            if any(start <= p < end or p <= start < end for p in found_positions):
                continue
            results.append(match.group())
            found_positions.add(start)
    
    return results
```

```python
def _register_temporary_character(self, name: str, context: str) -> Optional[Character]:
    """
    动态注册临时角色（带内存缓存）。

    增强的安全检查：
    1. 仅在上下文中找到相关动作描述或显式说话人提示时才创建
    2. 未通过安全检查的调用直接返回 None，不创建临时角色
    """
    # 安全检查：上下文必须有充分证据才创建临时角色
    SPEECH_ACTION_PATTERNS = [
        r'(?:说道|道|问|说|喊道|叫道|笑道|沉声道|低声道)',
        r'(?:点头|摇头|皱眉|转身|站起|坐下|抬手|挥手)',
        r'(?:出现|走来|过来|进来|离开)',
    ]
    has_speech_context = any(
        re.search(pat, context) for pat in SPEECH_ACTION_PATTERNS
    )
    if not has_speech_context:
        return None  # 无充分证据，不创建临时角色
    
    # 先查内存缓存
    if name in self._temp_char_cache:
        return self._temp_char_cache[name]
    
    try:
        gender = self._infer_gender_from_context(name, context)
        char = self.char_manager.add_character(
            name=name,
            aliases=set(),
            gender=gender
        )
        if char:
            self._temp_char_cache[name] = char
            logger.debug(f"注册临时角色: {name} (性别: {gender})")
        return char
    except Exception as e:
        logger.warning(f"注册临时角色失败: {name}, {e}")
        return None
```
