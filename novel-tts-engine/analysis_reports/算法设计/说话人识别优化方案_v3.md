### 1.2 真正的遗漏点

**P0 核心问题**：`_extract_context_speakers` 方法在对 `context_before` 和 `context_after` 做 NER 上下文推理时，**没有调用 `_extract_narration` 剥离其中可能夹带的引号对话内容**。

当前代码流程：
```
analyze_dialogue()
  → 构造 prefix/suffix（可能包含前/后对话的引号内容）
  → 调用 match_speaker(context_before=prefix, context_after=suffix)
    → 调用 _extract_context_speakers(context_before, context_after)
      → 直接对 context_before/context_after 做 NER 分析 ❌ 未剥离引号！
```

**P1 核心问题**：代词消解的"就近原则"仅按字符串距离计算权重，忽略了**动词支配关系**。

典型案例：
```
"药老从戒指中飘出。他看了一眼萧炎，缓缓道：「这枚丹药，你先服下。」"
```
- 旁白（剥离引号后）："药老从戒指中飘出。他看了一眼萧炎，缓缓道："
- NER 提取到："药老"（主语）、"萧炎"（宾语）
- 代词"他"应回指"药老"（前一句主语），但当前错误消解为"萧炎"（更近的实体）

### 1.3 根因链

```
错误识别
├── P0 可修复（对话混入旁白）
│   ├── NER 提取到对话中的人名（P4、P12、P14、P20、P21、P34）
│   └── 上下文推理跳转到错误的角色
└── P1 可修复（代词消解错误）
    └── 代词"他/她"消解到宾语而非主语（P7）
```

## 4. P1：代词消解就近原则修复

### 4.1 问题描述

P0 修复后，以下案例仍会出错：

```
"药老从戒指中飘出。他看了一眼萧炎，缓缓道：「这枚丹药，你先服下。」"
```

P0 剥离引号后，旁白为："药老从戒指中飘出。他看了一眼萧炎，缓缓道："，NER 仍会提取到"药老"和"萧炎"两个实体。**代词"他"当前被错误消解为更近的"萧炎"，而非正确的"药老"。**

### 4.2 根因分析

当前代词消解的"就近原则"仅按字符串距离计算权重，忽略了**动词支配关系**：
- "缓缓道"的施事者是"他"
- "他"回指前一句主语"药老"
- "萧炎"是"看了一眼"的宾语，不应作为"他"的指代对象

### 4.3 修改文件

`pipeline/pronoun_resolver.py`

### 4.4 修改内容

在 `resolve_in_local_window` 方法中，增加主语位置加权逻辑：

```python
def resolve_in_local_window(self, gender: str, recent_speakers: List[str],
                            character_activity: Optional[Dict[str, int]] = None,
                            recent_mentions: Optional[List[str]] = None,
                            context_before: Optional[str] = None) -> Optional:
    # ... 现有逻辑 ...
    
    for idx, speaker_name in enumerate(reversed(window_speakers)):
        char = self.char_manager.get_character_by_name(speaker_name)
        if char and char.gender == gender:
            position_score = 1.0 - (idx / len(window_speakers)) if window_speakers else 0.5
            activity_score = 0.0
            if character_activity:
                activity_count = character_activity.get(char.id, 0)
                activity_score = min(activity_count * 0.05, 0.2)
            
            # === 新增：主语位置加权 ===
            if context_before:
                if self._is_subject_position(speaker_name, context_before):
                    position_score += 0.15
                elif self._is_object_position(speaker_name, context_before):
                    position_score -= 0.10
            # === 新增结束 ===
            
            combined_score = position_score + activity_score
            candidates.append((char, combined_score))
```

**新增辅助方法**：

```python
def _is_subject_position(self, name: str, context: str) -> bool:
    """判断实体是否位于主语位置。
    
    启发式规则：
    1. 显式提示动词前最近的名词（正则匹配 {实体}.*[说道问喊叫]）
    2. 句首实体（句号或开头后的第一个名词性实体）
    """
    import re
    
    # 规则1：提示动词前的实体
    speech_verbs = '道说问喊叫呼唤'
    pattern = rf'{re.escape(name)}[^{speech_verbs}]*[{speech_verbs}]'
    if re.search(pattern, context):
        return True
    
    # 规则2：句首实体（句号后的第一个实体）
    sentences = re.split(r'[。！？\n]', context)
    for sent in sentences:
        sent = sent.strip()
        if sent.startswith(name):
            return True
    
    return False

def _is_object_position(self, name: str, context: str) -> bool:
    """判断实体是否位于宾语位置。
    
    启发式规则：实体紧邻"对/向/给/把"等介词后
    """
    import re
    
    prepositions = '对向给把'
    pattern = rf'[{re.escape(prepositions)}]{re.escape(name)}'
    return bool(re.search(pattern, context))
```
