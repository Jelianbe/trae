# 报告文件命名规范

## 命名规则

所有报告文件必须遵循以下命名格式：

```
中文报告类型_YYYYMMDD_HHMMSS.扩展名
```

## 格式说明

- **中文报告类型**: 使用中文描述报告类型（如：数据库连接优化报告）
- **下划线**: 使用 `_` 分隔各部分
- **YYYYMMDD**: 生成日期（年4位+月2位+日2位）
- **HHMMSS**: 生成时间（时2位+分2位+秒2位，24小时制）
- **扩展名**: .md, .json, .txt 等

## 示例

✅ 正确示例:
```
数据库连接优化报告_20260501_113002.md
数据库线程安全报告_20260501_113015.md
重构实施指南_20260501_113026.md
重构完成总结_20260501_113026.md
重构输出数据_20260501_113026.json
算法评估分析报告_20260430_165248.txt
详细数据_20260430_165248.json
```

❌ 错误示例:
```
DATABASE_FIX_SUMMARY.md          # 使用英文
test_report.md                   # 缺少时间戳
报告_20260501.md                 # 缺少具体时间
数据库报告_2026_05_01_11_30.md   # 时间格式错误
```

## PowerShell 重命名命令

```powershell
# 批量重命名示例
$timestamp = Get-Date -Format 'yyyyMMdd_HHmmss'
Rename-Item -Path "OLD_NAME.md" -NewName "中文报告类型_$timestamp.md"
```

## 自动生成时间戳

在脚本中生成符合规范的文件名：

```python
from datetime import datetime

def generate_report_filename(report_type: str, extension: str = "md") -> str:
    """生成符合命名规范的报告文件名"""
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    return f"{report_type}_{timestamp}.{extension}"

# 使用示例
filename = generate_report_filename("数据库连接优化报告")
# 输出: 数据库连接优化报告_20260501_113002.md
```

## 实施日期

本规范自 2026年5月1日 起实施，所有新生成的报告文件必须严格遵守此规范。
