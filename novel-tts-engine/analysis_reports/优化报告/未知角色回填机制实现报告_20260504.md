# 未知角色回填机制实现报告

**版本**: v1.0
**日期**: 2026-05-04
**模块**: pipeline/speaker_matcher.py, pipeline/pipeline_runner.py

---

## 一、设计背景

### 问题
- 短文本上下文推理：只看当前对话前后各两句，角色名不在上下文窗口内就标记为"未知"
- 长文本频率分析：能学到"谁是重要角色"，但不回答"这句话是谁说的"
- 两者孤立，无法互相补充

### 解决思路
模拟人类阅读过程——读到第三章时已经知道"黑甲骑士"是个重要角色，回头再读到第一章时自然会把他和之前的"未知_角色"关联起来。

---

## 二、实现方案

### 2.1 工作流程

```
短文本推理 → 输出候选说话人（含"未知_角色"）
     ↓
累积3000字 → 触发冷启动
     ↓
频率分析聚类 → CharacterManager注册全文高频角色
     ↓
回填机制 → 用全文角色库重新匹配"未知_角色"
     ↓
更新speaker字段 → 完成二次消歧
```

### 2.2 核心实现

#### speaker_matcher.py

```python
def backfill_unknown_speakers(self, sentences: list) -> int:
    """冷启动后用全文角色库回填未知说话人。"""
    if not sentences:
        return 0
    
    confirmed_chars = list(self.char_manager._confirmed_characters.values())
    if not confirmed_chars:
        return 0
    
    # 构建角色名→Character映射（包含别名）
    char_map = {}
    for char in confirmed_chars:
        char_map[char.name] = char
        for alias in char.aliases:
            char_map[alias] = char
    
    backfill_count = 0
    for sentence in sentences:
        if not sentence.speaker.startswith("未知"):
            continue
        
        text = sentence.text
        # 按角色名长度降序匹配（最长优先）
        sorted_chars = sorted(char_map.items(), key=lambda x: len(x[0]), reverse=True)
        for char_name, char in sorted_chars:
            if char_name in text:
                sentence.speaker = char_name
                sentence.speaker_id = char.id
                backfill_count += 1
                break
    
    return backfill_count
```

#### pipeline_runner.py

```python
def _trigger_cold_start(self):
    # ... 现有聚类逻辑 ...
    
    # 冷启动聚类完成后，回填未知说话人
    backfill_count = 0
    for result in self._result_cache.get("default", []):
        count = self.speaker_matcher.backfill_unknown_speakers(result.sentences)
        backfill_count += count
    
    logger.info(f"冷启动完成：回填 {backfill_count} 个未知说话人")
```

### 2.3 设计细节

| 特性 | 说明 |
|------|------|
| **最长匹配优先** | 按角色名长度降序，避免"萧炎"匹配到"萧" |
| **别名覆盖** | char_map 包含所有别名，支持"苏兄"→"苏夜" |
| **仅回填"未知"** | 只处理 speaker 以"未知"开头的句子 |
| **零侵入** | 不修改原有匹配逻辑，仅在冷启动后追加 |

## 四、预期效果

回填机制在**长篇小说**（数万字以上）中价值最大。

### 适用场景
- 前文未明确提到角色名，但后文通过频率分析识别为重要角色
- 冷启动后，该角色被注册到 CharacterManager
- 回填机制用全文角色库重新匹配前文的"未知_角色"

### 不适用场景
- 角色名从未在文本中出现（回填无法凭空创建角色）
- 群体说话人（"三人"、"众人"）

## 五、后续优化方向

1. **语义相似度匹配**：当前仅用字符串包含匹配，可引入 BGE 向量计算语义相似度
2. **跨段落回填**：支持跨段落的说话人关联
3. **置信度评估**：回填结果应有置信度评分，低置信度的保留"未知"
