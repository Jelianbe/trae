# LLM 情绪基准测试报告

**版本**: v1.0
**日期**: 2026-05-04
**测试模型**: Qwen2.5-1.5B-Instruct
**测试内容**: 使用 LLM 进行单句情绪分类，与规则系统对比

---

## 一、测试背景

情绪标注准确率仅 32%，尝试使用 LLM 进行基准测试，验证：
1. LLM 在单句情绪分类上的表现
2. 角色缺失是否是情绪信号压制的主因
3. 是否有必要引入更大的 LLM（7B/14B）

---

## 二、测试设置

| 项目 | 值 |
|------|-----|
| **模型** | Qwen2.5-1.5B-Instruct |
| **运行环境** | CPU |
| **测试集** | 100 条短文本双层标注（历史17 + 修仙23 + 西幻20 + 都市40） |
| **提示词** | 提供说话人信息作为角色上下文 |
| **输出** | L1(3类) + L2(6类) 双重标签 |

---

---

## 四、关键结论

### 1. LLM 表现不如规则系统

Qwen2.5-1.5B 的 L1 准确率仅 26%，低于规则系统的 33%。这说明：

- 单句情绪分类本身就是极难任务
- 1.5B 参数的 LLM 在缺乏足够上下文时无法准确判断情绪
- 角色缺失不是情绪信号压制的主因（LLM 有角色上下文仍然表现差）

### 2. 情绪标注需要更长上下文或更大模型

- 单句（3句上下文）不足以让 LLM 判断情绪
- 1.5B 参数太小，无法理解复杂的情绪表达（讽刺、混合情绪、隐含情绪）
- 可能需要 7B+ 参数 + 多轮对话上下文才能有效提升

### 3. 确认规则系统已足够

- 3类 + 规则系统 L1 33%
- LLM L1 26%（更低）
- 结论：在单句情绪分类任务上，规则系统已经达到 LLM(1.5B) 无法超越的水平
- 继续投入规则系统的边际收益递减

---

## 五、后续建议

- **短期**：保持规则系统作为基线
- **中期**：考虑 BGE-small + MLP 分类器（见《综合改进方案》）
- **长期**：测试更大 LLM（7B/14B）在多句上下文下的表现
- **不建议**：在 1.5B LLM 上继续投入
