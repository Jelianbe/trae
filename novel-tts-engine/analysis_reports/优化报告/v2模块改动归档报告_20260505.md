## 二、各模块详细改动

### 2.1 情绪提取器 v2/v3/v4

**文件**: `emotion_extractor_v2.py`

#### 核心改进
| 版本 | 准确率 (198条) | 主要改进 |
|------|---------------|----------|
| v1 | 39.9% | 基础关键词匹配 |
| v2 | 40.9% | 否定词处理、重复计分修复、情绪衰减、词典扩展 |
| v3 | 46.0% | 信号守卫系统 |
| v4 | 54.5% | 脏话误匹配修复、跨语言正面表达 |

#### v2 改进（通则级别）
- **否定词处理系统**: 中文否定词（不/没/别/莫/勿）普遍反转情绪极性
- **重复计分修复**: `居然/竟然` 重复加分修复，`怒吼` 去重
- **情绪衰减机制**: 连续3句以上同情绪逐句衰减
- **词典扩展**: 脏话词表 40→50，情绪副词 20→35，情绪动词 20→30
- **"唉"开头权重提升**: 0.3 → 0.45

#### v3 改进（信号守卫系统）
- 每个新信号必须满足守卫条件才触发
- 新增信号：群体反应、离别、无力/无奈、孤独/冷清、震惊/意外等
- 守卫条件示例：离别信号需要同时有情绪信号（泪/颤抖/不舍）

#### v4 改进（Bug修复+信号扩展）
- **脏话误匹配修复**: 单字"草"、"日"、"靠"、"滚"改用词边界正则
- **Joy信号扩展**: 群体正面反应、跨语言正面表达
- **Sadness信号扩展**: 哭泣类新增"哽咽"、"鼻子一酸"、"眼眶红"
- **Anger信号扩展**: 冷嘲热讽、对抗/争论、威胁/对决

#### 三层标注体系
```
L1 粗分类 (3类): neutral, excited, subdued
L2 细分类 (6类): joy, anger, sadness, surprise, fear, neutral
L3 8维向量: [happiness, anger, sadness, fear, disgust, melancholy, surprise, calm]
```

### 2.2 说话人匹配 v2

**文件**: `speaker_matcher_v2.py`

#### 核心改进
1. **动作归因增强**: 30+ 种网文常见动作模式
2. **对话内容推断**: 对话中提到某角色名字时，说话人大概率不是该角色
3. **网文说话动作扩展**: 声音描述类、语气描述类、情绪携带类
4. **对话交替模式**: ABAB 模式检测（最后手段）

#### 新增特性
- `GROUP_SPEAKERS`: 三人/众人/大家等群体说话人映射
- `ACTION_ATTRIBUTION_PATTERNS`: 动作执行者 = 说话人
- `_infer_speaker_from_content()`: 基于对话内容推断说话人

### 2.3 对话分类器 v2

**文件**: `dialogue_classifier_v2.py`

#### 核心改进
1. **内心独白检测**: `THOUGHT_INDICATORS` 词表（25+ 种心理活动动词）
2. **书面内容检测**: `WRITTEN_INDICATORS` 词表（40+ 种）
3. **冒号对话检测**: 无引号对话检测（`XX：对话内容`）
4. **细分类型**: thought、written 等新 sentence_type

#### 覆盖的书面内容类型
- 信件类：书信、遗书、密信、战书、请柬
- 法令类：圣旨、诏书、敕令、族规、门规
- 功法类：功法、心法、剑谱、秘籍、丹方
- 记录类：日记、手记、笔记、日志
- 地图类：地图、藏宝图
- 契约类：契约、盟约、誓言

### 2.4 引号分类器 v2

**文件**: `quotation_classifier_v2.py`

#### 核心改进
1. **书面内容标识词扩展**: 20 → 60 个
2. **新增引号类型**: MEMORY（回忆/闪回）、TELEPATHY（传音入密）
3. **文言文风格分析**: `CLASSICAL_CHINESE_MARKERS` 词表（25+ 个）
4. **评分算法优化**: 长模式匹配权重更高

## 四、明确不做的改动（违反泛化原则）

| 改动 | 不做原因 |
|------|---------|
| "哼"开头 → anger | "哼"在不同语境下可能是轻蔑、不满、撒娇 |
| "别怕+有我在" → joy | 过于具体的组合模式 |
| "怎么会+省略号" → fear | 省略号在网文中用途极广 |
| 场景氛围关键词检测 | 叙事文本中误判风险大 |

## 五、集成指南

### 5.1 替换方式
```bash
cp emotion_extractor_v2.py pipeline/emotion_extractor.py
cp speaker_matcher_v2.py pipeline/speaker_matcher.py
cp dialogue_classifier_v2.py pipeline/dialogue_classifier.py
cp quotation_classifier_v2.py pipeline/quotation_classifier.py
```

### 5.2 注意事项
- `speaker_matcher_v2.py` 依赖 `pipeline.character_manager`、`pipeline.nlp_basics`、`pipeline.semantic_ranker`
- `dialogue_classifier_v2.py` 的 `fasttext` 依赖为可选，缺失时自动回退到规则分类
- `emotion_extractor_v2.py` 完全独立，无外部依赖
- `quotation_classifier_v2.py` 完全独立，无外部依赖

### 5.3 回归风险
- emotion_extractor: 已验证零回归（198条跨文体测试集）
- 其他模块: 建议替换后在本地跑回归测试
