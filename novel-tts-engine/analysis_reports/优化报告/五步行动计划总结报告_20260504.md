## 二、行动2：情绪标注3类简化 ✅ 已完成

**目标**: 6→3类映射（joy/anger/surprise→excited, sadness/fear→subdued, neutral→neutral），重跑100条

### 结果：L1(3类)准确率 33.0%（仅比L2的32.0%高1%）

| 指标 | L2(6类) | L1(3类) | 提升 |
|------|---------|---------|------|
| 准确率 | 32.0% | **33.0%** | +1% |
| 综合准确率 | 21.0% | 21.0% | - |

### 预期 vs 实际

| | 预期 | 实际 | 差距 |
|--|------|------|------|
| 预期提升 | 55-65% | **33.0%** | -22% |

### 根因分析

**3类化未能提升准确率的原因**：
- 规则系统对绝大多数case（70+条）预测为`neutral`
- `neutral→neutral`的L1映射无法修正任何错误
- L1映射只有在L2预测在同一L1桶内时才有效（如joy↔anger都→excited）
- 但系统根本没预测到那些情绪，大部分case都落入`neutral`

**结论**: 3类化本身不能解决"全预测neutral"问题。规则系统的瓶颈在于**情绪信号覆盖不足**，而非分类粒度。

## 三、行动3：情绪ML基准线重测 ✅ 已完成

**目标**: 用Qwen2.5-1.5B-Instruct重测3类情绪benchmark，与规则系统对比

### 结果：LLM L1(3类)准确率 26.0%（低于规则系统的33.0%）

| 系统 | L2(6类) | L1(3类) |
|------|---------|---------|
| 规则系统 | 32.0% | 33.0% |
| LLM (Qwen2.5-1.5B) | **27.0%** | **26.0%** |

### LLM 详细结果

**L1(3类) 按类别F1**:
| 类别 | F1 | GT数量 |
|------|----|--------|
| excited | 0.169 | 51 |
| subdued | 0.211 | 32 |
| neutral | 0.330 | 17 |
| Macro F1 | **0.237** | |

**L2(6类) 按类别F1**:
| 类别 | F1 | GT数量 |
|------|----|--------|
| joy | 0.316 | 12 |
| anger | 0.229 | 28 |
| sadness | 0.207 | 22 |
| surprise | 0.000 | 11 |
| fear | 0.000 | 10 |
| neutral | 0.358 | 17 |
| Macro F1 | **0.185** | |

### 关键发现

1. **LLM在单句对话上的表现不如规则系统**
   - LLM L1准确率26.0% < 规则系统33.0%
   - LLM L2准确率27.0% < 规则系统32.0%
   
2. **LLM的主要问题是"全预测neutral"**
   - 100条中有46条预测为neutral（GT只有17条是neutral）
   - 与规则系统犯了相同的错误模式
   
3. **LLM在显式情绪词上表现良好**
   - 「你给我滚出去！」→ anger ✅
   - 「哈哈哈，这就是你的力量？」→ joy ✅
   - 「燕哥回来了！」→ joy ✅
   
4. **LLM在含蓄情绪上完全失效**
   - 「我没事。」GT=sadness → neutral ❌
   - 「今晚的月亮真圆啊。」GT=sadness → neutral ❌
   - 「你后悔吗？」GT=sadness → neutral ❌

### 结论

**"情绪标注本身就是极难任务"的判断被验证**。即使在有角色上下文锚点的情况下：
- 1.5B参数量的LLM在单句情绪分类上也只能做到26%
- 远低于预期的70%+
- 这说明问题不在于"角色缺失对情绪信号的压制"，而是**单句对话情绪分类本身就是需要更长上下文、更大模型的任务**
