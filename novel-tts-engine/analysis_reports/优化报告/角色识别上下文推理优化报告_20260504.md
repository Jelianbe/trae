# 角色识别上下文推理优化报告

**测试日期**: 2026-05-04  
**优化阶段**: 阶段1 + 阶段1.5  
**优化类型**: 上下文推理 + 临时角色动态注册

---

## 1. 优化背景

### 1.1 初始问题

| 指标 | 初始值 | 目标值 |
|------|--------|--------|
| 角色识别准确率 | 0.0% | ≥70% |
| 情绪标注准确率 | 26.0% | ≥60% |

### 1.2 问题根因

1. **接口不匹配**：测试数据用 `\n` 分隔上下文，Pipeline 不识别换行符
2. **角色未注册**：很多 GT 角色不在 CharacterManager 中
3. **上下文推理缺失**：系统无法从上下文推断说话人

---

## 2. 优化实施

### 2.1 阶段1：上下文主语追踪

**实现内容**：

在 `SpeakerMatcher` 中增加 `_extract_context_speakers` 方法：

```python
def _extract_context_speakers(self, context_before, context_after):
    """
    从上下文窗口中提取候选说话人。
    优先级：
    1. context_before中的"XX说/道/问"显式提示
    2. context_before中的PER实体（最近的优先）
    3. context_after中的PER实体
    """
```

**修改文件**：
- `pipeline/speaker_matcher.py`
- `scripts/evaluate_full_pipeline.py`

### 2.2 阶段1.5：临时角色动态注册

**实现内容**：

1. 增加 `_extract_descriptive_roles` 方法：提取描述性角色称呼
2. 增加 `_infer_gender_from_context` 方法：从上下文推断性别
3. 增加 `_register_temporary_character` 方法：动态注册临时角色

```python
def _extract_descriptive_roles(self, text: str) -> List[str]:
    """
    提取描述性角色称呼。
    如"黑甲骑士"、"圣骑士"、"老剑客"、"佣兵团长"
    """
    role_suffixes = (

        '弟子', '前辈', '长老', '掌门', '丫鬟', '侍女', '剑修'...
    )
```
