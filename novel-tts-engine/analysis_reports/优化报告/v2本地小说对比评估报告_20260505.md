## 四、核心结论

### 4.1 v2 的改进（✅）

1. **叙事文本识别更准确**：v1 对斗破和闺蜜有大量 anger 误判（叙事文本被误判为 anger），v2 正确地将其归为 neutral
2. **sadness 识别能力提升**：v1 在斗破/闺蜜中 sadness = 0，v2 能识别出悲伤场景
3. **fear/surprise 识别更敏感**：都市中 v2 多识别了恐惧和惊讶场景

### 4.2 v2 的问题（⚠️）

1. **脏话词边界 bug 导致 anger 漏判**：
   - "我，我草" → 应判 anger，v2 判 neutral
   - "滚出去" → 应判 anger，v2 判 neutral
   - 原因：`_SINGLE_CHAR_DIRTY_RE` 正则过于严格，要求脏话前后非中文

2. **anger 下降部分合理，部分不合理**：
   - 合理：大量叙事文本从 anger → neutral（这是改进）
   - 不合理：明确脏话 anger 也被归为 neutral（这是 bug）

### 4.3 修复建议

只需修复脏话词边界正则，v2 的表现就会显著优于 v1：

```python
# 当前（有问题）：
_SINGLE_CHAR_DIRTY_RE = re.compile(
    r'(?:^|[^一-龥])(?:滚|草|靠|日)(?:[^一-龥]|$)'
)

# 修复方案：放宽为"前后不全是中文"
# 即：脏字前或后至少有一侧是非中文（标点/空格/符号/边界）
_SINGLE_CHAR_DIRTY_RE = re.compile(
    r'(?:滚|草|靠|日)(?=[^一-龥]|$)|(?<=^|[^一-龥])(?:滚|草|靠|日)'
)

# 或者更简单：使用否定前瞻
_SINGLE_CHAR_DIRTY_RE = re.compile(
    r'(?<![一-龥])(?:滚|草|靠|日)(?![一-龥])'
)
```
