# Index-TTS 集成报告

**版本**: v1.0

**模块**: pipeline/tts_indextts.py, pipeline/tts_generator.py
**Index-TTS 路径**: D:\TTS\IndexTTS2-SonicVale
**服务地址**: http://localhost:7860

---

## 一、集成背景

### 1.1 原 TTS 引擎（Kokoro 82M）

| 指标 | 值 |
|------|-----|
| 模型大小 | 186MB |
| 音色数量 | 103 个中文音色 |
| 推理速度 | ~1.4s/句（CPU） |
| 情绪控制 | 预留接口，模型不支持 |
| 音色克隆 | 不支持 |

### 1.2 Index-TTS 优势

| 特性 | 说明 |
|------|------|
| 音色克隆 | 通过参考音频克隆任意音色 |
| 情绪控制 | 支持 emo_text（情感描述文本）和 emo_vector（8维向量） |
| 音质 | 优于 Kokoro |
| 服务化 | 通过 HTTP API 调用，可分布式部署 |

---

## 二、Index-TTS API 接口

### 2.1 端点

```
POST http://localhost:7860/v2/synthesize
```

### 2.2 请求体

```json
{
  "text": "要合成的文本",
  "audio_path": "参考音频路径或绝对路径",
  "emo_text": "情感描述文本（可选）",
  "emo_vector": [0.1, 0.2, ...]  // 8维情感向量（可选）
}
```

### 2.3 响应

- 成功：WAV 音频 bytes（Content-Type: audio/wav）
- 失败：422 Validation Error 或 500 Internal Server Error

## 三、实现方案

### 3.1 架构

```
TTSGenerator (业务逻辑层)
├── KokoroTTSGenerator (本地引擎)
└── IndexTTSEngine (HTTP API 引擎) ← 新增
```

### 3.2 新增模块

**pipeline/tts_indextts.py**

| 组件 | 说明 |
|------|------|
| `IndexTTSEngine` 类 | Index-TTS HTTP API 适配器 |
| `initialize()` | 检查服务可用性 |
| `generate_audio(text, audio_path, emotion, emo_vector)` | 生成音频返回 bytes |
| `generate_audio_to_file(text, output_file, ...)` | 生成音频并保存 |
| `get_voice_for_speaker(speaker)` | 返回参考音频路径（与 Kokoro 接口兼容） |

### 3.3 情感映射

| 系统情感标签 | Index-TTS emo_text |
|-------------|-------------------|
| joy | 开心地说 |
| anger | 生气地说 |
| sadness | 悲伤地说 |
| surprise | 惊讶地说 |
| fear | 害怕地说 |
| neutral | 平静地说 |

### 3.4 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `base_url` | http://localhost:7860 | Index-TTS 服务地址 |
| `default_audio_path` | D:/TTS/IndexTTS2-SonicVale/examples/voice_01.wav | 默认参考音频 |
| `timeout` | 120s | HTTP 请求超时 |

## 四、使用方式

### 4.1 直接使用 IndexTTSEngine

```python
from pipeline.tts_indextts import IndexTTSEngine

engine = IndexTTSEngine(
    base_url="http://localhost:7860",
    default_audio_path="D:/TTS/IndexTTS2-SonicVale/examples/voice_01.wav"
)
audio_bytes = engine.generate_audio(
    text="你好，世界！",
    emotion="joy"  # 自动映射为 "开心地说"
)
```

### 4.2 通过 TTSGenerator 使用

```python
from pipeline.tts_generator import get_tts_generator

# 使用 Index-TTS
tts = get_tts_generator(
    engine="indextts",
    indextts_url="http://localhost:7860",
    indextts_audio_path="D:/TTS/IndexTTS2-SonicVale/examples/voice_01.wav"
)
```

### 4.3 测试脚本

```bash
python scripts/test_index_tts_integration.py
```
