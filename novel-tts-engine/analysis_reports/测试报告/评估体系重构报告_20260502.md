## 一、新旧评估体系对比表

### 旧版评估体系（5项）

| 指标 | 权重 | 说明 |
|------|------|------|
| 章节划分 | 20% | 评估章节分割的准确性 |
| 对话分类 | 20% | 评估对话与旁白的分类能力 |
| 拟声词检测 | 20% | 评估拟声词的识别能力 |
| 命名实体识别(NER) | 20% | 评估实体识别的准确率 |
| 说话人匹配 | 20% | 评估对话与说话人的匹配能力 |
| **平均得分** | - | 五项简单平均 |

### 新版评估体系（6项）

| 模块 | 权重 | 说明 |
|------|------|------|
| 基础结构完整性 | 10% | 原章节划分+对话分类合并，衡量文本基础解析能力 |
| 拟声词检测 | 15% | 保持独立，权重微调 |
| 说话角色识别 | 30% | 原NER重命名，突出角色识别在TTS中的核心地位 |
| 对话-角色匹配 | 30% | 原说话人匹配，权重提升，衡量对话归属准确性 |
| 端到端正确率 | 10% | 新增：对话被正确识别且匹配到正确说话人的比例 |
| 系统稳定性罚分 | 最多-5分 | 基于三轮测试的标准差，公式: min(5.0, stdev_sum x 2) |

### 新综合分公式

```
综合分 = 基础结构x0.10 + 拟声词x0.15 + 说话角色识别x0.30 + 对话-角色匹配x0.30 + 端到端正确率x0.10 - 稳定性罚分
```

## 三、新指标解释和优势说明

### 3.1 基础结构完整性 (10%)

**定义**: 合并原章节划分和对话分类两个指标，计算两者的平均值。

**公式**: `(章节划分得分 + 对话分类得分) / 2`

**优势**:
- 章节划分和对话分类都属于基础文本解析能力，合并后避免重复加权
- 降低基础指标权重，让核心指标(角色识别、匹配)获得更高权重
- 简化评估维度，从5项到6项但更具层次感

### 3.2 说话角色识别 (30%)

**定义**: 原NER评估的重命名，评估系统识别文本中说话角色的能力。

**优势**:
- 重命名更贴合TTS应用场景，强调"说话角色"而非笼统的"命名实体"
- 权重从20%提升到30%，体现角色识别在TTS中的核心地位
- TTS系统必须准确识别谁在说话，才能正确生成语音

### 3.3 对话-角色匹配 (30%)

**定义**: 原说话人匹配评估，衡量系统将对话正确归属到说话人的能力。

**优势**:
- 权重从20%提升到30%，与说话角色识别并列最重要的指标
- 在TTS场景中，"谁说什么"是最核心的需求
- 高权重倒逼优化说话人匹配算法

### 3.4 端到端正确率 (10%)

**定义**: 新增指标，衡量对话被正确识别为对话且匹配到正确说话人的综合比例。

**公式**: `正确识别且匹配的对话数 / GT总对话数 x 100`

**计算方法**:
1. 遍历GT中标注的所有对话句子
2. 检查每句话是否被系统正确识别为对话
3. 检查说话人是否匹配正确
4. 只有两者都正确才计为"正确"

**优势**:
- 反映系统的整体端到端能力，而非各模块的独立表现
- 揭示模块间串联时的信息损失
- 帮助用户了解真实场景下的最终效果

### 3.5 系统稳定性罚分 (最多-5分)

**定义**: 基于三轮测试的标准差计算罚分。

**公式**: `min(5.0, stdev_sum x 2)`

其中 `stdev_sum` 是所有六项指标标准差的总和。

**优势**:
- 鼓励系统输出稳定可预测的结果
- 如果三轮测试完全一致(标准差=0)，则无罚分
- 罚分上限为5分，避免过度惩罚

## 四、测试结果分析

### 4.1 稳定性

所有三个文本的三轮测试标准差均为0，说明系统具有极高的确定性。这在当前实现中是因为：
- 章节划分使用确定性正则表达式
- 对话分类使用规则匹配
- NER和说话人匹配虽然涉及ML模型，但在相同输入下输出一致

### 4.2 分数差异原因

新版综合分普遍低于旧版平均分，主要原因：

1. **权重重新分配**: 核心指标(说话角色识别30% + 对话-角色匹配30%)权重更高，而这两项通常是较低分项
2. **端到端正确率**: 新增指标通常低于单项指标，因为它要求"对话识别"和"说话人匹配"同时正确
3. **更真实的评估**: 旧版平均简单地将五项等权平均，新版加权平均更能反映TTS系统的真实价值

### 4.3 改进优先级

根据新权重，优化优先级应为：

1. **说话角色识别 (30%)** - 西幻最低(55.6)，需要重点提升
2. **对话-角色匹配 (30%)** - 三项均在65-76%之间，有提升空间
3. **端到端正确率 (10%)** - 与说话人匹配高度相关，改善后者可同时提升两者
4. **拟声词检测 (15%)** - 三项均在80-90%之间，相对稳定
5. **基础结构完整性 (10%)** - 三项均为100%，已无需优化

## 五、后续改进建议

### 短期 (1-2周)

1. **优化西幻文本的NER**: 西幻风格的命名实体识别准确率(55.6%)显著低于其他两种风格，建议：
   - 添加西幻风格的实体白名单
   - 优化翻译体文本的实体识别规则
   - 针对西方人名、地名调整识别策略

2. **提升说话人匹配准确率**: 三项文本的匹配率都在65-76%之间，建议：
   - 增加对话上下文的窗口大小
   - 优化L2语义排序器的阈值
   - 引入更多对话模式规则

### 中期 (1个月)

3. **端到端正确率提升**: 作为新增指标，需要从系统层面优化：
   - 确保对话分类器和说话人匹配器的接口对齐
   - 减少模块间信息传递的损失
   - 建立端到端的错误分析机制

4. **稳定性监控**: 虽然当前稳定性极佳，但建议：
   - 持续监控标准差变化
   - 在模型更新后重新运行稳定性测试
   - 设置稳定性阈值告警

### 长期 (3个月+)

5. **评估体系持续优化**: 
   - 考虑引入更多风格类型的测试文本
   - 评估指标权重的动态调整机制
   - 探索基于用户反馈的评估修正
