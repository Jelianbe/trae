## 二、P0 级别修复

### E.27：线程安全连接池

**问题**: 原数据库管理器使用 `check_same_thread=False`，存在线程安全隐患。

**修复方案**: 使用 `threading.local()` 实现线程隔离的连接：

```python
# 修复前（不安全）
self.conn = sqlite3.connect(db_path, check_same_thread=False)

# 修复后（安全）
self._local = threading.local()

def get_connection(self):
    if not hasattr(self._local, 'conn') or self._local.conn is None:
        self._local.conn = sqlite3.connect(self.db_path, timeout=30)
        self._local.conn.execute("PRAGMA journal_mode=WAL")
        self._local.conn.execute("PRAGMA foreign_keys=ON")
    return self._local.conn
```

**关键改进**:
- 移除 `check_same_thread=False`
- 每个线程拥有独立连接
- 添加 30 秒超时机制避免锁竞争
- 启用 WAL 模式提高并发读写性能

### E.28：事务完整性保障

**问题**: `merge_characters` 等多步操作缺乏事务保护，中间失败会导致数据不一致。

**修复方案**: 实现事务上下文管理器：

```python
@contextmanager
def transaction(self):
    conn = self.get_connection()
    try:
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
```

**使用示例**:
```python
def merge_characters(self, source_id, target_id):
    with self.transaction() as conn:
        conn.execute("UPDATE dialogues SET character_id=? WHERE character_id=?",
                     (target_id, source_id))
        conn.execute("DELETE FROM characters WHERE id=?", (source_id,))
```

**关键约束**:
- 外键约束：确保数据引用完整性
- CHECK 约束：`gender IN ('male', 'female', 'unknown')`
- CHECK 约束：`activity_weight BETWEEN 0 AND 1`

### E.29：SQL 注入安全防护

**问题**: LIKE 查询使用动态 SQL 拼接，存在注入风险。

**修复方案**: 使用参数化查询和 `||` 运算符：

```python
# 修复前（不安全）
cursor.execute(f"SELECT * FROM characters WHERE name LIKE '%{name}%'")

# 修复后（安全）
safe_name = name.replace('%', '\\%').replace('_', '\\_').replace('\\', '\\\\')
cursor.execute("SELECT * FROM characters WHERE name LIKE '%' || ? || '%' ESCAPE '\\'",
               (safe_name,))
```

**关键改进**:
- 所有查询使用参数化（`?` 占位符）
- 特殊字符转义（`%`、`_`、`\`）
- 移除所有动态 SQL 拼接

## 三、P1 级别修复

### E.30：异常处理精细化

**问题**: 使用 `except Exception` 捕获所有异常，无法区分错误类型。

**修复方案**: 细化异常类型：

```python
# 修复前
except Exception as e:
    logger.error(f"Error: {e}")

# 修复后
except sqlite3.IntegrityError as e:
    logger.error(f"数据完整性错误：{e}")
except sqlite3.OperationalError as e:
    logger.error(f"数据库操作错误：{e}")
except sqlite3.DatabaseError as e:
    logger.error(f"数据库错误：{e}")
```

## 五、测试验证

### 5.1 线程安全测试

```python
def test_thread_safety():
    """多线程并发写入测试"""
    import threading
    
    def insert_data(thread_id):
        db = DatabaseManager(":memory:")
        for i in range(100):
            db.insert_character(f"角色_{thread_id}_{i}")
    
    threads = [threading.Thread(target=insert_data, args=(i,)) for i in range(5)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    
    # 验证数据完整性
    assert db.count_characters() == 500
```

### 5.2 事务回滚测试

```python
def test_transaction_rollback():
    """事务回滚测试"""
    db = DatabaseManager(":memory:")
    
    try:
        with db.transaction():
            db.insert_character("角色A")
            db.insert_character("角色B")
            raise ValueError("模拟错误")
    except ValueError:
        pass
    
    # 验证事务回滚
    assert db.count_characters() == 0
```
