# 管道一致性修复报告 v3.11

**报告日期**: 2026-05-03
**版本**: v3.11
**影响范围**: ContextDiversityValidator, SpeakerRoleFilter

---

## 一、修复背景

在开发手册 v3.11 版本中，发现了两个严重的管道一致性问题，可能导致实体置信度被错误修改，影响最终说话人匹配的准确性。

---

## 二、修复 1：L2 补偿上限限制

### 问题描述

SpeakerRoleFilter 的 L2 语义补偿可以无限制提升实体置信度，导致统计验证降级的实体被后续组件覆盖。这违反了管道一致性原则。

**管道一致性原则**:
> 统计验证降级的实体不能被后续组件提升到高于原始值的 1.5 倍

### 修复方案

在 SpeakerRoleFilter 中增加 L2 补偿上限：

```python
# 修复前
if l2_boost > 0:
    entity.confidence = min(1.0, entity.confidence + l2_boost)

# 修复后
max_allowed = entity.original_confidence * 1.5
entity.confidence = min(
    1.0,
    entity.confidence + l2_boost,
    max_allowed  # 不能超过原始置信度的 1.5 倍
)
```

### 影响

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 管道一致性 | ❌ 违反 | ✅ 符合 |
| 置信度可靠性 | 低（可被任意修改
