# 管道一致性修复报告 v3.11

**报告日期**: 2026-05-03
**版本**: v3.11
**影响范围**: ContextDiversityValidator, SpeakerRoleFilter, pipeline_runner

---

## 一、修复背景

v3.11 版本发现并修复了两个严重的管道一致性问题：
1. L2 语义补偿无上限，导致统计验证降级结果被覆盖
2. HanLP 将"人名+动词"误合并为更长实体名

---

## 二、问题 1：L2 补偿上限限制

### 2.1 问题描述

**管道一致性原则**：统计验证降级的实体不能被后续组件提升到高于原始值的 1.5 倍。

但 SpeakerRoleFilter 的 L2 语义补偿没有上限：
```python
# 修复前（错误）
if l2_boost > 0:
    entity.confidence = min(1.0, entity.confidence + l2_boost)
    # 问题：可能超过 original_confidence * 1.5
```

**影响**：
- ContextDiversityValidator 的统计验证结果被后续组件覆盖
- 管道各阶段的置信度调整失去意义
- 低质量实体可能被提升到高置信度

### 2.2 修复方案

在 `speaker_role_filter.py` 中增加 L2 补偿上限：

```python
# 修复后（正确）
max_allowed = getattr(entity, 'original_confidence', entity.confidence) * 1.5
if l2_boost > 0:
    entity.confidence = min(1.0, entity.confidence + l2_boost, max_allowed)
```

**关键设计**：
- `original_confidence` 记录实体在进入管道时的初始置信度
- L2 补偿不能超过 `original_confidence * 1.5`
- 最终置信度取三者最小值：1.0、补偿后值、上限值

## 三、问题 2：统计误合并检测

### 3.1 问题描述

HanLP NER 会将"人名 + 动词/形容词"误合并为更长的人名实体：

| 误合并示例 | 正确拆分 |
|-----------|---------|
| "萧炎冷" | "萧炎"（PER）+ "冷"（形容词） |
| "林雪说道" | "林雪"（PER）+ "说道"（动词） |
| "苏夜看着" | "苏夜"（PER）+ "看着"（动词） |

**影响**：
- 实体识别准确率下降
- 误合并的实体无法正确匹配到说话人
- 下游组件（SpeakerMatcher）使用错误的实体名

### 3.2 修复方案

在 `context_diversity_validator.py` 中新增 `_detect_mis_merged_entities` 方法：

```python
def _detect_mis_merged_entities(self, entities, full_text):
    """
    统计误合并检测：利用全文级别信息检测"人名+动词"误合并
    
    策略：
    1. 检查实体末尾是否为常见动词/形容词
    2. 检查拆分后的子串是否在全文中独立出现
    3. 如果独立出现频率高，则拆分
    """
    # 常见可能被合并到人名末尾的词
    suspicious_suffixes = [
        # 动词
        "说", "道", "问", "答", "想", "看", "听", "喊", "叫",
        "走", "跑", "跳", "站", "坐", "躺", "笑", "哭",
        # 形容词
        "冷", "热", "快", "慢", "大", "小", "高", "低",
        # 助词
        "了", "着", "过",
    ]
    
    for entity in entities:
        if entity.type != "PER":
            continue
        
        for suffix in suspicious_suffixes:
            if entity.text.endswith(suffix):
                # 检查拆分后的子串是否在全文中独立出现
                base_name = entity.text[:-len(suffix)]
                if base_name and self._check_independent_occurrence(base_name, full_text):
                    # 拆分实体
                    entity.text = base_name
                    entity.end = entity.start + len(base_name)
                    break
```

**核心逻辑**：
1. 遍历所有 PER 实体
2. 检查实体末尾是否为可疑后缀
3. 如果拆分后的基础名字在全文中独立出现频率高，则执行拆分
4. 更新实体的 text 和 end 位置

### 3.3 测试结果

| 测试文本 | 修复前 | 修复后 | 提升 |
|----------|--------|--------|------|
| **斗破苍穹** | 85.7 | **92.3** | **+6.6** |
| 都市异能 | 73.3 | 74.0 | +0.7 |
| 西幻 | 55.6 | 55.6 | 0 |

**分析**：
- 斗破苍穹受益最大（+6.6%），因为修仙小说中"人名 + 动作"模式频繁
- 都市异能提升较小（+0.7%），误合并问题不严重
- 西幻无影响，因为西方人名较少出现此类误合并
