## 二、L2在匹配漏斗中的位置

### 当前漏斗（L0+L1）

```
get_speaker_for_sentence(text, prev_speaker, chapter_id)
  │
  ├─ extract_speaker_hint(text)
  │    ├─ 呼唤句式过滤 ✅
  │    └─ 返回 (speaker, hint_type)
  │
  ├─ L0: match_speaker(speaker)
  │    ├─ 精确姓名匹配 ✅
  │    ├─ 别名匹配 ✅
  │    └─ 头衔匹配 ✅
  │
  ├─ L1: match_by_pronoun(ctx)
  │    ├─ 性别匹配 ✅
  │    └─ prev_speaker优先 ✅
  │
  └─ _infer_from_address(ctx)
       ├─ 活动度排序 ✅
       └─ 最近提及排序 ✅
```

### 改进后漏斗（L0+L1+L2）

```
get_speaker_for_sentence(text, prev_speaker, chapter_id)
  │
  ├─ extract_speaker_hint(text)
  │    └─ 返回 (speaker, hint_type) 或 (None, "")
  │
  ├─ L0: match_speaker(speaker)  [精确匹配]
  │    └─ if found → return Character, 100%
  │
  ├─ L1: match_by_pronoun(ctx)  [代词解析]
  │    └─ if found → return Character, 80%
  │
  ├─ 🆕 L2: semantic_rank(candidates, context)  [语义排序]
  │    │
  │    ├─ 获取当前章节活跃角色列表
  │    ├─ 计算每个角色的"特征文本"与当前句子的相似度
  │    ├─ 特征文本 = 角色历史对话的TF-IDF摘要
  │    ├─ 按相似度排序，取top-1
  │    └─ if score >= 0.7 → return Character, score%
  │
  └─ _infer_from_address(ctx)  [地址推断-兜底]
       └─ if found → return Character, 60%
       └─ else → return None, None (标记为未知)
```

## 三、L2语义排序详细设计

### 3.1 候选角色获取

```python
def _get_candidates_for_l2(self, chapter_id: int) -> List[Character]:
    """获取L2候选角色列表"""
    # 策略1：本章已出现的角色
    chars_in_chapter = self.char_manager.get_characters_by_chapter(chapter_id)
    
    # 策略2：活动度>阈值的角色
    active_chars = [
        c for c in chars_in_chapter
        if self.char_manager.get_activity_weight(c.id) > 0.5
    ]
    
    # 策略3：如果太少，加入全局活跃角色
    if len(active_chars) < 3:
        all_chars = self.char_manager.get_all_characters()
        active_chars.extend([
            c for c in all_chars
            if c not in active_chars and 
               self.char_manager.get_activity_weight(c.id) > 0.3
        ])
    
    return active_chars[:10]  # 限制最多10个候选
```

### 3.2 角色特征文本生成

```python
def _build_character_profile(self, char: Character) -> str:
    """构建角色特征文本"""
    # 从数据库获取角色历史对话
    dialogues = self.char_manager.get_character_dialogues(char.id, limit=20)
    
    # 拼接为特征文本
    profile_parts = []
    profile_parts.append(char.name)  # 角色名
    profile_parts.append(char.gender)  # 性别
    if char.aliases:
        profile_parts.append(",".join(char.aliases))  # 别名
    
    # 添加代表性对话
    for d in dialogues[:10]:
        profile_parts.append(d.content[:50])  # 截断到50字
    
    return " ".join(profile_parts)
```

### 3.3 相似度计算

```python
def _compute_semantic_similarity(
    self, 
    sentence: str, 
    candidates: List[Character]
) -> List[Tuple[Character, float]]:
    """计算句子与候选角色的语义相似度"""
    if not self._embedding_model:
        self._load_embedding_model()
    
    # 编码当前句子
    sentence_embedding = self._encode(sentence)
    
    results = []
    for char in candidates:
        profile = self._build_character_profile(char)
        profile_embedding = self._encode(profile)
        
        # 余弦相似度
        similarity = cosine_similarity(sentence_embedding, profile_embedding)
        results.append((char, similarity))
    
    # 按相似度降序
    results.sort(key=lambda x: x[1], reverse=True)
    return results
```

### 3.4 集成到match_speaker漏斗

```python
def match_speaker(self, name: str, context: str = None,
                  prev_speaker: Optional[str] = None, 
                  chapter_id: int = None) -> Optional[MatchResult]:
    """L0精确匹配"""
    result = self._match_exact(name)
    if result:
        return result
    
    """L1代词匹配"""
    if not name:
        result = self._match_by_pronoun(
            DialogueContext(
                text=context or "",
                prev_speaker=prev_speaker,
                chapter_id=chapter_id
            )
        )
        if result:
            return result
    
    """🆕 L2语义排序"""
    if chapter_id is not None:
        candidates = self._get_candidates_for_l2(chapter_id)
        if candidates:
            ranked = self._compute_semantic_similarity(
                context or "", 
                candidates
            )
            if ranked and ranked[0][1] >= 0.7:  # 阈值
                best_char, score = ranked[0]
                self.update_activity(best_char.id, best_char.name)
                return MatchResult(
                    character=best_char,
                    confidence=score
                )
    
    """兜底：地址推断"""
    result = self._infer_from_address(
        DialogueContext(
            text=context or "",
            prev_speaker=prev_speaker,
            chapter_id=chapter_id
        )
    )
    return result
```

## 四、阈值设计

| 阶段 | 阈值 | 说明 |
|------|------|------|
| L0精确匹配 | 100% | 姓名/别名完全匹配 |
| L1代词匹配 | 80% | 性别匹配+prev_speaker优先 |
| L2语义排序 | 70% | 余弦相似度≥0.7才接受 |
| 地址推断 | 60% | 活动度/最近提及兜底 |
| 未知 | <60% | 所有阶段都失败 |

### 阈值调优策略

1. **初始值**：L2阈值设为0.7
2. **验证集测试**：在测试小说上运行，统计误判率
3. **动态调整**：
   - 误判率>10% → 提高阈值到0.75
   - 漏判率>20% → 降低阈值到0.65
4. **最终目标**：L2单独贡献+5分说话人匹配得分

## 五、性能优化

### 5.1 缓存策略

```python
class SemanticCache:
    """语义缓存，避免重复编码"""
    def __init__(self, max_size: int = 1000):
        self._cache: Dict[str, np.ndarray] = {}
        self._max_size = max_size
    
    def get(self, text: str) -> Optional[np.ndarray]:
        return self._cache.get(text)
    
    def put(self, text: str, embedding: np.ndarray):
        if len(self._cache) >= self._max_size:
            self._cache.pop(next(iter(self._cache)))
        self._cache[text] = embedding
```

### 5.2 批量编码

```python
def _encode_batch(self, texts: List[str]) -> np.ndarray:
    """批量编码，提升速度"""
    # 检查缓存
    to_encode = []
    cached_indices = []
    for i, text in enumerate(texts):
        cached = self._cache.get(text)
        if cached is not None:
            cached_indices.append((i, cached))
        else:
            to_encode.append((i, text))
    
    if not to_encode:
        # 全部命中缓存
        return np.array([v for _, v in sorted(cached_indices)])
    
    # 批量编码未命中的
    batch = [t for _, t in to_encode]
    embeddings = self._model.encode(batch, batch_size=32)
    
    # 合并缓存和新编码
    result = [None] * len(texts)
    for i, emb in cached_indices:
        result[i] = emb
    for (i, _), emb in zip(to_encode, embeddings):
        result[i] = emb
        self._cache.put(texts[i], emb)
    
    return np.array(result)
```

### 5.3 延迟加载

```python
def _load_embedding_model(self):
    """延迟加载，只在需要时加载模型"""
    if self._embedding_model is not None:
        return
    
    try:
        from transformers import AutoTokenizer, AutoModel
        import torch
        
        self._tokenizer = AutoTokenizer.from_pretrained("BAAI/bge-small-zh-v1.5")
        self._model = AutoModel.from_pretrained("BAAI/bge-small-zh-v1.5")
        self._model.eval()
        self._device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        self._model.to(self._device)
        
        print("L2语义模型加载成功")
    except Exception as e:
        print(f"L2语义模型加载失败: {e}")
        self._model = None
```
