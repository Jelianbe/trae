## 验证A：跨小说泛化测试

### A.1 测试设置

| 项目 | 值 |
|------|-----|
| 测试小说 | 《都市异能：异能觉醒》（test_novel_urban.txt） |
| 小说类型 | 现代都市异能 |
| 对比基准 | 《斗破苍穹》（修仙题材） |
| 样本数量 | 30句包含引号的对话 |
| GT标注方式 | AI标注，建议人工抽查 |

### A.2 评估结果

| 指标 | 值 | 目标 | 判定 |
|------|-----|------|------|
| **准确率** | **26.7%** | ≥60% | ❌ **未达标** |
| 正确数 | 8/30 | - | - |
| 错误数 | 22/30 | - | - |

### A.3 混淆矩阵

| 预期\预测 | anger | fear | joy | neutral | surprise |
|-----------|-------|------|-----|---------|----------|
| anger | 0 | 0 | 0 | 3 | 0 |
| fear | 0 | 1 | 0 | 3 | 0 |
| joy | 0 | 0 | 1 | 7 | 1 |
| neutral | 0 | 0 | 0 | 6 | 2 |
| surprise | 0 | 0 | 0 | 6 | 0 |

**关键发现**：
- **neutral 严重过检**：22个错误中有16个被误判为 neutral（72.7%）
- **joy 漏检严重**：9个 joy 样本中只有1个正确识别，7个误判为 neutral
- **surprise 完全漏检**：6个 surprise 样本中6个被误判为 neutral
- **fear 部分识别**：4个 fear 样本中1个正确，3个误判为 neutral

### A.4 每情绪 F1 分数

| 情绪 | Precision | Recall | F1 |
|------|-----------|--------|-----|
| anger | 0.00 | 0.00 | 0.00 |
| fear | 1.00 | 0.25 | 0.40 |
| joy | 1.00 | 0.11 | 0.20 |
| neutral | 0.24 | 0.75 | 0.36 |
| surprise | 0.00 | 0.00 | 0.00 |

### A.5 错误原因分析

| 错误类型 | 示例 | 原因 |
|----------|------|------|
| 缺少明确情绪关键词 | "苏夜，你在这里！" → neutral | 引号内无"笑""怒""惊讶"等词 |
| 依赖引导词但引导词不在句中 | "公司出事了。" → neutral | 引导词"脸色凝重"在引号外 |
| 现代小说表达更隐晦 | "那你能帮我吗？" → neutral | 缺少修仙小说中常见的强烈情绪词 |
| 感叹号不足以判定情绪 | "为了守护这个世界！" → neutral | 规则未将标点符号作为情绪依据 |

### A.6 结论

**❌ 泛化能力不足（26.7% < 60%）**

情绪标注器在当前都市异能小说上表现远低于目标。核心问题是：
1. **过度依赖引导词**（如"笑道""怒道"），当引导词不在引号内时失效
2. **关键词词典偏向修仙题材**，对都市/现代小说的情绪表达覆盖不足
3. **中性默认倾向严重**：无明确匹配时统一返回 neutral

## 综合结论

### 决策矩阵

| 验证A结果 | 验证B结果 | 建议 |
|-----------|-----------|------|
| ✅ ≥60% | ✅ 差异明显 | 情绪标注有价值，继续优化 |
| ✅ ≥60% | ❌ 差异不明显 | 情绪标注有用但对TTS影响小，可降低优先级 |
| ❌ <60% | ✅ 差异明显 | **需要改进情绪标注后再集成TTS** |
| ❌ <60% | ❌ 差异不明显 | 情绪标注对当前阶段价值有限 |

**当前状态**: 
- 验证A: ❌ 26.7% (<60%)
- 验证B: ⏳ 待人工听评

### 下一步建议

#### 短期（1周内）
1. **修复情绪标注泛化问题** - 这是TTS质量的前提
   - 扩展关键词词典，覆盖都市/现代小说表达
   - 支持引号外引导词（上下文窗口扩大）
   - 考虑引入简单ML分类器替代纯规则

2. **完成B3人工听评** - 确认情绪对听感的影响

#### 中期（2-4周）
3. **ML情绪分类器** - 使用预训练模型（如 BERT-base-chinese fine-tuned on emotion）
4. **TTS模块完善** - 音频合并、离线降级方案
5. **前端音频播放器** - 实现播放控制

#### 长期（1个月+）
6. **端到端优化** - 情绪标注 → TTS → 人工反馈 → 模型迭代
