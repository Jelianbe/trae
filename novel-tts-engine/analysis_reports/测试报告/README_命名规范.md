## 文件命名规范

### 规则1：所有报告文件必须包含时间戳

**格式**: `中文类型_YYYYMMDD_HHMMSS.md`

**示例**:
- ✅ `泛化性测试报告_20260502_001700.md`
- ✅ `L2部署与NER增强修改汇总报告_20260502_100000.md`
- ✅ `第四轮测试进度_20260501_230000.md`
- ❌ `泛化性测试报告.md`（缺少时间戳）
- ❌ `第四轮测试进度_20260501.md`（缺少时间）

### 规则2：Python脚本命名

**格式**: `功能_版本号.py`

**示例**:
- ✅ `evaluate_generalization_v3.py`
- ✅ `compare_l2_v2.py`
- ✅ `run_v3_tests.py`
- ❌ `第五轮测试.py`（应改为英文+版本号）

### 规则3：调试脚本命名

**格式**: `动作_目标.py`（使用英文前缀）

| 前缀 | 用途 |
|------|------|
| `check_` | 检查/验证某项功能 |
| `diagnose_` | 诊断问题 |
| `debug_` | 调试Bug |

### 规则4：测试原始数据目录命名

**格式**: `测试类型_测试文本_YYYYMMDD_HHMMSS/`

**示例**:
- ✅ `泛化性测试_test_novel_urban_20260502_001634/`
- ✅ `全面分析测试_test_novel_western_20260501_120000/`

## 强制规则

1. **根目录必须为空**：所有文件必须放入对应子目录
2. **禁止嵌套**：不得在`analysis_reports/`下创建额外的子目录（如`analysis_reports/analysis_reports/`）
3. **测试数据定期清理**：每次运行评估脚本后，保留最新3个测试原始数据目录，删除旧的
4. **临时文件及时清理**：废弃的脚本和文件应放入`临时文件/`目录，定期删除

### 自动化清理脚本（建议添加到评估脚本）

```python
# 在run_v3_tests.py或其他评估脚本末尾添加：
import os
from pathlib import Path
import shutil

def cleanup_old_test_data(test_data_dir: str, keep_count: int = 3):
    """自动清理旧的测试原始数据目录"""
    dir_path = Path(test_data_dir)
    if not dir_path.exists():
        return
    
    # 获取所有测试数据目录，按修改时间排序
    test_dirs = sorted(
        [d for d in dir_path.iterdir() if d.is_dir()],
        key=lambda x: x.stat().st_mtime,
        reverse=True
    )
    
    # 删除旧目录（保留最新keep_count个）
    for old_dir in test_dirs[keep_count:]:
        print(f"🗑️  删除旧测试数据: {old_dir.name}")
        shutil.rmtree(old_dir)
    
    print(f"✅ 测试原始数据清理完成，保留最新{keep_count}个目录")

# 使用示例
cleanup_old_test_data("D:/trae/novel-tts-engine/analysis_reports/测试原始数据")
```
