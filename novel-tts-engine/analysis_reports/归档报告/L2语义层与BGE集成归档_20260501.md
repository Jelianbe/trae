### 2.3 HanLP 模块优化

#### 改动 5：添加批量处理支持

**问题**：HanLP 逐句处理性能低

**解决方案**：
- 添加 `batch_size` 配置参数
- 实现批量编码逻辑

**代码示例**：
```python
def batch_analyze(self, texts: List[str], batch_size: int = 32):
    """批量分析文本"""
    results = []
    for i in range(0, len(texts), batch_size):
        batch = texts[i:i+batch_size]
        batch_result = self.hanlp_model(batch)
        results.extend(batch_result)
    return results
```

**文件**: `pipeline/nlp_basics.py`

## 五、技术架构

### 5.1 L2 语义排序流程

```
输入对话文本
    ↓
提取候选说话人 (L1 过滤后)
    ↓
遍历候选人:
    1. 获取候选人对话历史
    2. 编码输入对话
    3. 编码候选人历史
    4. 计算余弦相似度
    ↓
选择最高分候选人
    ↓
置信度计算: 0.6 + (score - threshold) * 0.5
    ↓
输出 MatchResult
```
