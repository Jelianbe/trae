### 2.1 数据库路径集中化

#### 改动 1：创建统一配置模块

**问题**：数据库路径在多个文件中重复定义，指向不同位置

**旧代码问题**：
```python
# utils/config.py
DB_PATH = PROJECT_ROOT / "novel_tts.db"  # 根目录

# db/db_utils.py
DB_PATH = Path(__file__).parent.parent / "novel_tts.db"  # 根目录
```

### 2.2 日志系统优化

#### 改动 3：实现日志轮转

**问题**：日志文件无限增长，占用磁盘空间

**解决方案**：
```python
import logging
from logging.handlers import RotatingFileHandler

def setup_logger(name: str, log_file: str, max_bytes: int = 10*1024*1024, 
                 backup_count: int = 5) -> logging.Logger:
    """配置日志轮转"""
    logger = logging.getLogger(name)
    
    # 文件处理器（带轮转）
    file_handler = RotatingFileHandler(
        log_file,
        maxBytes=max_bytes,      # 10MB
        backupCount=backup_count  # 保留 5 个备份
    )
    
    # 控制台处理器
    console_handler = logging.StreamHandler()
    
    # 格式
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    file_handler.setFormatter(formatter)
    console_handler.setFormatter(formatter)
    
    logger.addHandler(file_handler)
    logger.addHandler(console_handler)
    logger.setLevel(logging.INFO)
    
    return logger
```

**文件**: `utils/logger.py`

#### 改动 4：增加日志文件大小限制

**配置**：
- 单个日志文件最大：10MB
- 保留备份数量：5 个
- 总磁盘占用：最多 60MB（1 个当前 + 5 个备份）
