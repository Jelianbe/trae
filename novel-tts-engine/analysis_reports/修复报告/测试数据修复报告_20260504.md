**修复日期**: 2026-05-04

**修复内容**: 为 dialogue_speakers 数组中的对话添加中文引号

---

## 一、问题背景

测试数据文件中的 `dialogue_speakers` 数组存储了对话文本和说话人的对应关系，但对话文本没有引号包裹，导致：

1. 与实际小说文本格式不一致（小说使用 `""` 或 `「」` 引号）
2. 评估脚本匹配时需要特殊处理
3. 无法测试引号分类器对中文引号的识别能力

## 三、修复示例

**修复前**:
```json
{
  "text": "少爷，您终于醒了！",
  "speaker": "小翠"
}
```

**修复后**:
```json
{
  "text": ""少爷，您终于醒了！"",
  "speaker": "小翠"
}
```

**引号字符**: 使用 Unicode 字符
- 左引号: `"` (U+201C)
- 右引号: `"` (U+201D)

---

## 四、评估脚本同步修复

为配合测试数据修改，同步修复了评估脚本 `evaluate_generalization_v3.py`：

**新增函数**:
```python
def normalize_quotes(text):
    """统一中英文引号为英文引号，便于匹配"""
    return text.replace('\u201c', '"').replace('\u201d', '"')
```

**修改匹配逻辑**:
```python
# 构建GT映射时统一引号格式
text_key = normalize_quotes(item["text"]).strip('"\'"\'')[:30]

# 匹配时也统一格式
normalized_line = normalize_quotes(line)
for key, speaker in gt_map.items():
    if key in normalized_line:
        gt_speaker = speaker
        break
```
