## 改动详情

### BUG-001: 回填机制依赖私有属性

**文件**: `pipeline/speaker_matcher.py` (L399)
**严重程度**: P1
**影响范围**: 冷启动回填路径，导致 AttributeError 并中断整个回填流程

**问题描述**:
`backfill_unknown_speakers()` 直接访问 `self.char_manager._confirmed_characters`，但 CharacterManager 的该属性名未公开保证稳定性，属于实现细节。

**修复方案**:
```python
# 修复前
confirmed_chars = list(self.char_manager._confirmed_characters.values())

# 修复后
confirmed_chars = self.char_manager.get_all_characters()
```

**影响分析**:
- 修复前：回填机制无法正常工作，"未知_角色" 永远无法被回填
- 修复后：使用公共 API，保证向后兼容性

---

### BUG-002: PipelineRunner 属性未初始化

**文件**: `pipeline/pipeline_runner.py` (L127)
**严重程度**: P1
**影响范围**: 在调用 `analyze_chapters()` 前调用 `export_json()` 时触发 AttributeError

**问题描述**:
`_full_text` 属性未在 `__init__` 中初始化，导致早期导出 JSON 时失败。

**修复方案**:
```python
def __init__(self):
    # ... 现有代码 ...
    self._full_text = ""  # 新增
```

**影响分析**:
- 修复前：必须严格按顺序调用 API，违反防御性编程原则
- 修复后：支持灵活的 API 调用顺序

---

### BUG-003: 章节标题属性名错误

**文件**: `pipeline/tts_generator.py` (L343)
**严重程度**: P1
**影响范围**: MP3 文件名生成失败，导致音频文件命名混乱

**问题描述**:
使用不存在的 `chapter_result.chapter_title` 属性，应为 `chapter_result.title`。

**修复方案**:
```python
# 修复前
chapter_name = chapter_result.chapter_title or "unknown"

# 修复后
chapter_name = chapter_result.title or "unknown"
```

**影响分析**:
- 修复前：所有生成的 MP3 文件名均为 "unknown"
- 修复后：文件名与章节标题一致，便于定位

## 竞品对标结论

### SonicVale vs Novel-TTS 架构对比

| 维度 | SonicVale | Novel-TTS |
|------|-----------|-----------|
| 技术栈 | Electron + Vue3 + Vite + Element Plus + FastAPI | 纯后端管道 + Streamlit 样品 |
| TTS 路线 | 在线 LLM + 云端 TTS | 离线 NLP + Kokoro/Index-TTS |
| 角色识别 | 手动指定 | 自动识别 + 回填 |
| 情绪标注 | 手动调节 | 自动提取 |
| 前端完成度 | ~90%（生产级） | ~40%（样品阶段） |

### Novel-TTS 独有优势
1. 角色自动识别（L0-L2 多级匹配）
2. 自动情绪标注（6 种情绪，Macro F1 0.94）
3. 代词消解
4. 离线优先
5. 回填机制
6. 拟声词检测

### SonicVale 独有优势
1. LLM 集成（在线处理）
2. Electron 桌面应用
3. 波形可视化编辑（wavesurfer.js）
4. 完整前端状态管理
