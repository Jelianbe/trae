## 1. 问题回顾

### 1.1 初始现象

| 指标 | 预期值 | 实际值 |
|------|--------|--------|
| 角色识别准确率 | ≥70% | **0.0%** |
| 情绪标注准确率 | ≥60% | 26.0% |

所有50条测试样本的角色预测结果均为**空字符串**。

### 1.2 根因定位

**问题链路**：

```
测试数据用 \n 分隔上下文
    ↓
split_sentences_smart 不识别 \n 为分隔符
    ↓
多行文本被合并成一个"句子"
    ↓
find_target_sentence 精确匹配失败
    ↓
返回空字符串
```

**核心问题**：`split_sentences_smart` 只识别标点符号（。！？；），不识别换行符（\n）。

---

## 2. 修复方案

### 2.1 方案A：换行符分隔（治本）

**修改文件**: `utils/text_utils.py`

**修改内容**: 重构 `split_sentences_smart` 函数，支持换行符作为句子分隔符。

**修改前**：
```python
def split_sentences_smart(text: str) -> List[str]:
    # 只识别标点符号，不识别换行符
    sentences = _SENTENCE_END_PATTERN.split(text)
    ...
```

**修改后**：
```python
def split_sentences_smart(text: str) -> List[str]:
    # 先按换行符分割，再对每行进行智能分割
    all_sentences = []
    lines = text.split('\n')
    for line in lines:
        if not line.strip():
            continue
        line_sentences = _split_line_smart(line.strip())
        all_sentences.extend(line_sentences)
    return all_sentences
```

**验证结果**：
```python
>>> split_sentences_smart('苏夜站在门口。\n「滚出去！」\n林雪愣住了。')
['苏夜站在门口。', '「滚出去！」', '林雪愣住了。']
```

### 2.2 方案B：包含匹配（兜底）

**修改文件**: `scripts/evaluate_full_pipeline.py`

**修改内容**: `find_target_sentence` 函数增加包含匹配作为兜底。

**代码**：
```python
def find_target_sentence(sentences, target_text: str):
    target_text = target_text.strip()
    # 精确匹配
    for s in sentences:
        if s.text.strip() == target_text:
            return s
    # 包含匹配（兜底）
    for s in sentences:
        if target_text in s.text:
            return s
    return None
```

## 4. 问题诊断

### 4.1 为什么准确率仍然较低？

**原因分析**：

1. **测试数据特性**：50条测试样本都是**高难度场景**，专门设计用于测试系统的边界能力

2. **系统未实现的功能**：
   - 代词消解：将"他/她/那人"关联到上一句提到的角色
   - 别名映射：将"老臣/属下/师兄"映射到具体角色名
   - 描述性称呼识别：将"黑甲骑士/圣骑士"关联到具体角色

3. **简单场景已解决**：显式提示在上文/下文的场景，准确率已达100%
