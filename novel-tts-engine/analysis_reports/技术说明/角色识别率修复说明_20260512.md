## 一、问题背景

| 项目 | 状态 |
|------|:--:|
| 情绪标注 | ✅ 64%，已恢复 |
| L2语义匹配 | ✅ 可用，注入修复生效 |
| 角色识别 | ❌ **58.9%**，预期76.4%，缺口17.5% |

### 根因定位

`match_speaker` 方法在v4到当前版本之间发生了逻辑改动。v4中"不确定就返回未知"的行为被改成了"不确定就继续猜"，导致原本正确返回"未知"的场景被后续低置信度匹配覆盖。

更深层的问题：
1. **角色库匹配被阻断**：`_extract_context_speakers` 返回"未知"后，`match_speaker` 直接返回未知，阻断了所有后续 fallback 策略（角色库匹配、语义匹配等）
2. **身份词提取模式不完整**：`_extract_identity_words` 缺少对"笑道""沉声道"等说话动词变体的支持
3. **缺少角色库兜底匹配**：上下文推理失败时，没有尝试从预创建角色库中匹配旁白内容

## 二、修复内容

### 修复1：在 `_extract_context_speakers` 中添加角色库匹配作为兜底步骤

**文件**: `pipeline/speaker_matcher.py`
**行号**: L637-L645

**修改前**：
```python
        if not candidates:
            candidates.append(('未知_无法推断', '无上下文线索', 0.30))
```

**修改后**：
```python
        # 兜底步骤：在角色库中匹配旁白内容
        # 用于处理"掌柜抬头看了看他，笑道"等场景，其中身份词提取失败但角色库中有该角色
        if not candidates:
            narration = self._extract_narration('', context_before, context_after)
            if narration:
                char_match = self._match_from_character_library(narration)
                if char_match:
                    candidates.append((char_match.name, '角色库旁白匹配', 0.70))
                    seen_names.add(char_match.name)

        if not candidates:
            candidates.append(('未知_无法推断', '无上下文线索', 0.30))
```

**修复原理**：
当身份词提取、NER、代词解析等所有常规方法都失败时，尝试从预创建的角色库中直接匹配旁白文本。例如：
- 原文：`掌柜抬头看了看他，笑道："客官来得巧..."`
- 旁白：`掌柜抬头看了看他，笑道`
- 角色库匹配：找到预创建的"掌柜"角色，返回 `(掌柜, '角色库旁白匹配', 0.70)`

### 修复2：移除过早返回"未知"阻断后续fallback的逻辑

**文件**: `pipeline/speaker_matcher.py`
**行号**: L957-L969

**修改前**：
```python
        if context_candidates:
            name, reason, confidence = context_candidates[0]
            if name.startswith('未知_') or name == '未知':
                # 直接返回未知，阻断所有后续匹配
                unknown_char = Character(id=-1, name=name, aliases=set(), gender='unknown')
                return MatchResult(character=unknown_char, confidence=confidence, match_type=f'context_unknown:{reason}')
            else:
                char = self.char_manager.get_character_by_name(name, self._current_project_id)
                if char:
                    return MatchResult(character=char, confidence=confidence, match_type=f'context_reasoning:{reason}')
                # 有候选名但未在角色库中找到，也返回未知
                unknown_char = Character(id=-1, name=name=name, aliases=set(), gender='unknown')
                return MatchResult(character=unknown_char, confidence=confidence, match_type=f'context_unknown_not_in_db:{reason}')
```

**修改后**：
```python
        if context_candidates:
            name, reason, confidence = context_candidates[0]
            # 不直接返回未知，允许后续 fallback 策略尝试匹配角色库
            if not name.startswith('未知_') and name != '未知':
                # _extract_context_speakers 已匹配到角色库
                char = self.char_manager.get_character_by_name(name, self._current_project_id)
                if char:
                    return MatchResult(
                        character=char,
                        confidence=confidence,
                        match_type=f'context_reasoning:{reason}'
                    )
            # 如果返回未知或不在角色库中，继续走后续匹配环节
            # 让 match_by_semantic、match_from_context_mentioned 等 fallback 策略有机会尝试
```

**修复原理**：
移除保守策略中过于激进的 early return。当上下文推理返回"未知"时，不再立即终止匹配流程，而是允许后续的 fallback 策略（如语义匹配、上下文提及匹配、角色库匹配等）继续尝试。

### 修复3：修复 `_extract_identity_words` 身份词提取模式

**文件**: `pipeline/speaker_matcher.py`
**行号**: L480-L503

**修改前**：
```python
        # 规则1：对着/对/向/跟 + 名词 + 说话动词
        pattern1 = r'(?:对着|朝向|向着|跟着|对着|向着|跟|向|对)([\u4e00-\u9fa5]{2,4}?)(?:说道|问道|喊道|叫道|说|道|问|喊|叫|呼唤)'
        for match in re.finditer(pattern1, text):
            word = match.group(1)
            if word not in ('什么', '哪里', '怎么', '为什么'):
                candidates.append(word)
```

**修改后**：
```python
        # 规则1：对着/对/向/跟 + 名词 + 说话动词
        # 使用简单字符类，避免非贪婪匹配吞噬后缀动词
        pattern1 = r'[对着向跟]([\u4e00-\u9fa5]{2,4})[说道问喊叫呼唤]'
        for match in re.finditer(pattern1, text):
            word = match.group(1)
            if word not in ('什么', '哪里', '怎么', '为什么'):
                candidates.append(word)
        
        # 规则1b：名词 + 说话动词（含笑道/沉声道等变体）
        # 用于处理"掌柜抬头看了看他，笑道"、"苏夜冷声道"等场景
        pattern1b = r'([\u4e00-\u9fa5]{2,4})(?:笑道|沉声道|低声道|高声道|冷冷道|淡淡道|回答道|答道)'
        for match in re.finditer(pattern1b, text):
            word = match.group(1)
            # 过滤非人名：代词、动词结尾、功能词
            if word not in ('什么', '哪里', '怎么', '为什么', '看着他', '看了看', '他又劝', '看了看他'):
                # 过滤以代词开头的词（如"他又劝"）
                if not word.endswith(('了', '着', '的', '地')):
                    if not word.startswith(('他', '她', '它', '我', '你', '们')):
                        candidates.append(word)
```

**修复原理**：
1. **简化规则1**：从复杂的非贪婪匹配改为简单字符类 `[对着向跟]...说道`，避免正则表达式吞噬后缀动词
2. **新增规则1b**：支持"笑道""沉声道"等说话动词变体，覆盖更多小说常见表达方式
3. **过滤代词开头**：防止模式误匹配"他又劝"等代词短语作为角色名
