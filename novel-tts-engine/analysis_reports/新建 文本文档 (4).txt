## 功能一：统计误合并检测泛化（v2.2方案的后续升级）

### 1.1 当前状态

`_detect_mis_merged_entities` 的 v2.2 方案已落地，NER 达到 92.3。检测逻辑是：

```
实体A是误合并，如果：
1. A长度 ≥ 3
2. A包含高频前缀B（B出现 ≥ 5次）
3. A出现次数 ≤ 2
4. A出现次数 < B的10%
5. A的右邻字中，至少50%是对话引导词
```

这个方案已经完全消除了旧版 `SINGLE_CHAR_VERBS` 的 30 个硬编码后缀，但其第 5 个判定条件中仍包含一个人工枚举的 `DIALOGUE_WORDS` 集合（20 个节点）。

### 1.2 被遗弃的子任务

在测试报告出炉后，我们共同指出了 `DIALOGUE_WORDS` 仍是硬编码，长期来看会有限制，并提出了一个“动态对话引导词发现”的方向。这个子任务后来被评定为“战略投资”，因为短期内 NER 已经达到了 92.3 的优良水平，但长期来看消除这个硬编码具有明显的架构价值。

### 1.3 潜在优化方向

*   **动态对话引导词发现**：其核心思路是，既然“萧炎冷”的右邻字高度集中在对话场景，那我们可以直接从文本中学习这个规律。具体做法是，从已确认的说话角色（比如出现 ≥ 5 次且右邻字多样的 PER 实体）的对话中，自动收集其右邻字作为高概率对话引导词，从而彻底移除硬编码。
*   **启动条件**：根据我们之前制定的框架，该任务在以下条件下可重新激活：`硬编码密度` 指标超过阈值；或者新文体（如历史、科幻）的 NER 分数低于 75 分。

---

## 功能二：连续 nr 合并（外国人名修复）

### 2.1 问题的提出

在项目早期，你曾主动提出过这个优化方向。当时我们发现，HanLP 在遇到西幻翻译体小说中的外国人名时，常常会错误地将它们拆开。比如，“艾米莉亚”会被拆成 `艾米/nr + 莉亚/nr` 两个独立的实体，而不是一个完整的人名。

### 2.2 当时的讨论结论

我们商量出的具体实现方案是：在 `_enhance_entities` 中增加一条规则，专门处理词性为 `nr` 的连续 token。如果中间夹着间隔符（`·`、`-`），就跳过间隔符继续合并，最终将合并后的文本作为一个新的 `PER` 实体。关于吞掉间隔符这一点，你倾向于保留，比如输出“艾米莉亚”，因为 TTS 引擎可以直接朗读这样的组合。

### 2.3 被遗弃原因

这个方向在当时被评估为“锦上添花”而非“雪中送炭”。因为在那个时候，我们还有更紧迫的、基础性的问题要解决，比如整个 NER 的准确率还很低，西幻文本的整体分数也没上来，所以这项优化就被暂时搁置，之后再也没被提起过。

### 2.4 现在重新实施的可行性

现在重拾这个方案是一个绝佳的时机，因为实施基础已经完全不同了：

*   **改动量极小**：只需要在现有的规则增强逻辑（`_enhance_entities`）中增加一个扫描连续 `nr` token 的循环即可。
*   **测试完备**：我们现在已经有了完整的 160 个测试用例网，包括专门的西幻文本测试。这意味着改动后可以立刻跑通西幻测试来验证效果，评估提升幅度。
*   **风险可控**：这项修改的作用域非常清晰，只会影响连续 `nr` token 的处理，不会干扰到我们现有的、已经成熟的实体增强规则。

### 2.5 预期收益

这个优化实施后，预计将直接提升西幻翻译体小说的 NER 召回率，特别是对那些包含较长译名（如“克里斯托弗”）的角色识别会有明显改善。考虑到改动成本极低，其投入产出比会非常高。

### 工具函数设计
```python
# utils/wordlist_loader.py
import json
from pathlib import Path
from typing import List, Dict, Any

WORDLIST_DIR = Path(__file__).parent.parent / "data" / "wordlists"

def load_wordlist(category: str, name: str) -> List[str]:
    """加载指定词表
    
    Args:
        category: 词表类别（emotion/speaker/dialogue）
        name: 词表名称（如 dirty_words）
    
    Returns:
        词表列表，加载失败时返回空列表
    """
    file_path = WORDLIST_DIR / category / f"{name}.json"
    if not file_path.exists():
        return []
    with open(file_path, 'r', encoding='utf-8') as f:
        return json.load(f)

def load_emotion_wordlists() -> Dict[str, List[str]]:
    """加载所有情绪相关词表"""
    return {
        "dirty_words": load_wordlist("emotion", "dirty_words"),
        "emotion_adverbs": load_wordlist("emotion", "emotion_adverbs"),
        "emotion_verbs": load_wordlist("emotion", "emotion_verbs"),
    }
```
