## 5. 发现的问题及处理

### 5.1 数据清理类

| 问题 | 涉及用例数 | 处理方式 |
|------|-----------|----------|
| 重复条目（3条各×3） | 6条冗余 | 去重保留1份 |
| Speaker 含注释文本（"其中X与Y为同一角色"） | 6条 | 截取首段，清理注释 |
| 多对话 speaker 数组未拆分 | 3条（C2类） | 改进 JSON-like 列表解析 |
| Speaker 描述性文本 | 3条（C3/C4类） | 标准化：提取主名称，"未知角色"→"未知" |
| E类缺失上下文对话 | 6条（E1/E2类） | 补全第一段引号对话期望值 |
| D1类段落含"(无)"噪声 | 3条 | 清理为纯文本 |

### 5.2 分类修正类

| 用例 | 原分类 | 修正后 | 原因 |
|------|--------|--------|------|
| F1-3 | non_dialogue | unknown_speaker | 传音符内容，有实际对话但说话人未知 |
| D3-1 | unknown_speaker | non_dialogue | 古籍文字引用，非角色对话 |
| D3-2 | unknown_speaker | non_dialogue | 石碑铭文，非角色对话 |

### 5.3 格式标准化

- **统一字段**: `id` / `source` / `category` / `paragraph` / `dialogues` / `note`
- **speaker 规范**: 角色名 / `未知` / `GROUP:XXX`，不含注释文本
- **非对话**: `dialogues: []` 表示预期无对话检测
- **ID 规则**: 
  - `H-NNN` → 历史用例
  - `A1-N`~`F2-N` → AI生成分类用例
  - `GT-文体-NNN` → 全文GT提取（如 `GT-修仙-001`）

### 5.4 重叠分析

| 对话文本 | 出现位置 | 处理 |
|----------|----------|------|
| "把东西交出来。" | H-004 + D1-1 | 保留双份（不同场景） |
| "林轩，你又在偷懒！" | H-005 + C3-1 | 保留双份 |
| "这丹药如何？" | H-015 + C1-1 | 保留双份 |
| "撤退！" | 西幻 GT 重复 | 去重 |
