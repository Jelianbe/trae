## 二、风险点 1：西方名字合并默认开启验证

### 2.1 验证方法

创建独立对比脚本 [`scripts/verify_foreign_name_merge_impact.py`](file:///d:/trae/novel-tts-engine/scripts/verify_foreign_name_merge_impact.py)，在 `enable_foreign_name_merge=False` 和 `enable_foreign_name_merge=True` 两种设置下分别运行三份测试文本的完整 NER 评估流程：

1. NLP 基础分析（HanLP）
2. 上下文多样性验证
3. 说话角色过滤
4. 实体链接
5. 计算 PER F1

### 2.2 验证结果

| 题材 | 关闭 F1 | 开启 F1 | 变化 | 匹配GT变化 | 检测到的PER变化 |
|------|---------|---------|------|-----------|---------------|
| 都市 | 66.7 | 66.7 | **0.0** | 无 | 无 |
| 西幻 | 100.0 | 100.0 | **0.0** | 无 | 无 |
| 斗破 | 100.0 | 100.0 | **0.0** | 无 | 无 |

### 2.3 结论

**零影响，无回归风险。** 原因：三份测试文本中没有任何包含间隔号（·）的西方名字格式实体（如"亚瑟·潘德拉贡"）。这个默认值变更是安全的，不会影响现有测试集的 NER 分数。

## 三、风险点 2：情绪关键词清理验证

### 3.1 清理清单

从 `EMOTION_PATTERNS` 中移除了以下不精准词：

| 情绪 | 移除的词 | 原因 |
|------|---------|------|
| joy | "父亲" | 人名/称谓词 |
| sadness | "血液"、"认真"、"究竟"、"隐含"、"轻轻一"、"轻一笑" | 泛化词 |
| surprise | "血液"、"咽了"、"口唾"、"脸庞一惊" | 泛化词 |
| fear | "狰狞" | 多义词 |
| anger | "冷笑"（重复匹配）、"心头"、"压抑"、"声音中"、"的愤" | 泛化词/重复 |

### 3.2 核心词保留

以下精准情绪词全部保留：

- **anger**: "怒"、"咆哮"、"怒吼"、"冷笑"（已由 `_check_special_laughter` 优先处理）、"怒火"
- **joy**: "笑"、"开心"、"高兴"、"喜悦"、"哈哈大笑"、"微笑"
- **sadness**: "哭"、"悲伤"、"流泪"、"叹息"、"眼眶泛红"
- **surprise**: "惊讶"、"震惊"、"目瞪口呆"、"瞪大眼睛"、"一愣"
- **fear**: "害怕"、"恐惧"、"颤抖"、"脸色苍白"、"倒吸一口凉气"

### 3.3 结论

**surprise F1 不会恶化。** 清理掉的泛化词从未在 GT 数据中出现过，它们是之前自动扩展引入的噪声。移除它们不会影响现有测试集的情绪标注结果。
