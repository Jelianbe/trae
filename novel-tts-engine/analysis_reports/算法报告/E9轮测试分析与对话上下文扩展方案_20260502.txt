## 问题根因与修复方案

### 问题：对话上下文提取窗口不够聪明

当前 `SpeakerRoleFilter._get_dialogue_texts` 的逻辑是：

```
找到引号 → 取引号前15字符 → 提取其中的PER实体
```

这漏掉了两种关键模式：
1. **“XX说道”在引号后**：如 `“少爷，您醒了。”老陈说道。`
2. **说话人提示在引号中间**：如 `“少爷，”老陈说道，“您醒了。”`

### 修复方案：扩展上下文提取策略

不需要重写整个过滤器，只需要在 `_get_dialogue_texts` 中增加两种模式的检测：

```python
def _get_dialogue_contexts(self, text: str) -> List[str]:
    """提取所有可能包含说话人提示的上下文窗口"""
    contexts = []
    
    # 模式1：引号前的上下文（已有）
    for match in re.finditer(r'["\u201c].*?["\u201d]', text):
        start = match.start()
        contexts.append(text[max(0, start-15):start])
    
    # 模式2：引号后的上下文（新增）
    # 匹配 "dialogue" 后面紧跟的 "XX说道"
    for match in re.finditer(r'["\u201d]\s*([^，。！？\n]{2,10}?)(?:说道|问道|喊道|笑道|道|说)', text):
        speaker = match.group(1).strip()
        if speaker:
            contexts.append(speaker)
    
    # 模式3：引号中间的说话人提示（新增）
    # 匹配 "dialogue，" XX说道，"dialogue"
    for match in re.finditer(r'["\u201d]\s*，\s*([^，。！？\n]{2,10}?)(?:说道|问道|喊道|笑道|道|说)\s*[，,]\s*["\u201c]', text):
        speaker = match.group(1).strip()
        if speaker:
            contexts.append(speaker)
    
    return contexts
```

这个修复预计能让都市 NER 回到 70% 以上，同时保持西幻 NER 的回升势头。
