## 说话角色识别与验证融合方案

### 1. 核心策略

放弃对全文中所有名词的识别，只关注**在对话引导词附近出现的**实体。质量远胜于数量。

*   **策略转变**：从“找所有可能的人名/组织名”转变为“找对话中是谁在说话”。
*   **技术路径**：将 `SpeakerRoleFilter`（负责筛选说话角色）与 `ContextDiversityValidator`（负责统计验证）正交融合。前者进行场景筛选，后者进行统计确认，形成交叉验证。

### 2. 详细实施步骤

#### 步骤 1：新增 `SpeakerRoleFilter` 模块

创建文件 `pipeline/speaker_role_filter.py`。这个模块负责完成两件事：扫描全文找出所有说话角色候选，以及利用 L2 语义交互来捞回低频实体。

```python
# pipeline/speaker_role_filter.py
import re
from typing import List, Set, Dict, Optional, Tuple
from pipeline.nlp_basics import NLPBasics, Entity, get_nlp

class SpeakerRoleFilter:
    """说话角色过滤器：只保留出现在对话引导词附近的实体"""
    
    def __init__(self, semantic_ranker=None, l2_threshold=0.7):
        self.semantic_ranker = semantic_ranker
        self.l2_threshold = l2_threshold
        self._dialogue_entities_cache = None  # (text_hash, entities_set)
        self._entity_scene_count: Dict[str, int] = {}  # 实体出现在不同对话场景的次数

    def _get_dialogue_texts(self, text: str) -> List[str]:
        """提取所有包含引号的对话行或其附近的文本窗口"""
        # 简单实现：匹配成对的引号，并取引号前15个字符作为说话人提示上下文
        pattern = re.compile(r'["\u201c].*?["\u201d]')
        contexts = []
        for match in pattern.finditer(text):
            start = match.start()
            # 取对话前面的上下文窗口
            context_window = text[max(0, start-15):start]
            contexts.append(context_window.strip())
        return contexts

    def _extract_dialogue_entities(self, text: str, nlp: NLPBasics) -> Set[str]:
        """从所有对话上下文中提取说话角色候选实体"""
        contexts = self._get_dialogue_texts(text)
        entities = set()
        scene_ids = set()
        for ctx in contexts:
            if not ctx:
                continue
            # 用NLP分析上下文窗口，提取PER实体
            result = nlp.analyze(ctx)
            for e in result.entities:
                if e.type == 'PER':
                    entities.add(e.text)
                    # 统计出现在不同场景的次数（简单用上下文窗口作为场景区分）
                    scene_key = ctx[:30]  # 截取前30字作为场景ID
                    if scene_key not in scene_ids:
                        self._entity_scene_count[e.text] = self._entity_scene_count.get(e.text, 0) + 1
                        scene_ids.add(scene_key)
        return entities

    def filter(self, entities: List[Entity], text: str, nlp: NLPBasics) -> List[Entity]:
        # 仅首次调用时提取说话角色集合
        if self._dialogue_entities_cache is None:
            self._dialogue_entities_cache = self._extract_dialogue_entities(text, nlp)
        dialogue_entities = self._dialogue_entities_cache

        filtered = []
        for e in entities:
            # 1. 过滤非说话角色
            if e.text not in dialogue_entities:
                continue
                
            # 2. 对低频实体进行L2补偿
            if e.confidence < 0.5 and self.semantic_ranker:
                new_conf = self._apply_l2_boost(e, text)
                if new_conf > e.confidence:
                    e.confidence = new_conf
            filtered.append(e)
        return filtered

    def _apply_l2_boost(self, entity: Entity, full_text: str) -> float:
        # 检查该实体作为说话人的场景次数
        scene_count = self._entity_scene_count.get(entity.text, 0)
        if scene_count >= 2 and self.semantic_ranker.is_available():
            # 简单模拟：取该实体作为说话人的几句上下文，与实体名做语义相似度
            # 这里不需要真正跑L2，仅根据场景次数提升置信度
            if scene_count >= 3:
                return 0.8
            else:
                return 0.65
        return entity.confidence
```

### 4. 风险与回退

1.  **漏掉没有说话、但旁白中很重要的角色**：
    *   **影响**：这些角色不需要配音，对有声书制作无影响，属于统计性可接受的漏检。
    *   **回退**：若需要全人物识别，可设置开关关闭 `SpeakerRoleFilter`，退回到原逻辑。

2.  **初始标注成本**：需为每个测试文本标注 `speaking_persons`，但工作量极小。
3.  **L2 交互验证失效**：若 L2 引擎未加载，过滤效果仅靠场景统计，低频实体仍可能被降级。可配置降级阈值。
