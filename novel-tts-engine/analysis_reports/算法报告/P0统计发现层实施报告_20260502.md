## 三、问题根因分析

### 3.1 统计发现层已工作

DEBUG输出显示`discover_compound_entities`成功发现了9个新实体：
```

NEW COMPOUND: 萧族 (count=5, pos=11575)
NEW COMPOUND: 萧叔 (count=4, pos=11888)
```

**关键发现**："药老"被正确发现了（出现2次在对话引导词附近），且GT的`speaking_persons`中包含"药老"。

### 3.2 NER不升反降的原因

即使"药老"被发现，NER从45.5降到38.7。可能原因：

**假设1：统计发现的新实体被下游管道过滤**
- `SpeakerRoleFilter`的`_dialogue_entities`集合只包含HanLP识别的出现在对话附近的实体
- 新发现的"药老"不在这个集合中，可能被后续步骤过滤
- `EntityLinker`可能无法将"药老"正确关联到GT的`aliases`映射

**假设2：评估管道的entity type不一致**
- `discover_compound_entities`创建的实体type='PER'
- 但评估脚本中`high_conf_entities = [e for e in linked_entities if getattr(e, 'confidence', 1.0) >= 0.5]`
- 如果`EntityLinker`修改了confidence或type，可能导致新实体被过滤

**假设3：GT别名映射问题**
- GT中`aliases: {'药老': ['药尘', '老者']}`
- 如果`EntityLinker`将"药老"链接到"药尘"，但GT的`speaking_persons`是"药老"
- 则F1计算时"药尘"不在`gt_speaking_persons`中

### 3.3 需要上层AI诊断的问题

1. **`SpeakerRoleFilter`是否过滤了新发现的实体？**
   - 需要检查`role_filter.filter()`方法内部如何处理confidence=0.65的实体
   - 评估脚本中已让组合实体绕过filter，但需要确认

2. **`EntityLinker`是否正确处理新实体？**
   - 需要检查`linker.link()`方法对confidence=0.65的实体的处理逻辑
   - 别名映射是否正确应用到新实体

3. **评估脚本中`high_conf_entities`的过滤逻辑**
   - confidence阈值是0.5，新实体confidence=0.65应该通过
   - 但`EntityLinker`可能修改了confidence

### 附录A：`discover_compound_entities` 完整代码

```python
def discover_compound_entities(
    self,
    full_text: str,
    existing_entities: List[Entity],
) -> List[Entity]:
    """
    通用实体统计发现：从全文扫描中发现"字A+字B"组合模式（2026-05-02）
    
    P0级别核心方法。不依赖词表，纯从文本统计中学习组合模式。
    
    策略：
    1. 找到所有单字PER实体（如"药"、"萧"、"云"）
    2. 统计"单字+后继字"组合出现在对话引导词前面的次数
    3. 如果"药老说道"出现多次，而"药师说道"不出现，说明"药老"才是说话角色
    
    Args:
        full_text: 完整文本
        existing_entities: 已有的实体列表
        
    Returns:
        新发现的组合实体列表
    """
    # 收集所有单字PER实体
    single_char_pers = set()
    for entity in existing_entities:
        if entity.type == 'PER' and len(entity.text) == 1:
            single_char_pers.add(entity.text)
    
    if not single_char_pers:
        return []
    
    # 边界词列表
    BOUNDARY_WORDS = [
        '说道', '问道', '喊道', '笑道', '淡淡道', '沉声道', '冷声道',
        '轻声道', '低声道', '道', '来到', '走出', '看着',
        '点了点头', '摇了摇头', '皱眉', '转身', '站起', '坐下',
        '讽刺道', '承喏道', '打趣道', '柔声道', '安慰道', '询问道',
        '赞叹道', '怪笑道', '冷笑道', '喃喃道', '怪声道',
    ]
    
    # 统计"单字+后继字"组合出现在边界词前面的次数
    combo_counter = Counter()
    combo_positions = defaultdict(list)
    
    for char in single_char_pers:
        start = 0
        while True:
            pos = full_text.find(char, start)
            if pos == -1:
                break
            
            # 检查该字符后面是否紧跟一个字
            if pos + 1 < len(full_text):
                next_char = full_text[pos + 1]
                # 跳过标点和空白
                if next_char in '，。！？；：""''（）【】《》\n\r\t 、…':
                    start = pos + 1
                    continue
                
                combo = char + next_char
                
                # 检查该组合后面不远处是否有边界词（50字符内）
                context_end = min(len(full_text), pos + 60)
                context = full_text[pos:context_end]
                has_boundary = any(bw in context for bw in BOUNDARY_WORDS)
                
                if has_boundary:
                    combo_counter[combo] += 1
                    combo_positions[combo].append(pos)
            
            start = pos + 1
    
    # 过滤：只保留出现≥2次的组合
    existing_texts = set(e.text for e in existing_entities)
    new_entities = []
    
    for combo, count in combo_counter.items():
        if count < 2:
            continue
        
        # 跳过已存在的实体
        if combo in existing_texts:
            continue
        
        # 创建新实体
        first_pos = combo_positions[combo][0]
        import os
        if os.environ.get('DEBUG_DISCOVER'):
            print(f"  NEW COMPOUND: {combo} (count={count}, pos={first_pos})")
        
        new_entity = Entity(
            text=combo,
            type='PER',
            start=first_pos,
            end=first_pos + len(combo),
            confidence=0.65,
        )
        new_entities.append(new_entity)
    
    import os
    if os.environ.get('DEBUG_DISCOVER'):
        print(f"[DEBUG] discover_compound_entities: found {len(new_entities)} new entities: {[e.text for e in new_entities]}")
    return new_entities
```

### 附录B：`validate()` 方法变更

```python
def validate(
    self,
    entities: List[Entity],
    full_text: str,
    chapters: Optional[List[Dict]] = None,
) -> List[Entity]:
    # 步骤1：为每个唯一实体文本收集上下文统计 + 共现统计
    stats = self._collect_context_stats(entities, full_text, chapters)
    
    # 步骤2：根据多样性 + 共现统计调整置信度
    validated = []
    for entity in entities:
        key = entity.text
        if key in stats:
            new_conf = self._calculate_confidence(entity, stats[key])
            entity.confidence = new_conf
        validated.append(entity)
    
    # 通用实体统计发现：P0 - 从全文扫描中发现"字A+字B"组合模式（2026-05-02）
    # 这是统计发现层，不依赖词表，从文本自身学习组合模式
    discovered = self.discover_compound_entities(full_text, validated)
    validated.extend(discovered)
    
    return validated
```
