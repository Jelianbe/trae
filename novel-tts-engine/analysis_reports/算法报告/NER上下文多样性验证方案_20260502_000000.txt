## ContextDiversityValidator 测试方案

### 一、目标

在不修改现有 NER 规则的前提下，对实体列表进行二次过滤，自动调整置信度：
- 过滤掉“固定搭配中的高频片段”（如“青龙帮”中的“青龙”）
- 保留“多种上下文中出现的真实实体”（如“林轩”、“艾德温”）

### 二、核心判定逻辑

| 条件 | 操作 |
|------|------|
| 总出现次数 < 3 | 降为低置信度（0.3），疑似噪声 |
| 总出现次数 ≥ 3，右邻字种类 ≤ 1 | 极可能为固定搭配片段，降为极低置信度（0.2） |
| 总出现次数 ≥ 3，右邻字种类 ≥ 2 | 维持原置信度 |
| 总出现次数 ≥ 5，右邻字种类 ≥ 3，且章节分布 ≥ 2 | 提升为高置信度（最低0.8） |

### 三、实现步骤

#### 第一步：新建模块 `pipeline/context_diversity_validator.py`

核心类 `ContextDiversityValidator`：

```python
class ContextDiversityValidator:
    def __init__(self, min_occurrences=3, high_conf_threshold=5, diversity_threshold=2):
        self.min_occurrences = min_occurrences
        self.high_conf_threshold = high_conf_threshold
        self.diversity_threshold = diversity_threshold
    
    def validate(self, entities: List[Entity], full_text: str, chapters: List = None) -> List[Entity]:
        """主入口：对实体列表进行上下文多样性验证，返回调整后的实体列表"""
        # 步骤1：为每个唯一实体文本收集上下文
        stats = self._collect_context_stats(entities, full_text)
        
        # 步骤2：根据多样性调整置信度
        validated = []
        for entity in entities:
            key = entity.text
            if key in stats:
                new_conf = self._calculate_confidence(entity, stats[key])
                entity.confidence = new_conf
            validated.append(entity)
        
        return validated
    
    def _collect_context_stats(self, entities, full_text):
        """收集每个实体文本的出现次数、右邻字集合、所在章节（如有）"""
        stats = {}
        for entity in entities:
            key = entity.text
            if key not in stats:
                stats[key] = {
                    'occurrences': 0,
                    'right_neighbors': set(),
                    'chapter_ids': set()
                }
            # 在全文中查找所有出现位置，收集右邻字
            # 由于性能考虑可先收集实体位置，此处简化：按已知实体位置
            # 实际实现会用 regex 或直接扫描全文
            stats[key]['occurrences'] += 1
            # 从 entity.start/end 获取右邻字，需传入全文，这里略
        
        return stats
    
    def _calculate_confidence(self, entity, stat):
        """根据上下文多样性计算新置信度"""
        occ = stat['occurrences']
        diversity = len(stat['right_neighbors'])
        
        if occ < self.min_occurrences:
            return 0.3  # 低频，降置信度
        if occ >= self.min_occurrences and diversity <= 1:
            return 0.2  # 固定搭配片段
        if occ >= self.high_conf_threshold and diversity >= self.diversity_threshold:
            return max(entity.confidence, 0.8)  # 高频高多样，提升置信度
        
        return entity.confidence  # 保持原样
```

**注意**：性能优化——为避免对每个实体都全文搜索，可以在 `_collect_context_stats` 中只处理传入实体列表，利用已有的位置信息。如果当前实体没有位置信息，则可以再走全文搜索。

#### 第二步：在 `evaluate_ner` 评估函数中接入

在 `evaluate_generalization_v3.py`（或你的测试脚本）的 NER 评估部分，在获取实体后立即调用验证器：

- 真实实体（如“林轩”、“艾德温”）是否保持高置信度
- NER 精确率是否有提升

### 五、注意事项与后续调优

1. 如果测试后发现某些低频但重要的实体被误降级（如只出现2次的核心配角），可调整 `min_occurrences` 为 2 或结合其他信号。
2. 右邻字的获取可先实现简单版（取实体后第1-2个非标点字符），后续可优化为词的右邻字。
3. 若性能成为瓶颈，可先对实体列表去重，只对唯一文本进行全文扫描，再回填结果。
