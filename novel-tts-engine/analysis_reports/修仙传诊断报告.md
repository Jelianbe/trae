《修仙传》
作者：月笙如歌
简介：无

第1章
  午阳山的山风吹在身上，带着一股硫磺与草木腐烂混合的独特气味。孙项明站在蜿蜒的队伍中，看着前方鳞次栉比、领取物资的散修背影，心中那份穿越者的傲气早已被现实磨砺得只剩下冰冷的棱角。

  筑基中期。

  普通散修资质。

  金丹便是终点。

  这几个词像烙印一样刻在他的神魂深处。百余年后的枯骨，秘境里的无名炮灰——这便是"命运"为他勾勒的、清晰得令人绝望的轨迹。苍天给了他穿越的机缘，却又吝啬得只给了这样一副不上不下的躯壳，神魂强些？顶多让他日后在符箓丹道上做个精细些的工匠罢了，于大道长生，杯水车薪。

  "不甘心啊……"他低声自语，指节捏得发白。与其在末流的挣扎中耗尽寿元，不如趁着这百十年"壮年"，心气尚未被磨灭，去搏那一线并非注定的生机！

  前方传来管事刻板的声音："孙项明！"

  孙项明立刻收敛心神，迈步上前。

  负责发放物资的是仓央洲林家的管事，一个面无表情的中年修士。递过来的东西轻飘飘，却几乎是散修进入午阳山秘境的标配：一个粗糙玉瓶，装着几粒气味刺鼻的低阶回春丹；两张边缘微微磨损的土黄色遁地符；两张绘制着淡薄云纹的匿气符。

  "规矩都懂。出来之后，七成收获上交，林家自有灵晶丹药补偿。"管事眼皮都没抬，语气公式化。

  "明白。"孙项明接过东西，熟练地检查了一下符箓的灵光是否稳定，丹药是否有异样。这是他数次进入秘境养成的本能——散修的命，得靠自己小心。

  "哟，老孙！你也来了啊！"一个略显油滑的声音响起。

  孙项明回头，只见郭垣正笑嘻嘻地走过来。此人也是散修，修为同样是筑基中期，圆脸小眼，看起来颇为和气。然而此刻，他身上穿着的罩衫却绣着与林家不同的徽记——那是仓央洲另一个小家族，张家的标记。

  "郭道友。"孙项明点点头，态度不冷不热。散修之间，尤其是经常出入这种险地的，哪有什么真正的交情？不过是点头之交罢了。郭垣这种见风使舵，哪家给的好处多就暂时披哪家皮的行为，孙项明见怪不怪。

  "嘿，这次准备往哪边探？"郭垣凑近了些，压低声音，"听说东边的'火鸦涧'最近出了点好东西，几个好手都折在里面了，风险大，但油水也足啊。"

  孙项明心中冷笑，面上不动声色："我自知斤两，还是去老地方'幽石林'碰碰运气。"火鸦涧？那是出了名的死地，郭垣故意提起，不管是有心试探还是单纯想坑人，都其心可诛。

  "幽石林好啊，稳妥！"郭垣一拍大腿，笑得眼睛更眯了，"那咱们……各凭机缘？"他最后四个字咬得有些重。

  "自然。"孙项明不欲多言，转身走向秘境入口的方向。一个巨大的、仿佛被撕裂的山体裂缝，散发出灼热而扭曲的气息，便是午阳山秘境的入口。修士们鱼贯而入，身影消失在翻滚的能量乱流中。

  踏入裂缝的瞬间，天旋地转的感觉骤然袭来。空间的挤压感让孙项明不得不全力运转筑基中期的真元护体。几息之后，脚下一实，那股扭曲感消失，取而代之的是一片截然不同的天地。

  眼前的景象如同被烈焰炙烤后又冷却的焦土。天空是压抑的暗红色，弥漫着终年不散的硫磺云雾。大地是斑驳的暗褐色，裸露着嶙峋的怪石，有些石头缝隙间流淌着粘稠的、冒着细小气泡的岩浆溪流。空气灼热干燥，吸一口都带着火辣辣的感觉。远处，隐约可见倒塌的巨大宫殿废墟轮廓，以及形态扭曲、散发着不祥气息的巨大植物。

  这便是午阳山秘境——一个危险与机遇并存，资源被反复搜刮过无数次的古战场遗迹。对于金丹以上是已经没了价值，但对他们这些筑基散修来说，则是用命换资源的狩猎场。

  孙项明毫不犹豫地激发了匿气符，身形气息迅速变得淡薄模糊，与周围焦灼的环境几乎融为一体。他像一头经验丰富的猎豹，避开开阔地，紧贴着嶙峋怪石的阴影，朝着记忆中的"幽石林"方向移动。

  幽石林位于一片相对外围的区域，得名于那些被奇异力量侵蚀扭曲、如同石笋般林立、表面布满孔洞的黑色怪岩。这里盛产一种伴生于黑石缝隙间的"地火苔"，是炼制低阶火属性丹药的辅料，虽然价值不高，但胜在相对安全且稳定，是孙项明这种"求稳"但又必须冒险获取资源的散修常来的地方。

  一路上并非坦途。岩石阴影下潜伏着巴掌大小、甲壳坚硬如铁、口器能喷射腐蚀性酸液的"蚀骨甲虫"。偶尔有熔岩池翻滚，溅出的炽热液滴足以灼穿护体真元。孙项明精神高度集中，凭借远超同阶修士的神魂感知力，提前预判着危险，或绕行，或用微弱的指风精准击打甲虫的脆弱关节将其击退，尽量避免消耗宝贵的符箓和真元。

  一个时辰后，他才终于抵达幽石林边缘。黑色的怪石林立，如同沉默的森林，石缝间透出星星点点的暗红光芒，正是成熟的地火苔。孙项明心中一振，小心翼翼地开始采集。

  就在他屏息凝神，用特制的玉铲小心翼翼地将一片品相颇佳的、闪烁着殷红光泽的地火苔从石缝中撬起时，一股极其微弱、却冰冷尖锐的杀意陡然从侧后方袭来！

  孙项明神魂猛地刺痛示警！

  他甚至来不及思考，身体的本能先于意识做出了反应！几乎是同时，他猛地拧腰侧扑！

  "嗤！"

  一道乌黑的寒芒擦着他的后心飞过，狠狠钉在他刚才位置前方的黑色怪石上！那石头竟发出一阵令人牙酸的"滋滋"声，被腐蚀出一个冒着黑烟的深坑！

  腐骨钉！好歹毒的低阶法器！

  "郭垣？！"孙项明落地翻滚，瞬间再次激发一张匿气符维持身形模糊，同时厉声喝道。他看到了——就在他刚才采集位置侧后方的几块怪石阴影下，郭垣那张圆脸上再无半点笑意，只剩下冰冷的狰狞和贪婪！

  "哼，反应倒快！"郭垣见偷袭失败，索性不再隐藏，从阴影处走了出来，手中握着一把闪着寒光的淬毒短匕，"可惜，没用！把你身上的物资交出来！还有，告诉我你上次在'断崖'那边找到的玉简藏哪儿了？别以为我不知道你发了笔小财！"

  孙项明心中冰冷，瞬间明白了。郭垣盯上自己不是一天两天了！上次自己在断崖附近意外找到一枚残缺的低阶丹方玉简，还以为无人知晓，没想到这家伙竟然暗中留意了！

  "想要？自己来拿！"孙项明眼中寒光一闪。既然撕破脸，唯有一战！他深知郭垣为人狠辣，绝不会留自己活口。他毫不犹豫地祭出了一柄飞剑，同时暗中扣住了一张遁地符——此地怪石林立，地面坚固，遁地符效果会大打折扣，但也是眼下唯一的逃生手段。

  "找死！"郭垣狞笑一声，短匕化作一道毒蛇般的绿芒，直刺孙项明咽喉！他身形如风，显然也擅长近身缠斗，不打算给孙项明御剑远攻的机会。

  两人瞬间在这片怪石林中激斗起来。孙项明神魂强大，感知敏锐，总能险之又险地避开郭垣刁钻诡谲的毒匕攻击。但他法力不及郭垣浑厚，飞剑品质也差，几次硬碰硬都被震得气血翻腾，只能依靠身法和预判苦苦支撑。匿气符的效果也在剧烈争斗中早已消散。

  "噗！"郭垣找到一个破绽，毒匕划破了孙项明的左臂衣袖，衣裳撕裂，带起一溜血花，却少有痛楚，一阵麻痹感沿着伤口蔓延！

  "哈哈！中了老子的'蛇涎毒'，看你还能撑多久！"郭垣得意大笑，攻势更猛。

  孙项明心中一沉，知道不能再拖。他拼着硬受郭垣一掌，喷出一口鲜血，借助这股冲击力猛地向后倒飞，同时将唯一一张遁地符狠狠拍在地上！

第2章
  "想跑？！"郭垣早有防备，猛地甩手，又是三道乌黑的腐骨钉成品字形激射而出，彻底封死了孙项明所有可能逃脱的方向！

  遁地符的黄光亮起，但显然被此地扭曲的地脉之力干扰，传送效果极其不稳定且生效缓慢！

  眼看三枚致命的毒钉就要及体，生死关头，孙项明怒吼一声，不顾经脉剧痛，将残余的真元疯狂注入飞剑，猛地向地面一块不起眼的、布满裂纹的黑色怪石劈去——他要借助碎石阻挡毒钉！

  轰！

  飞剑斩在怪石上！想象中的碎石飞溅并未出现！

  那块看似脆弱的怪石被飞剑蕴含真元的一击劈中，表面的黑色石皮竟如同腐朽的蛋壳般寸寸碎裂剥落，露出了下面隐藏的东西——一个不足半人高、通体由暗金色不知名金属铸造、表面布满玄奥复杂纹路、散发着古老苍茫气息的微型祭坛！

  更诡异的是，就在石皮碎裂、法坛显露的瞬间，一股沛然莫御的强大吸力猛地从法坛中心爆发出来！这股力量是如此突兀、狂暴，几乎无视了空间规则！

  孙项明距离最近，他那点微弱的遁地符灵光瞬间被这股吸力碾碎！他整个人像被一只无形巨手狠狠攥住，猛地被扯向那法坛中心！

  "什么鬼东西？！"郭垣同样被这突如其来的变故惊呆了，再次射出的三枚腐骨钉也被法坛散逸的吸力扭曲了轨迹，"哆哆哆"地钉在了旁边的石壁上。他惊骇地看着孙项明的身影被疯狂扯向那诡异的金属法坛，而后那法坛便带着孙项明一同消失的无影无踪。

  郭垣咬牙切齿在原地摸索半天，不得其门，又怕孙项明真活着出去乱说，一时间在那乱石林中踌躇不决。

  "该死的！"

  话分两头，孙项明只来得及发出一声短促的惊呼，身体便狠狠撞在了那暗金色的法坛表面！

  因为郭垣毒药已经遍及全身的原因，他几乎没感觉到有什么疼痛，浑身上下几乎没了知觉，要不是借着灵识压制，把毒性压在脖颈以下，想来这会他就该殒命当场了。

  只是如今他浑身浴血，又中了毒，外面还有郭垣在蹲守，若是没有什么机遇估摸着就得交代在这了。

  不过……林家虽然规矩苛刻，不过东西是极好的。一枚解毒丹下肚，含在嘴里稍作炼化便感觉到身上渐渐有了些知觉，而后便可以感受到如今自己糟糕的伤势了……

  不过他已然筑基，如今这些伤痛不过皮外伤，调息几个周天，等体内的毒彻底解了再出去又是一条好汉，反倒是如今眼前的这法坛更需要他提高警惕。

  法坛远看是金属材质，凑近了才发现是表明镀了一层流光，加之表面光滑，这才认作了金属材质。如今细细打量，反倒看不出是什么质地，不过这秘境说是数千年前被强行封印了，这百余年才显露出来，被这些宗门家族占了开发出来，经历过不知道多少年月依旧有这样的神异，不用想也知晓并非凡物。

  孙项明没敢贸然上前，绕着法坛走了几圈，细细打量着可能存在的危险。

  不过以他那点浅显的见识要是能看出门道来那才显得这秘境低了档次。

  半柱香的功夫过去，体内的伤势已经化解了大半，孙项明却依然皱着眉头，远远打量着这祭坛。

  "别看了，小子，上前来，助我摆脱封印，送你一场造化。"一股子意念从祭坛中心传递出来，被孙项明轻易捕获……或者说，这就是冲着他来的。

  "谁！"孙项明身影瞬间暴退出数十丈的距离，已经残破的法剑再次挡在身前，仅剩的神魂凝结起来，准备做殊死一搏。

  不过这样的戒备在那个存在面前似乎依然微不足道，那股子意念依然强势的钻进了孙项明的脑海，并传达着自己的意志。

  "别这么紧张，我要是有恶意你早死了"虽然没有声音，但是孙项明依然感觉得到那存在语气中的慵懒和不屑。

  那存在见孙项明迟迟不敢靠近，似乎颇有些气愤，只是一个念头，孙项明手中的长剑便瞬间脱手，在半空中旋了一圈，当着孙项明的面上下翻飞几下，而后径直超他脖颈刺去。

  孙项明想躲，却发现身体已经完全被禁锢住，分毫不得动弹，只能像个待宰的羔羊，傻愣愣的杵在原地，任人宰割。

  索性，这似乎只是那人的一点玩笑。长剑的寒光在距离他脖颈不过半寸的地方瞬间止住前刺的势头，而后便再次飞回到他都手中，似乎它从未离开过一般。

  "别慌啊，我要杀你比你想的容易的多。"那道意志再次进入他的脑海，那道意念依旧不疾不徐，甚至带上了几分戏谑，像是在嘲弄着孙项明的自不量力。

  "前辈！"孙项明见此形状，利落滑跪叩首，连日里宝贝的不行的长剑被丢在一边。

  打不了，根本打不了，这种自己完全无法反抗的神魂强度起码得元婴往上走，在这种大能面前自己顶了天能迈开腿就得被抹杀。

  如今没有对自己动手只怕是被那祭坛限制住了，若非如此，哪里有的自己如今滑跪的功夫。

  那存在沉默了好一会，似乎是没想到这修行后辈如此识趣，又像是感慨修真界的青黄不接，最后只传一道"上祭坛来"的意念，便暂时没了生息。

  孙项明自然不敢怠慢，弓着腰往前迈步，一直到祭坛上都没敢抬起头来直视祭坛中央的那三人高的小塔。

  "不知如何能帮前辈脱困"孙项明依然低着头，心中念头急转，还想着如何规避可能存在的夺舍之类的行为。

  光看着自己的神魂自然是够不上的，那点强度给人挠痒痒都算是夸耀。

  那前世的记忆？保住本源让祂把前世的部分吞了？说是这种东西都有世界本源的加持，要是被其余人瞧去，指不定有什么妙用。

  不过这只能算是最终手段，要是这位大能破封第一时间就是给自己扬了，那自己也毫无办法。

## 5. 核心代码模块

### 5.1 说话人匹配器 (speaker_matcher.py)

**关键方法**: `match_speaker`

```python
# pipeline/speaker_matcher.py:150-180

def match_speaker(self, context: DialogueContext) -> Optional[SpeakerMatch]:
    """匹配说话人"""
    # 1. 上下文推理
    candidates = self._extract_context_speakers(
        context.text, context.context_before, context.context_after
    )
    
    # 2. NER提取
    ner_speakers = self._extract_ner_speakers(context)
    
    # 3. 角色库匹配
    charlib_speakers = self._match_character_library(context)
    
    # 4. 语义匹配
    semantic_speakers = self._semantic_match(context)
    
    # 5. 触发词匹配
    trigger_speakers = self._trigger_word_match(context)
    
    # 合并所有候选人，按置信度排序
    all_candidates = candidates + ner_speakers + charlib_speakers + ...
    
    if all_candidates:
        best = max(all_candidates, key=lambda x: x.confidence)
        return best
    return None  # 返回未知
```

**候选人生成逻辑**: `_extract_context_speakers`

```python
# pipeline/speaker_matcher.py:468-600

def _extract_context_speakers(self, text, context_before, context_after):
    """从上下文中提取说话人候选"""
    candidates = []
    
    # 步骤1: 冒号前匹配 ("XX道：")
    colon_match = self._match_colon_pattern(context_before)
    if colon_match:
        candidates.append(colon_match)
    
    # 步骤2: NER实体提取（后出现的优先）
    if context_before:
        result = self.nlp.analyze(context_before)
        before_pers = [e for e in result.entities if e.type == 'PER']
        # 扩展复姓实体
        before_pers_expanded = self._expand_surname_entities(context_before, 
            [(e.text, e.type) for e in before_pers])
        for pe_text, pe_type in reversed(before_pers_expanded):
            # 过滤修饰词...
            candidates.append((pe_text, "上下文PER(前)", 0.85))
    
    # 步骤3: 代词消解
    pronoun = self._resolve_pronoun(context_before)
    if pronoun:
        candidates.append(pronoun)
    
    return candidates
```

### 5.2 NLP基础模块 (nlp_basics.py)

**实体完整性修复**: `_expand_single_char_entities`

```python
# pipeline/nlp_basics.py:1088-1119

def _expand_single_char_entities(self, entities: List[Entity], raw_text: str) -> List[Entity]:
    """实体完整性修复：扩展单字NER实体为完整角色名。
    
    通用规则（不依赖特定角色名）：
    1. 检测单字PER实体（在SINGLE_CHAR_SURNAMES中）
    2. 在raw_text中取该单字后一个字符
    3. 若后字符是中文字符，则组合为新实体
    """
    expanded = []
    for ent in entities:
        if len(ent.text) == 1 and ent.type == 'PER' and ent.text in SINGLE_CHAR_SURNAMES:
            char_pos = raw_text.find(ent.text)
            if char_pos != -1 and char_pos + 1 < len(raw_text):
                next_char = raw_text[char_pos + 1]
                if '\u4e00' <= next_char <= '\u9fff':
                    combined_name = ent.text + next_char
                    expanded.append(Entity(text=combined_name, type='PER', ...))
                    continue
        expanded.append(ent)
    return expanded
```

**虚假人名过滤**: `_filter_false_persons`

```python
# pipeline/nlp_basics.py:1035-1085

def _filter_false_persons(self, entities: List[Entity]) -> List[Entity]:
    """过滤HanLP误识别的虚假人名"""
    # 过滤包含副词的实体（如"郭垣正"中的"正"）
    # 过滤包含形容词的实体（如"孙项明真"中的"真"）
    false_person_keywords = ['正', '真', '很', '都', '也', '就', ...]
    filtered = []
    for ent in entities:
        if any(ent.text.endswith(kw) for kw in false_person_keywords):
            # 截断到合理长度
            filtered.append(Entity(text=ent.text[:-1], ...))
        else:
            filtered.append(ent)
    return filtered
```

## 6. 失败类型分析

### 6.1 NER过度识别 (X02, X05, X18)

**问题**: HanLP将描述性短语识别为人名

| 案例 | 原文片段 | 识别结果 | 问题 |
|------|---------|---------|------|
| X02 | "一个面无表情的中年修士" | "无表情的中年修士" | 描述性短语被识别为人名 |
| X05 | "郭垣正笑嘻嘻地走过来" | "郭垣正" | "正"（副词）被包含进人名 |
| X18 | "孙项明真活着出去乱说" | "孙项明真" | "真"（副词）被包含进人名 |

**根因**: 
1. HanLP的NER模型对上下文边界判断不准确
2. `_filter_false_persons`方法存在但可能未正确工作

### 6.2 上下文继承错误 (X03, X14, X15, X16)

**问题**: 连续对话中，说话人切换但系统错误追踪

| 案例 | 上下文 | 期望 | 实际 |
|------|--------|------|------|
| X03 | "管事眼皮都没抬..."+"明白。"+孙项明接过 | 孙项明 | 管事 |
| X14 | 孙项明准备战斗 → "找死！" | 郭垣 | 孙项明 |
| X15 | 郭垣攻击命中 → "哈哈！中了老子的..." | 郭垣 | 孙项明 |
| X16 | 孙项明拍遁地符 → "想跑？！" | 郭垣 | 孙项明 |

**根因**: 
1. 系统没有正确追踪对话轮次切换
2. `_recent_speakers`在活动重置后为空
3. 跨段落的上下文连续性没有被维护

### 6.3 缺少说话人标识 (X04)

**问题**: "哟，老孙！你也来了啊！" 前面只有"一个略显油滑的声音响起。"

**原文**: 
```
"哟，老孙！你也来了啊！"一个略显油滑的声音响起。
```

**根因**: 
- 系统无法从"声音"推断出具体说话人
- 需要声音特征→角色映射（但这是大工程）

### 6.4 代词未解析 (X10)

**问题**: "他最后四个字咬得有些重。"中的"他"没有正确解析

**原文**:
```
"幽石林好啊，稳妥！"郭垣一拍大腿，笑得眼睛更眯了，"那咱们……各凭机缘？"他最后四个字咬得有些重。"自然。"
```

**根因**: 
- 代词"他"应该指向郭垣（前一句主语），但系统解析失败
- 代词消解依赖`recent_speakers`，但当前活动记录中没有

### 6.5 候选优先级错误 (X11)

**问题**: context_before中"郭垣"出现，但说话人是孙项明

**原文**:
```
一道乌黑的寒芒擦着他的后心飞过..."郭垣？！"孙项明落地翻滚...他看到了——就在他刚才采集位置侧后方的几块怪石阴影下，郭垣那张圆脸上再无半点笑意...
```

**根因**: 
- NER实体按`reversed()`顺序处理，后出现的"郭垣"优先级更高
- 但"郭垣？！"是孙项明看到郭垣后的惊呼，说话人应该是孙项明

### 6.6 角色库理解错误 (X19)

**问题**: "一股子意念从祭坛中心传递出来" → 期望"前辈"

**原文**:
```

```

**根因**: 
- 测试集期望的"前辈"角色在角色库中存在
- 但"意念从祭坛中心传递出来"没有明确的说话人标识
- 系统无法推断出"意念"来自"前辈"
