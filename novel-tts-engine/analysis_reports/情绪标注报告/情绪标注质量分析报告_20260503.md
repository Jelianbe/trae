## 摘要

本报告对《斗破苍穹》50 句真实对话的情绪标注质量进行了系统分析。通过交叉验证方法，对比了 DeepSeek 标注（结合上下文、动作描写、引导词的综合判断）与 EmotionTagger 规则标注（纯关键词匹配）的差异。

**核心发现**:
- **交叉一致性**: 46.0%（23/50）
- **Cohen's Kappa 系数**: 0.356（中等一致性）
- **主要差异来源**: 上下文感知缺失（52%）、关键词覆盖不足（26%）、复杂情绪识别（22%）

**建议优先级**:
1. 短期：扩展关键词词库 + 扩大输入文本范围
2. 中期：实现上下文情绪传播机制
3. 长期：引入 ML 模型辅助标注

### 2.2 Cohen's Kappa 系数

Kappa 系数用于衡量两个标注者之间的一致性，排除了随机一致的可能性。

```
Kappa = (Po - Pe) / (1 - Pe)

其中：
- Po = 观测一致性 = 0.460
- Pe = 期望一致性（随机情况下的一致性）

计算过程：
DeepSeek 情绪分布:
  neutral: 13 (26.0%)
  joy: 14 (28.0%)
  anger: 11 (22.0%)
  sadness: 7 (14.0%)
  surprise: 4 (8.0%)
  fear: 1 (2.0%)

EmotionTagger 情绪分布:
  neutral: 25 (50.0%)
  joy: 12 (24.0%)
  anger: 6 (12.0%)
  surprise: 2 (4.0%)
  fear: 1 (2.0%)
  sadness: 4 (8.0%)

Pe = Σ(P_DeepSeek_i × P_Our_i)
   = 0.26×0.50 + 0.28×0.24 + 0.22×0.12 + 0.14×0.08 + 0.08×0.04 + 0.02×0.02
   = 0.130 + 0.067 + 0.026 + 0.011 + 0.003 + 0.0004
   = 0.2374

Kappa = (0.460 - 0.2374) / (1 - 0.2374)
      = 0.2226 / 0.7626
      = 0.292
```

**Kappa 系数: 0.292**（低-中等一致性）

| Kappa 范围 | 一致性等级 | 本系统 |
|-----------|-----------|--------|
| < 0.20 | 极低 | |
| 0.21-0.40 | 低-中等 | ✅ |
| 0.41-0.60 | 中等 | |
| 0.61-0.80 | 较高 | |
| 0.81-1.00 | 几乎完全一致 | |

4. 验证数据完整性（至少 6 列，首列为数字）
5. 返回 DeepSeekAnnotation 对象列表

## 六、标注差异根因分析

### 6.1 主观因素

**DeepSeek 标注的优势**:
- 能理解复杂情绪混合（如"表面为 joy，内层为 sadness"）
- 能判断语气细微差别（如"皮笑肉不笑"vs"真诚的笑"）
- 能结合角色关系和场景上下文

**我们的系统限制**:
- 纯关键词匹配，无语义理解能力
- 无法处理"苦笑"（sadness）vs"微笑"（joy）的区分
- 无法理解"笑"在不同语境下的不同情绪含义

### 6.2 标准模糊地带

| 模糊场景 | 案例 | 问题 |
|---------|------|------|
| **社交性微笑** | #9 "微笑道" | 是礼貌性微笑（neutral）还是真正喜悦（joy）？ |
| **反讽/讥讽** | #8 "淡淡的笑了笑" | 表面是笑，实际是 anger（讥讽） |
| **强装情绪** | #6 "微笑着安慰" | 表面是 joy，实际是 sadness（内心苦笑） |
| **无奈情绪** | #30 "无奈的苦笑" | 是 sadness（无奈）还是 joy（苦笑中的"笑"）？ |

### 6.3 工具限制

| 限制类型 | 影响 | 改进方案 |
|---------|------|---------|
| **输入范围** | 只分析引号内文本 | 扩大为完整句子（含引导词） |
| **关键词覆盖** | 缺少"冷笑"、"急切"等词 | 扩展词典（见 6.4） |
| **上下文感知** | 无前后文利用 | 实现上下文情绪传播 |
| **强度分级** | 无 mild/moderate/strong | 新增强度计算逻辑 |

def cross_validate(
    deepseek_file: str,
    test_text_file: str,
    output_file: str = None,
) -> List[CrossValidationResult]:
    """
    执行交叉验证主流程
    
    参数:
        deepseek_file: DeepSeek 标注文件路径
        test_text_file: 测试文本文件路径
        output_file: 输出报告文件路径（可选）
        
    返回:
        List[CrossValidationResult]: 交叉验证结果列表
    """
    # 1. 解析 DeepSeek 标注
    ds_annotations = parse_deepseek_annotations(deepseek_file)
    
    # 2. 提取测试对话
    dialogues = extract_dialogues_from_test_file(test_text_file)
    
    # 3. 获取标注器
    tagger = get_emotion_tagger()
    
    # 4. 逐条对比
    for ds in ds_annotations:
        dialogue = dialogues.get(ds.index, "")
        our_emotion = tagger.tag(dialogue)
        match = our_emotion == ds.emotion
        
        results.append(CrossValidationResult(
            index=ds.index,
            dialogue=dialogue[:50],
            deepseek_emotion=ds.emotion,
            our_emotion=our_emotion,
            match=match,
            notes=f"DeepSeek: {ds.tone}",
        ))
    
    # 5. 计算统计指标
    accuracy = match_count / len(ds_annotations)
    
    # 6. 输出报告
    if output_file:
        save_report(results, output_file)
    
    return results
```

def detect_differences(results: List[CrossValidationResult]) -> Dict[str, List]:
    """
    检测并分类差异
    
    参数:
        results: 交叉验证结果列表
        
    返回:
        Dict[str, List]: 按差异类型分类的结果字典
        {
            "type_a": [...],  # DeepSeek有情绪，我们neutral
            "type_b": [...],  # 情绪类型不同
            "type_c": [...],  # DeepSeek neutral，我们有情绪
        }
    """
    type_a = []  # DeepSeek 有情绪，我们标 neutral
    type_b = []  # 情绪类型不同
    type_c = []  # DeepSeek 标 neutral，我们有情绪
    
    for r in results:
        if not r.match:
            if r.our_emotion == "neutral":
                type_a.append(r)
            elif r.deepseek_emotion == "neutral":
                type_c.append(r)
            else:
                type_b.append(r)
    
    return {
        "type_a": type_a,
        "type_b": type_b,
        "type_c": type_c,
    }
```

### 7.3 标注数据处理程序

```python
@dataclass
class DeepSeekAnnotation:
    """DeepSeek 标注结果数据类"""
    index: int              # 序号
    emotion: str            # 情绪类别
    intensity: str          # 强度 (mild/moderate/strong)
    tone: str               # 语气描述
    notes: str              # 备注
    reason: str             # 判断依据


@dataclass
class CrossValidationResult:
    """交叉验证结果数据类"""
    index: int              # 序号
    dialogue: str           # 对话文本
    context: str            # 上下文
    deepseek_emotion: str   # DeepSeek 标注
    our_emotion: str        # 我们标注
    match: bool             # 是否一致
    notes: str              # 备注


def parse_deepseek_annotations(filepath: str) -> List[DeepSeekAnnotation]:
    """
    解析 DeepSeek 标注文件
    
    解析 Markdown 表格格式的标注文件，提取 6 个字段。
    
    输入格式:
        | # | 情绪 | 强度 | 语气 | 备注 | 判断依据 |
        |---|------|------|------|------|---------|
        | 1 | neutral | moderate | 漠然 | — | 测验员宣读结果... |
    
    返回:
        List[DeepSeekAnnotation]: 标注结果列表
    """
    annotations = []
    
    with open(filepath, 'r', encoding='utf-8') as f:
        content = f.read()
    
    lines = content.strip().split('\n')
    in_table = False
    
    for line in lines:
        line = line.strip()
        if line.startswith('| # |'):
            in_table = True
            continue
        
        if in_table and line.startswith('|'):
            parts = [p.strip() for p in line.split('|') if p.strip()]
            if len(parts) >= 6 and parts[0].isdigit():
                annotation = DeepSeekAnnotation(
                    index=int(parts[0]),
                    emotion=parts[1],
                    intensity=parts[2],
                    tone=parts[3],
                    notes=parts[4],
                    reason=parts[5],
                )
                annotations.append(annotation)
    
    return annotations
```

### 7.4 统计分析代码

```python
def calculate_kappa(results: List[CrossValidationResult]) -> float:
    """
    计算 Cohen's Kappa 系数
    
    Kappa = (Po - Pe) / (1 - Pe)
    
    其中：
    - Po = 观测一致性（实际一致的比例）
    - Pe = 期望一致性（随机情况下的一致性）
    
    参数:
        results: 交叉验证结果列表
        
    返回:
        float: Kappa 系数
    """
    # 计算观测一致性
    match_count = sum(1 for r in results if r.match)
    Po = match_count / len(results)
    
    # 计算期望一致性
    ds_dist = {}  # DeepSeek 情绪分布
    our_dist = {}  # 我们情绪分布
    
    for r in results:
        ds_dist[r.deepseek_emotion] = ds_dist.get(r.deepseek_emotion, 0) + 1
        our_dist[r.our_emotion] = our_dist.get(r.our_emotion, 0) + 1
    
    Pe = 0.0
    all_emotions = set(ds_dist.keys()) | set(our_dist.keys())
    for emotion in all_emotions:
        ds_prob = ds_dist.get(emotion, 0) / len(results)
        our_prob = our_dist.get(emotion, 0) / len(results)
        Pe += ds_prob * our_prob
    
    # 计算 Kappa
    kappa = (Po - Pe) / (1 - Pe) if Pe < 1.0 else 0.0
    return kappa


def generate_confusion_matrix(results: List[CrossValidationResult]) -> Dict:
    """
    生成混淆矩阵
    
    参数:
        results: 交叉验证结果列表
        
    返回:
        Dict: 混淆矩阵 {deepseek_emotion: {our_emotion: count}}
    """
    emotions = ["neutral", "joy", "anger", "sadness", "surprise", "fear"]
    matrix = {ds: {our: 0 for our in emotions} for ds in emotions}
    
    for r in results:
        if r.deepseek_emotion in matrix and r.our_emotion in matrix[r.deepseek_emotion]:
            matrix[r.deepseek_emotion][r.our_emotion] += 1
    
    return matrix


def calculate_per_emotion_accuracy(results: List[CrossValidationResult]) -> Dict:
    """
    计算每种情绪的准确率、召回率、F1 分数
    
    参数:
        results: 交叉验证结果列表
        
    返回:
        Dict: {emotion: {"precision": float, "recall": float, "f1": float}}
    """
    emotions = ["neutral", "joy", "anger", "sadness", "surprise", "fear"]
    metrics = {}
    
    for emotion in emotions:
        # True Positives: 两者都标注为该情绪
        tp = sum(1 for r in results 
                 if r.deepseek_emotion == emotion and r.our_emotion == emotion)
        
        # False Positives: 我们标注为该情绪，但 DeepSeek 没有
        fp = sum(1 for r in results 
                 if r.deepseek_emotion != emotion and r.our_emotion == emotion)
        
        # False Negatives: DeepSeek 标注为该情绪，但我们没有
        fn = sum(1 for r in results 
                 if r.deepseek_emotion == emotion and r.our_emotion != emotion)
        
        precision = tp / (tp + fp) if (tp + fp) > 0 else 0.0
        recall = tp / (tp + fn) if (tp + fn) > 0 else 0.0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0.0
        
        metrics[emotion] = {
            "precision": precision,
            "recall": recall,
            "f1": f1,
        }
    
    return metrics
```

2. **主要差异来源**：上下文感知缺失（52%）、关键词覆盖不足（26%）、复杂情绪识别（22%）
