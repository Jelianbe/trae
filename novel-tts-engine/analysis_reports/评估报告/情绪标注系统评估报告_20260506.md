# 情绪标注系统评估报告：规则系统 vs LLM Benchmark

**日期**: 2026-05-06  
**测试集**: 50条人工标注对话（都市21 + 西幻10 + 修仙11 + 历史8）  
**评估目标**: 验证 EmotionExtractor 真实 F1，探测情绪标注任务的天花板

---

## 1. 执行摘要

### 关键发现

| 系统 | Macro F1 | 准确率 | 速度 |
|------|---------|--------|------|
| **规则系统 (EmotionExtractor)** | **0.723** | 0.700 | ~0.01s/条 |
| **LLM (Qwen2.5-1.5B-Instruct)** | **0.722** | 0.760 | 1.2s/条 |
| 旧规则系统 (35条GT) | 0.675 | - | ~0.01s/条 |

**结论**：规则系统与 1.5B LLM 的 F1 几乎相同（0.723 vs 0.722），说明情绪标注任务本身存在固有难度，LLM 并未显著优于精心设计的规则系统。

### 过拟合验证

| 测试集 | 规则系统 F1 |
|--------|------------|
| 旧 35 条 GT | 1.000 |
| **新 50 条 GT** | **0.723** |
| 跌幅 | **-0.277** |

**确认**：35 条全对确实是过拟合。扩大测试集后 F1 从 1.000 跌至 0.723。

## 3. 规则系统评估结果

### 3.1 L1 粗分类评估

| 类别 | F1 |
|------|-----|
| neutral | 0.519 |
| excited | 0.809 |
| subdued | 0.692 |
| **Macro F1** | **0.673** |
| **准确率** | **0.700** |

### 3.2 L2 细分类评估

| 类别 | F1 | GT数量 |
|------|-----|--------|
| joy | 0.667 | 10 |
| anger | 0.778 | 10 |
| sadness | 0.667 | 8 |
| surprise | 0.875 | 8 |
| fear | 0.833 | 7 |
| neutral | 0.519 | 7 |
| **Macro F1** | **0.723** |
| **准确率** | **0.700** |

### 3.3 错误分析（17条）

**主要问题**：

1. **情绪强度不足触发 neutral**（11条）
   - "这次让你死无葬身之地！" → GT=anger，预测=neutral
   - "冠军！我们是冠军！" → GT=joy，预测=neutral
   - 规则系统的打分阈值过高，中等强度情绪被归为 neutral

2. **L1 映射错误**（3条）
   - "以神之名，净化你！" → GT=excited/anger，预测=subdued/anger
   - L2 正确但 intensity < 0.6 导致 L1 归为 subdued

3. **L2 分类错误**（3条）
   - "我们竟然真的做到了。" → GT=joy，预测=surprise
   - "快跑！它醒了！" → GT=fear，预测=anger

### 3.4 按文体统计

| 文体 | L2 准确率 |
|------|----------|
| 都市 | 0.762 (16/21) |
| 西幻 | 0.700 (7/10) |
| 修仙 | 0.727 (8/11) |
| **历史** | **0.500 (4/8)** |

历史文体准确率最低，规则对古风/文言表达覆盖不足。

## 4. LLM Benchmark 结果

### 4.1 模型信息

- **模型**: Qwen2.5-1.5B-Instruct
- **参数量**: 1.5B
- **设备**: CPU
- **推理速度**: 1.2s/条

### 4.2 L2 细分类评估

| 类别 | F1 | GT数量 |
|------|-----|--------|
| joy | 0.947 | 10 |
| anger | 0.741 | 10 |
| sadness | 0.824 | 8 |
| surprise | 0.400 | 8 |
| fear | 0.545 | 7 |
| neutral | 0.875 | 7 |
| **Macro F1** | **0.722** |
| **准确率** | **0.760** |

### 4.3 错误分析（12条）

**LLM 主要问题**：

1. **surprise 类别表现最差**（F1=0.400）
   - "天哪！龙竟然复活了！" → GT=surprise，LLM=anger
   - "怎么可能会有这种事？" → GT=surprise，LLM=anger
   - LLM 倾向于将惊讶判断为愤怒

2. **fear 类别次差**（F1=0.545）
   - "别过来！求你别过来！" → GT=fear，LLM=anger
   - "你……你不要过来！" → GT=fear，LLM=anger
   - LLM 将恐惧中的祈使句误判为愤怒

3. **嘲讽类 joy 误判**
   - "哼，就这点本事？" → GT=joy（嘲讽），LLM=anger

## 6. 结论

### 6.1 天花板探测结论

**LLM F1 = 0.722，与规则系统 F1 = 0.723 几乎相同。**

这说明：
1. 情绪标注任务本身存在固有难度，并非规则系统设计问题
2. 1.5B 参数的 LLM 未能显著优于规则系统
3. 更大的 LLM（如 7B、14B）可能会有更好表现，但推理成本更高

### 6.2 规则系统评估

**规则系统在 surprise 和 fear 类别上优于 LLM**：
- surprise: 规则 0.875 vs LLM 0.400
- fear: 规则 0.833 vs LLM 0.545

**规则系统在 joy 和 neutral 类别上弱于 LLM**：
- joy: 规则 0.667 vs LLM 0.947
- neutral: 规则 0.519 vs LLM 0.875

### 6.3 决策建议

根据原定决策规则：

> - 如果扩大测试 F1 > 0.80：规则系统够用，不需要 ML
> - 如果扩大测试 F1 < 0.60：情绪标注是极难任务

当前 F1 = 0.723，落在中间区间（0.60~0.80）。

**建议**：

1. **短期**：继续优化规则系统
   - 降低 neutral 阈值，减少中等情绪被归为 neutral 的情况
   - 补充历史文体的关键词
   - 修复 L1 映射逻辑（高强度愤怒应归为 excited）

2. **中期**：混合方案
   - 规则系统处理 surprise、fear（规则优势）
   - LLM 处理 joy、neutral（LLM 优势）
   - anger 两者相当，用规则（速度快）

3. **长期**：如果需要更高精度
   - 尝试更大的 LLM（Qwen2.5-7B）
   - 或 BERT fine-tune（需要更多标注数据）
