## 2. 问题诊断

### 2.1 原始问题

根据初始评估报告，规则系统存在以下问题：

1. **neutral 是木桶最短的板**（F1 = 0.519）
   - neutral 只有负向兜底规则（"低于 0.35 归 neutral"）
   - 缺少正向特征，导致其他情绪得分不足时落入 neutral

2. **情绪强度阈值过高**（11条错误）
   - "这次让你死无葬身之地！" → GT=anger，预测=neutral
   - "冠军！我们是冠军！" → GT=joy，预测=neutral
   - 关键词覆盖不足，中等强度情绪被归为 neutral

3. **L1 映射阈值不合理**（3条错误）
   - anger 的 L1 映射阈值 0.6 过高
   - 中等强度愤怒被归为 subdued 而非 excited

### 2.2 错误分布

| 问题类型 | 数量 | 示例 |
|---------|------|------|
| 情绪强度不足触发 neutral | 11 | "死无葬身之地" → neutral |
| L1 映射错误 | 3 | "净化你！" → subdued/anger |
| L2 分类错误 | 3 | "快跑！它醒了！" → anger |

## 3. 优化措施

### 3.1 关键词扩展

#### anger 愤怒关键词

```python
# 威胁/诅咒类愤怒
if re.search(r'(死无葬身之地|自寻死路|找死|活腻|不得好死|碎尸万段|千刀万剐)', text):
    scores['anger'] += 0.5

# 叛逆/背叛类愤怒
if re.search(r'(背叛|叛徒|逆贼|谋反|造反)', text):
    scores['anger'] += 0.4

# 仇恨类愤怒
if re.search(r'(恨|仇恨|仇人|仇家|血债|血海深仇)', text):
    scores['anger'] += 0.4
```

#### fear 恐惧关键词

```python
# 求饶类恐惧
if re.search(r'(饶命|求饶|饶了我|放过|不要杀|别杀|救命|求求)', text):
    scores['fear'] += 0.5

# 危险/威胁类恐惧
if re.search(r'(危险|快跑|逃命|躲开|小心)', text):
    scores['fear'] += 0.4
```

#### sadness 悲伤关键词

```python
# 失去/离别类悲伤
if re.search(r'(最后一面|见不到|回不去|再也见|永别|死别|生离)', text):
    scores['sadness'] += 0.5

# 遗憾/后悔类悲伤
if re.search(r'(遗憾|后悔|来不及|没能|本该|早知道)', text):
    scores['sadness'] += 0.4

# 哭泣类悲伤
if re.search(r'(哭|泪|泣|泪流|泪如|泪下|落泪|掉泪)', text):
    scores['sadness'] += 0.4

# 亲人称呼 + 语气词
if re.search(r'(我的儿|我的孩|我的女|我的妻|我的夫|儿啊|孩儿|女儿啊)', text):
    scores['sadness'] += 0.5

# 放手/成全类悲伤
if re.search(r'(走吧|放手|成全|趁我|别管我)', text):
    scores['sadness'] += 0.3
```

#### joy 喜悦关键词

```python
# 胜利/成就类喜悦
if re.search(r'(冠军|胜利|赢了|成功|终于|梦寐以求|喜事|好消息)', text):
    scores['joy'] += 0.5

# 庆祝/祝福类喜悦
if re.search(r'(恭喜|祝贺|庆祝|万岁|干杯|庆祝)', text):
    scores['joy'] += 0.4

# 幸福/满足类喜悦
if re.search(r'(幸福|满足|开心|高兴|快乐|美好)', text):
    scores['joy'] += 0.4
```

#### surprise 惊讶关键词

```python
# "难道...真的"类惊讶
if re.search(r'(难道|怎会|怎可能|怎么可能)', text):
    scores['surprise'] += 0.4

# "真的" + 省略号/问号
if re.search(r'真的[……?？]', text):
    scores['surprise'] += 0.3
```

### 3.2 L1 映射阈值调整

```python
# 优化前
if emotion_label == 'anger':
    return 'excited' if intensity >= 0.6 else 'subdued'

# 优化后
if emotion_label == 'anger':
    # 愤怒本质是激烈情绪，阈值从 0.6 降到 0.4
    return 'excited' if intensity >= 0.4 else 'subdued'
```

## 5. 剩余问题分析

### 5.1 剩余 3 条错误

| ID | 对话 | GT | 预测 | 问题 |
|----|------|-----|------|------|
| emo_019 | 你终于回来了。 | subdued/joy | neutral/neutral | 句子太短，无感叹号 |
| emo_020 | 我们竟然真的做到了。 | excited/joy | excited/surprise | "竟然"权重过高 |
| emo_043 | 快跑！它醒了！ | excited/fear | excited/anger | 祈使句触发 anger |

### 5.2 问题根因

1. **emo_019**: "终于"作为喜悦关键词，但句子无感叹号、句号结尾，neutral 得分过高
2. **emo_020**: "竟然"是惊讶关键词，但此处表达的是"惊喜"，joy 和 surprise 边界模糊
3. **emo_043**: "快跑"是祈使句，触发 anger 规则，但实际是恐惧场景

### 5.3 改进建议

1. **emo_019**: 降低 neutral 的句号结尾加分，或增加"终于"的 joy 权重
2. **emo_020**: 考虑"竟然 + 做到/成功"组合作为 joy 信号
3. **emo_043**: 增加"它 + 醒了/来了"作为 fear 场景的上下文判断
