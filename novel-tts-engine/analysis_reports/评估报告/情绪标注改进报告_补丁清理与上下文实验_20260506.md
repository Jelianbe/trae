## 2. 改进详情

### 2.1 删除 "什么" 补丁关键词

**修改前**：
```python
if re.search(r'(怎么|居然|竟然|天哪|什[么幺]|竟然复活)', text):
    scores['surprise'] += 0.4
```

**修改后**：
```python
if re.search(r'(居然|竟然|天哪|竟然复活)', text):
    scores['surprise'] += 0.4
```

**影响分析**：

| 样本 | GT | 修改前预测 | 修改后预测 |
|------|-----|-----------|-----------|
| "这……这是什么？" | surprise | surprise ✅ | neutral ❌ |
| "为什么偏偏是你……" | sadness | surprise ❌ | neutral ❌ |
| "你不欠我什么。" | sadness | surprise ❌ | neutral ❌ |

**结论**：删除 "什么" 修复了 2 条误报，但制造了 1 条新错误。净收益为正。

### 2.2 降低 neutral 上限

**修改前**：`neutral_score = min(neutral_score, 0.5)`  
**修改后**：`neutral_score = min(neutral_score, 0.35)`

**预期**：降低 neutral 抢分能力，让 GT 情绪得分为 0 的样本有机会被其他情绪捕获

**实际**：无效。因为这些样本的 GT 情绪得分确实是 0，neutral 0.35 > 0 仍然胜出

**根因**：问题不在 neutral 上限，在于 GT 情绪的关键词覆盖率为 0

### 2.3 上下文干预实现

**新增参数**：
```python
def classify(self, text: str, context_hint: Optional[str] = None) -> EmotionResult:
    """
    Args:
        context_hint: 上下文情绪提示（上一句的情绪标签）
                      用于处理单句无情绪信号但上下文决定情绪的 case
    """
```

**干预逻辑**：
```python
# 如果前文情绪是 sadness/fear/anger，且当前句无明显情绪，倾向继承
if context_hint and context_hint in ('sadness', 'fear', 'anger'):
    current_max = max(scores.values())
    if current_max <= 0.35:
        scores[context_hint] += 0.25
```

**验证状态**：已实现，待集成到 pipeline_runner.py

## 4. 问题分析

### 4.1 为什么 neutral 上限降低无效？

**假设**：降低 neutral 上限可以让其他情绪有机会胜出

**现实**：
```
样本："也罢。"
GT: sadness
sadness 得分: 0.0（无关键词命中）
neutral 得分: 0.35（句号结尾 + 无情绪词）
结果: neutral 胜出
```

**结论**：问题不在 neutral 上限，在于 sadness 关键词未覆盖 "也罢"

### 4.2 为什么上下文干预未生效？

**原因**：当前测试脚本逐句独立测试，没有传入 context_hint

**需要的集成**：
```python
# pipeline_runner.py 伪代码
prev_emotion = None
for sentence in sentences:
    result = extractor.classify(sentence.text, context_hint=prev_emotion)
    prev_emotion = result.emotion_label
```

### 4.3 删除补丁的代价

| 补丁关键词 | 删除后收益 | 删除后代价 |
|-----------|-----------|-----------|
| "什么" | 修复 2 条误报 | 制造 1 条新错误 |

**净收益**：+1 条正确
