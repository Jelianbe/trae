# 数据库表约束优化报告

## 问题描述

### Issue: 表创建缺少完整性约束

**问题**: `_ensure_tables` 方法中的表定义缺少 CHECK 约束和必要的列

**原代码**:
```sql
CREATE TABLE IF NOT EXISTS characters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    aliases TEXT,
    gender TEXT DEFAULT 'unknown',
    first_appearance INTEGER,
    activity_weight REAL DEFAULT 1.0,
    vector BLOB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

**问题分析**:
1. `gender` 列缺少 CHECK 约束，可能插入无效值
2. `activity_weight` 列缺少范围约束，可能插入越界值
3. `is_confirmed` 列缺失，与 `schema.sql` 不一致

## 修复方案

### 添加完整性约束，与 schema.sql 保持一致

```sql
CREATE TABLE IF NOT EXISTS characters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    aliases TEXT,
    gender TEXT DEFAULT 'unknown' CHECK(gender IN ('male', 'female', 'unknown')),
    first_appearance INTEGER,
    activity_weight REAL DEFAULT 1.0 CHECK(activity_weight >= 0 AND activity_weight <= 10.0),
    is_confirmed INTEGER DEFAULT 1,
    vector BLOB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

### 迁移兼容处理

对于已存在的表，使用 ALTER TABLE 添加缺失的列和约束：

```python
try:
    cursor.execute("ALTER TABLE characters ADD COLUMN activity_weight REAL DEFAULT 1.0 CHECK(activity_weight >= 0 AND activity_weight <= 10.0)")
except sqlite3.OperationalError:
    pass
try:
    cursor.execute("ALTER TABLE characters ADD COLUMN is_confirmed INTEGER DEFAULT 1")
except sqlite3.OperationalError:
    pass
```

## 约束说明

### CHECK 约束

| 列名 | 约束 | 说明 |
|------|------|------|
| gender | `CHECK(gender IN ('male', 'female', 'unknown'))` | 限制性别只能为预设值 |
| activity_weight | `CHECK(activity_weight >= 0 AND activity_weight <= 10.0)` | 活动权重必须在 0-10 范围内 |

### 新增列

| 列名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| is_confirmed | INTEGER | 1 | 角色是否已确认 |
