## 问题概述

### Issue 1: LIKE转义函数转义逻辑错误 ✓

**问题位置**: `pipeline/character_manager.py#L196-202`

**问题描述**: `_escape_like_pattern` 函数中转义顺序错误，导致反斜杠转义不正确

**原代码**:
```python
return pattern.replace('%', r'\%').replace('_', r'\_').replace('\\', r'\\')
```

**问题分析**:
- 最后执行 `replace('\\', r'\\')` 会将之前转义的 `\%` 和 `\_` 中的反斜杠再次转义
- 例如：输入 `100%` → `100\%` → `100\\%`（错误）

**修复后**:
```python
def _escape_like_pattern(self, pattern: str) -> str:
    """
    转义 LIKE 查询中的特殊字符
    
    SQLite LIKE 查询中，% 和 _ 是通配符，需要转义
    必须先转义反斜杠本身，然后再转义其他特殊字符
    """
    return pattern.replace('\\', r'\\').replace('%', r'\%').replace('_', r'\_')
```

**转义顺序说明**:

| 步骤 | 输入 | 操作 | 输出 |
|------|------|------|------|
| 1 | `100%` | 转义 `\` → `\\` | `100%` (无变化) |
| 2 | `100%` | 转义 `%` → `\%` | `100\%` (正确) |
| 3 | `100\%` | 转义 `_` → `\_` | `100\%` (无变化) |

**错误修复前**:

| 步骤 | 输入 | 操作 | 输出 |
|------|------|------|------|
| 1 | `100%` | 转义 `%` → `\%` | `100\%` |
| 2 | `100\%` | 转义 `_` → `\_` | `100\%` (无变化) |
| 3 | `100\%` | 转义 `\` → `\\` | `100\\%` (错误！) |
