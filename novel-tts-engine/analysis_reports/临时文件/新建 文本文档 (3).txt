## 第一步：重构 neutral 正向特征

你当前的 neutral 逻辑是纯负向兜底——所有情绪得分都不够高就扔进 neutral。这导致 neutral 变成了垃圾桶。

正确做法：给 neutral 独立的特征体系，让它和其他六种情绪公平竞争。

### 修改位置

`pipeline/emotion_extractor.py` 的 `classify()` 方法中，在现有各情绪加分逻辑之前，先构建 neutral 的正向特征。

### 具体修改

```python
# === 新增：neutral 正向特征（在其他情绪加分之前执行） ===
# 原则：neutral 不是垃圾桶。它有自己的文本特征。
# 1. 句号结尾 + 无感叹号 → 平静信号
# 2. 句子长度适中 → 日常对话特征
# 3. 无情绪词命中 → 缺少情绪表达
# 4. 日常词汇命中 → 问候/事务/陈述

neutral_score = 0.0

# 信号1：句号结尾，且无感叹号/问号
if text.endswith('。') or text.endswith('.') or text.endswith('）') or text.endswith(') '):
    if features.exclamation_count == 0 and features.question_count == 0:
        neutral_score += 0.35

# 信号2：句子长度在正常范围（6-25字），无情绪标点
char_count = len(text)
if 6 <= char_count <= 25 and features.exclamation_count == 0:
    neutral_score += 0.20

# 信号3：无任何情绪词命中
has_any_emotion_word = (
    features.has_dirty_words or 
    features.has_emotion_verb or 
    features.has_emotion_adverb or
    features.is_exclamatory or
    features.is_rhetorical or
    features.is_imperative or
    features.has_repetition
)
if not has_any_emotion_word:
    neutral_score += 0.25

# 信号4：日常词汇命中（问候、事务、陈述类）
neutral_daily_words = [
    '吃饭', '天气', '走吧', '回去', '茶叶', '柜子', '卷宗', '路口',
    '退下', '告辞', '遵旨', '奏', '清单', '采买', '宴席', '路',
    '知道', '明白', '了解', '确定', '安排', '准备', '按你说的',
    '姓', '名', '单名', '可曾', '未曾', '可否',
]
for word in neutral_daily_words:
    if word in text:
        neutral_score += 0.08
        break  # 命中一个即可，避免堆叠

# 信号5：省略号出现在句末但无恐惧/悲伤语境
# （"我知道了……" 类模糊中性）
if features.ellipsis_count >= 1 and features.ellipsis_count <= 2:
    if not (features.has_emotion_verb or features.has_dirty_words):
        neutral_score += 0.10

# 归一化 neutral 分数
neutral_score = min(neutral_score, 0.85)

# 写入 scores（覆盖原有的兜底 0.3）
scores['neutral'] = neutral_score
```

### 关键变化

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| neutral 分数来源 | 固定 0.3 兜底 | 动态 0.0-0.85，由特征决定 |
| 句号结尾 | 无处理 | +0.35（无感叹号/问号时） |
| 句子长度 | 无处理 | +0.20（6-25字且无感叹号） |
| 无情绪词 | 无处理 | +0.25 |
| 日常词汇 | 无处理 | +0.08 |
| 短省略号 | 无处理 | +0.10 |

### neutral 的决策逻辑变化

```
修改前：
  所有情绪得分不足 → 归 neutral（垃圾桶）

修改后：
  neutral 有自己的得分 → 和其他 6 类公平竞争
  谁的分数高就是谁
  neutral 可以"赢"，也可以"输"
```

当前 `best_score <= 0.35` 归 neutral。这个阈值在旧逻辑下是合理的（没信号就归 neutral），但在新逻辑下 neutral 已经有了正向得分，需要调整。

```python
# 修改前
if best_score <= 0.35:

# 修改后

if best_score <= 0.25:
    return 'neutral', 0.3
```
