# 说话人识别流程改进方案

> **文档日期**: 2026-05-09
> **目的**: 优化说话人识别流程，解决当前实现中的逻辑缺陷
> **适用范围**: NovelTTS Cloud Pipeline 说话人匹配模块

---

## 一、问题背景

### 1.1 当前问题

当前说话人识别流程存在以下问题：

1. **未区分对话和旁白**：对整句进行 NER 分析，导致对话内容中的角色也被误识别为说话人
2. **缺乏角色库优先机制**：用户预设的角色库没有被优先使用
3. **锁定角色未发挥作用**：用户手动锁定的重要角色在匹配中没有获得优先级

### 1.2 问题示例

```
输入：「萧炎，你这丹药炼得如何？」药老捋着胡须问道。

当前错误流程：
  步骤 1：对整句做 NER → 识别到"萧炎"、"药老"  ← 错误！
  步骤 2：两个角色都作为候选说话人  ← 错误！
  结果：可能误判"萧炎"是说话人

正确流程：
  步骤 1：区分对话（引号内）和旁白
    → 对话："萧炎，你这丹药炼得如何？"  → 丢弃，不分析
    → 旁白：药老捋着胡须问道。          → 只分析这个
  
  步骤 2：在旁白中优先匹配角色库（锁定角色优先）
    → 检查角色库是否有"药老" → 找到 → 匹配成功
  
  步骤 3：如果角色库没找到，再走 NER
    → NER 识别旁白中的 PER 实体
    → 创建新角色
  
  结果：正确识别"药老"为说话人
```

## 二、改进方案

### 2.1 核心设计原则

| 原则 | 说明 |
|------|------|
| **只分析旁白** | 说话人识别只针对旁白内容，对话内容（引号内）不参与识别 |
| **角色库优先** | 在旁白中识别到人名后，优先匹配角色库中的角色 |
| **锁定角色最高优先** | 用户锁定的角色在匹配时获得最高优先级 |
| **NER 作为兜底** | 角色库匹配失败时，才使用 NER 自动创建新角色 |

### 2.2 新流程设计

```
输入句子：「对话内容」旁白描述说话动作。

步骤 1：区分对话和旁白
  → 使用引号模式识别对话内容
  → 分离出旁白内容

步骤 2：在旁白中匹配角色库
  → 检查锁定角色是否在旁白中出现
  → 如果匹配，返回高置信度结果（0.95）
  → 检查普通角色是否在旁白中出现
  → 如果匹配，返回正常置信度结果（0.85）

步骤 3：如果角色库没找到，走 NER 兜底
  → 对旁白做 NER 分析，提取 PER 实体
  → 创建新角色并返回

步骤 4：如果 NER 也没找到，使用默认逻辑
  → 代词解析、触发词匹配等
```

### 2.3 置信度体系

| 匹配类型 | 置信度 | 说明 |
|---------|--------|------|
| 锁定角色旁白匹配 | 0.95 | 用户锁定 + 旁白中识别 |
| 普通角色旁白匹配 | 0.85 | 角色库中已有角色 |
| NER 自动创建 | 0.70 | 系统自动识别新角色 |
| 代词解析 | 0.60 | 基于上下文代词推断 |
| 触发词匹配 | 0.50 | 基于触发词推断 |

```python
def _extract_context_speakers(
    self,
    text: str,
    context_before: str,
    context_after: str
) -> List[Tuple[str, str, float]]:
    """
    从上下文提取说话人候选。
    
    改进：只分析旁白内容，角色库优先匹配
    """
    candidates = []
    seen_names = set()
    
    # 步骤 1：分离对话和旁白
    narration = self._extract_narration(text, context_before, context_after)
    if not narration:
        return [('未知', '无旁白内容', 0.30)]
    
    # 步骤 2：优先匹配角色库（锁定角色优先）
    locked_result = self._match_from_character_library(narration, locked_only=True)
    if locked_result:
        candidates.append((locked_result.name, '锁定角色旁白匹配', 0.95))
        seen_names.add(locked_result.name)
    
    # 步骤 3：匹配普通角色库
    normal_result = self._match_from_character_library(narration, locked_only=False)
    if normal_result and normal_result.name not in seen_names:
        candidates.append((normal_result.name, '角色库旁白匹配', 0.85))
        seen_names.add(normal_result.name)
    
    # 步骤 4：NER 兜底（只在角色库匹配失败时使用）
    if not candidates:
        ner_candidates = self._extract_from_ner(narration)
        candidates.extend(ner_candidates)
    
    # 步骤 5：兜底
    if not candidates:
        candidates.append(('未知', '无充分证据', 0.30))
    
    return candidates

def _extract_narration(
    self,
    text: str,
    context_before: str,
    context_after: str
) -> str:
    """
    从文本中提取旁白内容（去除引号内的对话）。
    """
    # 移除所有引号内的对话内容
    import re
    narration = re.sub(r'[「"『].*?[」"』]', '', text)
    narration = re.sub(r'[「"『].*?[」"』]', '', context_before)
    narration = re.sub(r'[「"『].*?[」"』]', '', context_after)
    return narration.strip()

def _match_from_character_library(
    self,
    narration: str,
    locked_only: bool = False
) -> Optional[Character]:
    """
    在旁白中匹配角色库。
    
    Args:
        narration: 旁白内容
        locked_only: 是否只匹配锁定角色
    
    Returns:
        匹配的角色，或 None
    """
    if locked_only:
        characters = self.char_manager.get_locked_characters(self._current_project_id)
    else:
        characters = self.char_manager.list_characters(self._current_project_id)
    
    for char in characters:
        # 精确匹配角色名
        if char.name in narration:
            return char
        
        # 匹配别名
        for alias in char.aliases:
            if alias in narration:
                return char
    
    return None

def _extract_from_ner(self, narration: str) -> List[Tuple[str, str, float]]:
    """
    使用 NER 从旁白中提取人名（兜底方案）。
    """
    candidates = []
    try:
        result = self.nlp.analyze(narration)
        pers = [e for e in result.entities if e.type == 'PER']
        for pe in pers:
            if not self.name_validator.is_valid(pe.text):
                continue
            char = self.char_manager.get_character_by_name(pe.text, self._current_project_id)
            if char:
                candidates.append((char.name, 'NER角色库匹配', 0.80))
            else:
                new_char = self.char_manager.find_or_create(
                    pe.text, self._current_project_id,
                    first_appearance=self._current_chapter_id
                )
                candidates.append((new_char.name, 'NER自动创建', 0.70))
    except Exception as e:
        logger.debug(f"NER 分析失败: {e}")
    
    return candidates
```

### 3.3 CharacterManager 新增方法

```python
def lock_character(self, char_id: int, project_id: str = '') -> bool:
    """锁定角色"""
    with self._get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute(
            "UPDATE characters SET is_locked = 1, updated_at = CURRENT_TIMESTAMP WHERE id = ?",
            (char_id,)
        )
        conn.commit()
        return cursor.rowcount > 0

def unlock_character(self, char_id: int, project_id: str = '') -> bool:
    """解锁角色"""
    with self._get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute(
            "UPDATE characters SET is_locked = 0, updated_at = CURRENT_TIMESTAMP WHERE id = ?",
            (char_id,)
        )
        conn.commit()
        return cursor.rowcount > 0

def get_locked_characters(self, project_id: str = '') -> List[Character]:
    """获取所有锁定角色"""
    with self._get_connection() as conn:
        cursor = conn.cursor()
        cursor.execute(
            "SELECT id, name, aliases, gender, first_appearance FROM characters "
            "WHERE project_id = ? AND is_locked = 1",
            (project_id,)
        )
        return [Character(
            id=row[0], name=row[1], aliases=set(json.loads(row[2])) if row[2] else set(),
            gender=row[3] or "unknown", first_appearance=row[4]
        ) for row in cursor.fetchall()]
```

## 五、预期效果

### 5.1 改进前 vs 改进后

| 场景 | 改进前 | 改进后 |
|------|--------|--------|
| 「萧炎，你这丹药炼得如何？」药老捋着胡须问道。 | 可能误判"萧炎"为说话人 | 正确识别"药老"为说话人 |
| 用户锁定"萧炎"角色 | 锁定不生效 | 锁定角色优先匹配 |
| 角色库中有"药老" | NER 可能创建重复角色 | 直接匹配角色库，避免重复 |
| 新角色出现 | NER 识别 | NER 兜底识别（角色库未匹配时） |

### 5.2 关键指标

| 指标 | 目标 |
|------|------|
| 说话人识别准确率 | 从 70% → 85%+ |
| 重复角色创建率 | 从 15% → <5% |
| 锁定角色匹配率 | 100%（如果锁定角色在文本中） |
| 误判率（对话内容被识别为说话人） | 从 20% → <2% |
