## 二、任务分解与实施顺序

### T-016: 实体链接模块

**优先级**: P0  
**预估工作量**: 半天  
**依赖**: T-007（CharacterManager 已完成）

#### 2.1 问题定义

当前 NER 输出存在三类问题：

| 问题类型 | 示例 | 影响 |
|---------|------|------|
| 单字人名误检 | "苏"、"张" | 降低精确率 |
| 非标准称呼 | "张总"、"赵大哥" | 候选池膨胀 |
| 变体未归一 | "苏夜" vs "苏先生" | 同一角色被当成多个 |

#### 2.2 功能设计

**核心逻辑**:
```python
class EntityLinker:
    """实体链接器：将 NER 输出链接到角色库中的标准角色"""
    
    def link(self, entities, text, char_manager):
        """
        1. 过滤单字人名（长度 < 2 的 PER 实体）
        2. 检查实体是否在角色库中（标准名或别名）
        3. 不在角色库中的实体，判断是否为非角色称呼
        4. 返回链接后的实体列表（带 standard_name 字段）
        """
```

**处理流程**:

```
NER 输出实体列表
  ↓
过滤单字 PER（长度 < 2）
  ↓
角色库匹配：标准名 or 别名
  ├── 匹配成功 → 标记 standard_name，置信度提升至 0.8+
  └── 匹配失败 → 进入下一步
判断是否为非角色称呼
  ├── "XX总"、"XX哥"、"XX姐" → 尝试提取核心人名后再次匹配
  └── 无法识别 → 降级置信度至 0.3（后续被过滤）
返回链接后列表
```

#### 2.3 调用位置

在 `evaluate_generalization_v3.py` 的 `evaluate_ner()` 函数中，串联在 SpeakerRoleFilter 之后：

```python
def evaluate_ner(text, ground_truth):
    nlp = get_nlp()
    result = nlp.analyze(text)
    
    # 第一层：上下文多样性验证
    validator = get_context_validator(mode='speaker_role', ...)
    validated = validator.validate(result.entities, text)
    
    # 第二层：说话角色过滤器
    role_filter = SpeakerRoleFilter(...)
    role_entities = role_filter.filter(validated, text, nlp)
    
    # 第三层：实体链接（新增）

    linked_entities = linker.link(role_entities, text, char_manager)

    ...
```

|------|-------|

### T-017: 角色聚类模块

**优先级**: P0  
**预估工作量**: 1-2 天  
**依赖**: T-007（CharacterManager 已完成）

#### 3.1 问题定义

西幻文本中同一角色有多种称呼，导致：

| 角色 | 变体 | 问题 |
|------|------|------|
| 艾德温 | "艾德温"、"艾德温骑士"、"年轻的骑士" | 各自独立，频次被拆分 |
| 伊莉雅 | "伊莉雅"、"魔法伊莉雅" | 每个变体都被 ContextDiversityValidator 降级 |
| 加尔文 | "加尔文"、"骑士长加尔文" | 同上 |

**核心洞察**: 聚类的判断依据不是实体名字长什么样，而是它们出现的上下文语义有多相似。"轩儿"和"林轩"字面上完全不同，但在小说中出现的位置几乎总是相同的语境——BGE-small 编码这些上下文后，向量会高度接近。

#### 3.3 性能估算

| 指标 | 值 |
|------|-----|
| 500 万字小说候选实体数 | ~200 个 |
| 每实体上下文数 | 5-10 条 |
| 总编码量 | 2000 条以内 |
| BGE-small CPU 编码时间 | 秒级 |
| 相似度计算 | 200×200÷2 = 2 万次，毫秒级 |

#### 3.4 边界情况处理

| 情况 | 处理策略 |
|------|---------|
| 两个不同角色共享相似上下文（如"林轩"和"林天豪"都在林家场景） | 加入字面相似度辅助信号，姓氏重叠、长度差异提供区分度 |
| 实体出现次数极少（1 次） | 不参与聚类，保持独立 |
| 聚类结果不确定（0.5~0.85 相似度） | 标记为"待用户确认"，前端可展示让用户决定 |

## 五、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| BGE-small 编码速度慢 | 性能下降 | 限制上下文窗口大小，只取前后 50 字符 |
| 聚类阈值不当 | 误合并或漏合并 | 先用都市文本调参，再用西幻验证 |
| 实体链接过度过滤 | 召回率下降 | 保留置信度 0.3-0.5 的实体用于调试 |
| 角色库为空时行为 | 崩溃 | 添加空库保护，回退到原始逻辑 |
