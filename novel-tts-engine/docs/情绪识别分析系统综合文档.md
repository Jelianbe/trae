## 1.3 三层标注体系

| 层级 | 名称 | 类别 | 用途 | 消费者 |
|------|------|------|------|--------|
| L1 | 粗分类 | `neutral`, `excited`, `subdued` | 规则系统训练目标 | 内部统计 |
| L2 | 细分类 | `joy`, `anger`, `sadness`, `surprise`, `fear`, `neutral`, `unknown` | 主情绪标签 | TTS 引擎 |
| L3 | 情感向量 | 8维向量 | Index-TTS 直接消费 | Index-TTS |

### L3 8维情感向量定义

```
[happiness, anger, sadness, fear, disgust, melancholy, surprise, calm]
  [0]        [1]     [2]       [3]     [4]        [5]          [6]       [7]
```

### L2 → L1 映射规则

```
neutral   → neutral（无论强度）
unknown   → neutral（无论强度）
sadness   → subdued（无论强度）
fear      → subdued（无论强度）
anger     → excited（intensity >= 0.4）/ subdued（intensity < 0.4）
joy       → excited（intensity >= 0.4）/ neutral（intensity < 0.4）
surprise  → excited（intensity >= 0.4）/ neutral（intensity < 0.4）
```

### L2 → L3 向量映射

```python
joy      → [confidence*intensity, 0, 0, 0, 0, 0, 0, 0]
anger    → [0, confidence*intensity, 0, 0, 0, 0, 0, 0]
sadness  → [0, 0, confidence*intensity, 0, 0, confidence*intensity*0.3, 0, 0]
fear     → [0, 0, confidence*intensity*0.2, confidence*intensity, 0, 0, 0, 0]
surprise → [0, 0, 0, 0, 0, 0, confidence*intensity, 0]
neutral  → [0, 0, 0, 0, 0, 0, 0, 1.0]
unknown  → [0, 0, 0, 0, 0, 0, 0, 1.0]  # 等同于 calm
```

### 2.1.7 引导词情绪加分（**[本次修改] 新增**）

```python
def _apply_guide_phrase_bonus(self, text: str, scores: Dict[str, float]) -> None:
    """引导词情绪加分：基于引导词内容给对应情绪加分
    
    引导词是紧邻对话引号的动词短语，通常是作者直接给出的情绪提示，
    应作为强信号（加分幅度高于普通关键词匹配）。
    """
    guide_phrase = self._extract_guide_phrase(text)
    if not guide_phrase:
        return
    
    special = self._check_special_laughter(guide_phrase)
    if special:
        scores[special] += 0.5
        return
    
    if '怒' in guide_phrase or '骂' in guide_phrase or '吼' in guide_phrase:
        scores['anger'] += 0.4
    elif '哭' in guide_phrase or '叹' in guide_phrase or '泣' in guide_phrase:
        scores['sadness'] += 0.4
    elif '笑' in guide_phrase:
        if '微' in guide_phrase or '轻' in guide_phrase:
            scores['neutral'] += 0.2
        else:
            scores['joy'] += 0.3
    elif '喊' in guide_phrase or '叫' in guide_phrase or '嚷' in guide_phrase:
        scores['surprise'] += 0.3
    elif '问' in guide_phrase:
        scores['surprise'] += 0.2
```

### 2.1.8 unknown 判定逻辑（**[本次修改] 新增**）

```python
# unknown 判定：所有情绪得分 <= 阈值 且无引导词加分
# unknown 表示"无法判断情绪类型"，不等于"中性"
# 如果 best_emotion 已经是 neutral（有正向特征支持），保持 neutral
if len(text) == 0:
    best_emotion = 'neutral'
    best_score = 0.3
elif best_score <= UNKNOWN_SCORE_THRESHOLD and len(text) >= UNKNOWN_MIN_TEXT_LENGTH:
    # 只在 best_emotion 不是 neutral 时才判定为 unknown
    # neutral 本身就是一种明确的情绪判断，不需要转为 unknown
    if best_emotion != 'neutral':
        best_emotion = 'unknown'
        best_score = 0.3
```

## 2.2 情绪提取流程

```
原始文本
  │
  ▼
extract_features(text)
  ├─ 标点统计（感叹号、问号、省略号）
  ├─ 句式检测（感叹句、反问句、祈使句）
  ├─ 词表匹配（脏词、情绪动词/副词、语气词）
  ├─ 重复模式检测
  └─ [新增] 引导词提取（紧邻引号的动词短语）
  │
  ▼
classify(text, context_hint, context_confidence)
  ├─ 情绪打分（5种情绪 + neutral）
  │   ├─ ANGER: 脏话、祈使句+感叹号、情绪动词、威胁词、仇恨词...
  │   ├─ FEAR: 颤抖动词、省略号、求饶词、危险词、退缩词...
  │   ├─ SADNESS: 叹词开头、失去/离别词、遗憾/后悔词、哭泣词...
  │   ├─ SURPRISE: 反问句、"居然/竟然"、"太可怕了"类惊叹...
  │   ├─ JOY: 感叹句模式、笑声词、胜利/成就词、庆祝词...
  │   └─ NEUTRAL: 句号结尾+无感叹/问号、无情绪词命中
  ├─ 否定词惩罚（否定词+情绪词 → 分数减半）
  ├─ [新增] 引导词情绪加分（"冷笑道"→anger+0.5, "叹道"→sadness+0.4...）
  ├─ 上下文干预（前句情绪继承）
  ├─ unknown 判定（低分且非 neutral → unknown）
  ├─ L2 → L1 映射
  ├─ L2 + confidence → L3 向量
  └─ 生成情感描述文本
  │
  ▼
EmotionResult(emotion_class, emotion_label, emotion_vector, emotion_text, confidence, intensity)
```

_extractor_lock = threading.Lock()

def get_emotion_extractor() -> EmotionExtractor:
    global _extractor
    if _extractor is None:

# [本次修改]
def map_l2_to_vector(emotion_label, confidence, intensity):
    # [新增] 值域验证
    confidence = max(0.0, min(1.0, confidence))
    intensity = max(0.0, min(1.0, intensity))
    
    vector = [0.0] * 8
    primary_value = min(confidence * intensity, 1.0)
    
    # ... 情绪映射 ...

        vector[7] = 1.0
    
    # [新增] 最终裁剪
    vector = [max(0.0, min(v, 1.0)) for v in vector]
    
    return vector

# 第七部分：错误模式分析

## 7.1 Top 5 错误案例

| ID | 文本 | GT | Pred | 问题类型 |
|----|------|:---:|:---:|----------|
| emo_020 | "我们竟然真的做到了。" | joy | surprise | 竟然/居然误判为惊讶 |
| emo_024 | "这……这是什么？" | surprise | unknown | unknown 阈值敏感 |
| emo_043 | "快跑！它醒了！" | fear | anger | 祈使句+感叹号误判为愤怒 |
| emo_048 | "走吧，我们回去。" | neutral | sadness | 规则误触发 |
| emo_052 | "末将愿往！" | anger | unknown | 单字短句被 unknown 截断 |

## 7.2 四大错误模式

| 模式 | 频次 | 占比 | 典型表现 |
|------|:---:|:---:|----------|
| **① 祈使句误判** | ~6次 | 16% | "快跑！"、"别过来！" 被误判为 anger |
| **② unknown 阈值敏感** | ~5次 | 14% | 低分但有情绪信号的文本被归为 unknown |
| **③ 引导词误触发** | ~4次 | 11% | 无引导词的文本被错误匹配 |
| **④ 混合情绪误判** | ~4次 | 11% | "竟然"+"做到了" 的 joy/surprise 冲突 |

## 7.3 错误模式详细分析

### 7.3.1 祈使句误判为愤怒

**根因**: `IMPERATIVE_PATTERNS` 包含 "快跑"、"别过来" 等词，与祈使句+感叹号的组合被误判为愤怒。

**影响情绪**: fear → anger

**典型样例**:
- "快跑！它醒了！" (GT=fear, Pred=anger)
- "不必管我！你们快走！" (GT=fear, Pred=anger)

### 7.3.2 unknown 阈值过于敏感

**根因**: `UNKNOWN_SCORE_THRESHOLD = 0.25`，当所有情绪得分都 ≤ 0.25 时归为 unknown，但某些有明确情绪信号的文本得分恰好在此阈值以下。

**影响情绪**: 所有 → unknown

**典型样例**:
- "末将愿往！" (GT=anger, Pred=unknown) — 短文本，得分不足
- "这……这是什么？" (GT=surprise, Pred=unknown)

### 7.3.3 悲伤信号误触发

**根因**: 某些中性文本触发了 sadness 规则（如"走吧"匹配了 `(走吧|放手|成全|趁我|别管我)` 模式）。

**影响情绪**: neutral → sadness

**典型样例**:
- "走吧，我们回去。" (GT=neutral, Pred=sadness)

class TestEmotionExtractor:
    def test_anger_dirty_words(self, extractor):
        """愤怒：脏话/粗口"""
        result = extractor.classify("你给我滚出去！混蛋！")
        assert result.emotion_label == 'anger'
        assert result.confidence >= 0.5

    def test_anger_imperative_exclamation(self, extractor):
        """愤怒：祈使句 + 高感叹号密度"""
        result = extractor.classify("全体集合！准备战斗！马上！")
        assert result.emotion_label == 'anger'
        assert result.confidence >= 0.4

    def test_fear_trembling(self, extractor):
        """恐惧：颤抖动词"""
        result = extractor.classify("她颤抖着说：别过来……我害怕……")
        assert result.emotion_label == 'fear'
        assert result.confidence >= 0.4

    def test_sadness_sigh(self, extractor):
        """悲伤：叹词开头"""
        result = extractor.classify("唉，这一切都结束了……")
        assert result.emotion_label == 'sadness'
        assert result.confidence >= 0.4

    def test_surprise_rhetorical(self, extractor):
        """惊讶：反问句"""
        result = extractor.classify("难道这不是你做的吗？怎么可能！")
        assert result.emotion_label == 'surprise'
        assert result.confidence >= 0.4

    def test_joy_laughter(self, extractor):
        """喜悦：笑声"""
        result = extractor.classify("哈哈哈！太好了！太棒了！")
        assert result.emotion_label == 'joy'
        assert result.confidence >= 0.5

    def test_neutral_plain_statement(self, extractor):
        """中性：平淡叙述"""
        result = extractor.classify("他走进了房间，看了看四周。")
        assert result.emotion_label == 'neutral'

    def test_empty_text(self, extractor):
        """空文本"""
        result = extractor.classify("")
        assert result.emotion_label == 'neutral'

    def test_emotion_result_fields(self, extractor):
        """EmotionResult 三层标注字段测试"""
        result = extractor.classify("你给我滚出去！混蛋！")
        # L1 粗分类
        assert result.emotion_class in ('neutral', 'excited', 'subdued')
        # L2 细分类
        assert result.emotion_label in ('joy', 'anger', 'sadness', 'surprise', 'fear', 'neutral', 'unknown')
        # L3 8维向量
        assert len(result.emotion_vector) == 8
        assert all(0.0 <= v <= 1.0 for v in result.emotion_vector)
        # 情感描述
        assert isinstance(result.emotion_text, str)
        assert len(result.emotion_text) > 0
        # 强度
        assert 0.0 <= result.intensity <= 1.0

    def test_emotion_vector_anger(self, extractor):
        """L3 向量：愤怒维度"""
        result = extractor.classify("滚！混蛋！")
        assert result.emotion_label == 'anger'
        assert result.emotion_vector[1] > 0  # anger 维度应该有值

    def test_emotion_vector_neutral(self, extractor):
        """L3 向量：平静维度"""
        result = extractor.classify("他走进了房间。")
        assert result.emotion_label == 'neutral'
        assert result.emotion_vector[7] == 1.0  # neutral 时 calm 应该是 1.0

    def test_batch_classify(self, extractor):
        """批量分类"""
        texts = [
            "你给我滚出去！",
            "哈哈哈！太好了！",
            "唉，一切都结束了……",
            "他走进了房间。",
        ]
        results = extractor.batch_classify(texts)
        assert len(results) == 4
        assert results[0].emotion_label == 'anger'
        assert results[1].emotion_label == 'joy'
        assert results[2].emotion_label == 'sadness'

def run_gate():
    ext = EmotionExtractor()
    
    with open('tests/emotion_gt_100.json', 'r', encoding='utf-8') as f:
        gt_data = json.load(f)
    
    correct = 0
    neutral_count = 0
    errors = []
    
    for item in gt_data:
        r = ext.classify(item['text'])
        if r.emotion_label == item['emotion_label']:
            correct += 1
        if r.emotion_label == 'neutral':
            neutral_count += 1
        if r.emotion_label != item['emotion_label']:
            errors.append({
                'id': item['id'],
                'text': item['text'][:30],
                'gt': item['emotion_label'],
                'pred': r.emotion_label
            })
    
    # 准出判断
    passed = True
    checks = [
        (correct/100 >= 0.29, f"L2 准确率 {correct/100:.3f} >= 0.290"),
        (dirty_fp == 0, f"脏词误报 {dirty_fp} == 0"),
    ]
    
    for ok, desc in checks:
        status = "PASS" if ok else "FAIL"
        if not ok:
            passed = False
        print(f"  [{status}] {desc}")
    
    return passed
