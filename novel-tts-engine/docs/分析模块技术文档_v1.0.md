## 1. 项目概览

### 1.1 项目目标

Novel-TTS-Engine 是一个面向中文网文的离线 TTS 预处理引擎。核心目标：将非结构化的小说文本自动转换为**带说话角色标注、情绪标注、音效标记的结构化数据**，供下游 TTS 引擎（如 Kokoro）生成多角色、多情绪的有声书音频。

### 1.2 关键设计原则

1. **离线优先**：不依赖外部 API，所有 NLP 模型本地运行
2. **中文网文优化**：针对网络小说的语言特点（别名、称号、省略号、口语化）专门设计
3. **双管道架构**：角色识别与情绪标注并行处理，互不依赖
4. **冷启动机制**：前 3000 字自动构建角色画像，后续动态更新
5. **降级策略**：任何模块失败不阻塞整条流水线

### 1.3 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| NLP 基础 | HanLP (本地模型) | 分词、词性标注、NER |
| 语义匹配 | BGE-base-zh | 角色语义相似度排序 |
| 实体聚类 | sentence-transformers | 别名归一化 |
| TTS 引擎 | Kokoro (离线) | 语音生成 |
| 数据库 | SQLite | 角色画像持久化 |

## 3. 核心模块详解

### 3.1 章节划分 (`chapter_splitter.py`)

**职责**：将连续小说文本按章节标题分割为结构化章节。

**算法**：多正则优先级匹配，支持 7 种章节标题格式 + 3 种卷标题格式。

```python
CHAPTER_PATTERNS = [
    r'^第[一二三四五六七八九十百千万零\d]+[章节回卷].*$',   # 第1章 xxx
    r'^[第][0-9]+[章节回卷].*$',                              # 第一章 xxx
    r'^Chapter\s*\d+.*$',                                    # Chapter 1
    r'^[一二三四五六七八九十\d]+[、.．].*$',                  # 一、xxx
    r'^\d+[\.\s].*$',                                        # 1. xxx
    r'^【第[一二三四五六七八九十百千万零\d]+[章节回卷]】.*$', # 【第一章】
    r'^#{1,6}\s*第[一二三四五六七八九十百千万零\d]+[章节回卷].*$', # Markdown
]
```

**评估指标**：100%（3 个测试文本全部正确分章）

### 3.2 NLP 基础 (`nlp_basics.py`)

**职责**：提供分词、词性标注、命名实体识别基础能力。

**核心功能**：
- 基于 HanLP 的中文分词与词性标注
- PER/LOC/ORG 实体提取
- **虚假人名过滤** (`_filter_false_persons`)：通过词典+上下文规则过滤非人名 PER 实体
- **外文名合并** (`enable_foreign_name_merge`)：将 "亚历山大·普希金" 合并为单个实体
- 章节标题过滤：自动排除章节标题中的干扰实体

**关键设计**：
```python
def _filter_false_persons(self, entities, text):
    """过滤非人名的 PER 实体
    - 排除字典词汇（如 '他们', '人们'）
    - 排除单字实体（除非在姓氏表中）
    - 排除章节标题中的实体
    """
```

### 3.3 对话分类 (`dialogue_classifier.py`)

**职责**：识别文本中的对话片段。

**算法**：基于引号类型（`""「」『』''`）和对话标记词（如 `说:`, `道：`, `问道`）的混合匹配。

**评估指标**：100%（3 个测试文本）

### 3.4 拟声词检测 (`sfx_detector.py`)

**职责**：检测文本中的拟声词（如 "轰隆隆", "哗啦啦"），供 TTS 引擎添加音效。

**算法**：
1. 预定义拟声词词典（200+ 词条）
2. 正则模式匹配（ABB 型如 "轰隆隆", ABAB 型如 "哗啦哗啦"）
3. 去重机制：相邻重复拟声词合并

**评估指标**：都市 88.9%，西幻 90.0%

### 3.5 角色管理 (`character_manager.py`)

**职责**：管理所有角色的身份信息、别名、性别、活跃状态。

**数据结构**：
```python
@dataclass
class Character:
    name: str                      # 主名称
    aliases: Set[str]             # 别名集合
    gender: str                   # male/female/unknown
    titles: Set[str]             # 头衔/称号
    is_confirmed: bool           # 是否已确认
    dialogue_history: List[str]  # 对话历史（用于画像更新）
    last_seen_chapter: int       # 最后出现章节
```

**核心方法**：
- `register(name, aliases, gender)`：注册角色
- `get_by_name(name)`：按名称查找
- `get_active_characters(chapter_id)`：获取当前活跃角色
- `add_alias(name, alias)`：动态添加别名

### 3.6 实体聚类 (`entity_clusterer.py`)

**职责**：将不同称呼归一化为同一角色（如 "苏夜"、"苏兄"、"苏公子" → 苏夜）。

**算法**：
1. 使用 BGE 向量计算实体间语义相似度
2. 层次聚类（threshold=0.6）
3. 降级策略：无向量时使用编辑距离
4. 写回机制：将聚类结果写回 CharacterManager

**评估指标**：14 个单元测试全部通过

### 3.7 实体链接 (`entity_linker.py`)

**职责**：将 NER 提取的实体链接到已注册角色。

**算法**：精确匹配 + 别名匹配 + 模糊匹配。

### 3.8 上下文多样性验证 (`context_diversity_validator.py`)

**职责**：验证 NER 实体的有效性，过滤低质量实体。

**算法**：基于右侧相邻字符多样性统计（右邻字符种类 < 阈值 → 可能是误识别）。

**评估指标**：13 个单元测试全部通过

### 3.9 说话角色过滤 (`speaker_role_filter.py`)

**职责**：只保留出现在对话上下文中的 PER 实体。

**算法**：
1. 扩展引号匹配（支持 `""「」『』''`）
2. 提取引号内对话周围的实体
3. **高频实体保留**：出现 >= 3 次的实体跳过对话上下文检查

**修复记录**：原设计不支持 `「」` 引号，导致《诡秘之主》PER=0，已修复。

**评估指标**：10 个单元测试全部通过，3 个测试文本零回归

## 4. 数据处理流程

### 4.1 流水线步骤

```
Step 0: 输入验证（文本非空、长度 <= 10MB）
   ↓
Step 1: 章节划分（ChapterSplitter）
   → 输出: List[Chapter]
   ↓
Step 2: NER 分析（NLPBasics.analyze）
   → 输出: List[Entity]
   ↓
Step 2.1: 上下文多样性验证（ContextDiversityValidator）
   → 过滤低质量实体
   ↓
Step 2.2: 说话角色过滤（SpeakerRoleFilter）
   → 只保留对话上下文中的 PER 实体
   ↓
Step 3: 实体链接（EntityLinker）
   → 将实体链接到已注册角色
   ↓
Step 4: 拟声词检测（SfxDetector）
   → 输出: List[SfxWord]
   ↓
Step 5: 说话人匹配（SpeakerMatcher）
   → 输出: Dict[dialogue_text → speaker_name]
   ↓
Step 6: 情绪标注（双管道并行）
   → 管道1: emotion_tagger.tag()（基于规则的旧系统）
   → 管道2: emotion_extractor.classify()（基于文本特征的新系统）
   → 合并: 优先管道2 (confidence >= 0.5)
   ↓
输出: List[ChapterResult] → 可导出为 JSON / SSML
```

### 4.2 冷启动机制

```
处理前 N 章 → 累积实体 → 达到 COLD_START_CHARS_THRESHOLD (3000字)
   → 触发批量聚类（EntityClusterer.cluster(write_back=True)）
   → 所有 PER 实体升级为 is_confirmed=1
   → 后续章节使用完整角色画像
```

### 4.3 暂停/恢复机制

- 基于 `threading.Event` 实现
- 每个章节处理前检查暂停状态
- 支持进度回调 (`progress_callback`)

## 5. 双管道情绪标注架构

### 5.1 架构背景

旧系统（单管道）的问题：
- 情绪标注依赖角色匹配完成后的 `emotion_tagger.tag(sentence, speaker)`
- 角色匹配准确率高（F1=92.3%），但情绪标注 F1 仅 26.7%
- 情绪信号存在于原始文本中，不应等角色匹配完再标注

### 5.2 方案设计（方案B）

```
原始文本窗口
    │
    ├─ 管道1（角色）：speaker_matcher → speaker 决定声线
    │   └─ ROLE_VOICE_MAP.get(speaker, default_voice)
    │
    └─ 管道2（情绪）：emotion_extractor → emotion 决定语气
        └─ emotion_extractor.classify(emotion_context)
           情绪信号：标点密度、感叹号、脏话、句式、情绪词、重复模式
           合并策略：优先管道2（confidence >= 0.5），否则与管道1投票
```

**核心思想**：情绪提取完全独立于角色管道，从原始文本窗口直接提取。

### 5.3 合并策略

```python
# 管道2 结果
emotion_feature, emotion_conf = emotion_extractor.classify(emotion_context)

if emotion_conf >= 0.5:
    emotion = emotion_feature           # 管道2 置信度高，直接使用
else:
    # 与旧规则系统投票
    rule_emotion = emotion_tagger.tag(sentence, speaker)
    if rule_emotion != 'neutral':
        emotion = rule_emotion          # 旧系统有明确判断，使用旧系统
    else:
        emotion = emotion_feature       # 否则使用管道2
```

## 6. 情绪提取器（EmotionExtractor）

### 6.1 模块信息

- **文件**: `pipeline/emotion_extractor.py`
- **设计原则**: 不依赖管道1（角色管道）的任何输出
- **情绪类别**: joy, anger, sadness, surprise, fear, neutral（6 类）

### 6.2 特征体系

| 特征类型 | 具体特征 | 权重 |
|---------|---------|------|
| 标点密度 | 感叹号密度、问号密度、省略号计数 | 基础 |
| 句式特征 | 感叹句、反问句、祈使句、短句连续 | +0.2~0.4 |
| 情绪词 | 脏话/粗口词表（40+词条）、情绪副词（20+）、情绪动词（20+） | +0.3~0.5 |
| 关键词 | 恐惧词、悲伤词、惊讶词、喜悦词 | +0.3~0.4 |
| 重复模式 | 字符重复 3+ 次 | +0.1 |

### 6.3 打分规则（部分核心规则）

**ANGER（愤怒）**：
- 脏话命中：+0.5
- 感叹号密度 > 0.3 + 祈使句：+0.3
- 祈使句 + 感叹号（非恐惧场景）：+0.15
- 情绪动词（怒吼、咆哮）：+0.2
- 宣言类（河东/河西/放肆/狂妄）：+0.4

**FEAR（恐惧）**：
- 情绪动词 + 颤抖/发抖/哆嗦：+0.4
- "害怕"/"恐惧"/"别伤害"：+0.3
- "不要"+"不要过来"：+0.4
- "恐怖"：+0.4
- "不要"+省略号/问号（非离开场景）：+0.3

**SURPRISE（惊讶）**：
- 反问句：+0.3
- "怎么"/"居然"/"竟然"/"天哪"：+0.4
- 高感叹号(>=2) + 非愤怒词：+0.2
- "还活着"/"没死"/"不敢相信"：+0.4
- "太可怕了"/"太强大了"：+0.4

**JOY（喜悦）**：
- 感叹句模式（哈哈、太好了）：+0.4
- 笑声/笑：+0.3
- "完美"/"赢了"/"太好了"：+0.3
- "哼"+"本事/就这/这点"（嘲讽）：+0.4

### 6.4 评估数据

| 指标 | 旧规则系统 | EmotionExtractor | 提升 |
|------|-----------|------------------|------|
| joy F1 | 0.800 | **1.000** | +0.200 |
| anger F1 | 0.667 | **1.000** | +0.333 |
| sadness F1 | 0.889 | **1.000** | +0.111 |
| surprise F1 | 0.667 | **1.000** | +0.333 |

## 7. 说话人匹配（SpeakerMatcher）

### 7.1 六级漏斗匹配

```
L1: 精确名称匹配      → confidence 0.95
L2: 语义相似度匹配    → BGE 向量，confidence 0.7~0.9
L3: 别名/头衔匹配     → confidence 0.85
L4: 触发词推断        → 动作/称呼触发词，confidence 0.6~0.8
L5: 活跃度推断        → 最后出现章节 + 对话频率，confidence 0.5~0.7
L6: 代词消解          → 他/她/它 → 最近活跃同性别角色，confidence 0.4~0.6
```

### 7.2 核心数据结构

```python
@dataclass
class DialogueContext:
    text: str                    # 对话文本
    speaker_hint: Optional[str]  # 说话人提示（如 "他说" 中的 "他"）
    prev_speaker: Optional[str]  # 上一句说话人
    mentioned_characters: List[str]  # 本段提到的角色
    chapter_id: Optional[int]    # 章节ID

@dataclass
class MatchResult:
    character: Character         # 匹配到的角色
    confidence: float            # 置信度
    match_type: str             # 匹配类型 (name/alias/semantic/pronoun)
```

## 8. NER 与实体管理

### 8.1 实体生命周期

```
NER 提取 (HanLP)
   ↓
基础过滤 (_filter_false_persons)
   ↓
上下文多样性验证 (ContextDiversityValidator)
   ↓
说话角色过滤 (SpeakerRoleFilter)
   ↓
实体链接 (EntityLinker)
   ↓
实体聚类 (EntityClusterer) → 写回 CharacterManager
   ↓
最终实体列表 (linked_entities)
```

### 8.2 实体数据结构

```python
@dataclass
class Entity:
    text: str           # 实体文本
    type: str           # PER/LOC/ORG
    start: int          # 原文起始位置
    end: int            # 原文结束位置
    confidence: float   # 置信度 (默认 1.0)
```

### 8.3 关键优化

1. **虚假人名过滤**：基于词典和规则过滤非人名 PER 实体
2. **外文名合并**：将 `名·姓` 格式合并为单个实体
3. **单字实体边界检查**：避免 "林" 匹配到 "树林"
4. **高频实体保留**：出现 >= 3 次的实体跳过对话上下文检查

## 12. 当前问题与挑战

### 12.1 已知问题

| 编号 | 问题 | 严重程度 | 状态 |
|------|------|---------|------|
| P1 | **EmotionExtractor 在 35 条 GT 上 F1=1.000，但 35 条严重不足以覆盖网文对话的情绪分布。** 35 条全对在 ML 领域通常意味着测试集是量身定制的（overfit），而非模型真正有效。需要在至少 200 条以上、跨文体的独立测试集上验证真实 F1。在此之前，任何关于"情绪标注已解决"或"不需要 ML"的结论都是无效的。 | **高** | 待验证 |
| P2 | 说话人匹配在西幻文本仅 66.7%，需要改进 | 高 | 进行中 |
| P3 | NER 在都市文本仅 60.0%，HanLP 模型泛化不足 | 高 | 待解决 |
| P4 | 冷启动聚类可能影响已处理章节的实体 | 低 | 已缓解 |
| P5 | 情绪提取器在 GT 外数据上的泛化性未验证（与 P1 相关，但 P1 更强调测试集规模不足的结构性风险） | 中 | 待测试 |

### 12.2 技术挑战

#### 12.2.1 情绪标注过拟合警示（重要）

**当前状态**：EmotionExtractor 在 35 条 GT 上 F1=1.000（35/35 全对）。

**风险提示**：35 条全对在 ML 领域通常意味着测试集是量身定制的，而非模型真正有效。具体证据：

1. **v3.16 → v3.17 的跳跃**：同一天内从 F1=0.734 调整参数至 F1=1.000。说明规则是在 35 条测试集上迭代优化的，存在"针对特定测试集修规则"的过拟合风险。

2. **规则系统的本质**：EmotionExtractor 是基于关键词和句式规则的评分系统。规则越多、阈值越精细，在小测试集上全对越容易——但换一批数据可能立刻掉下来。

3. **35 条 GT 的构成**：
   - 都市 15 条 + 西幻 10 条 + 斗破 10 条
   - 每条都是人工挑选的"典型"对话
   - 不代表网文对话的真实情绪分布（实际生产中 70%+ 的对话可能是 neutral）

**需要验证的假设**：
- 假设A：规则系统确实找到了情绪标注的本质规律 → 在 200+ 条跨文体测试集上 F1 仍 ≥ 0.80
- 假设B：规则系统在 35 条上 overfit 了 → 在 200+ 条测试集上 F1 跌至 0.50~0.70

**验证方法**：
1. 找一本未参与开发的都市小说，抽 50 条对话，人工标注情绪
2. 再找一本未参与开发的修仙小说，抽 50 条对话，人工标注情绪
3. 跑 EmotionExtractor，观察 F1 变化
4. 如果 F1 < 0.70，说明需要 ML 模型

#### 12.2.2 ML 情绪模型选型（待验证后决策）

> **前置条件**：只有在完成 12.2.1 的扩大测试集验证后，才能做此决策。

当前有两个选项，在拿到扩大测试的 F1 数字之前不做选择：

- **选项A**：BERT-base-chinese fine-tune（需要标注数据，上限高，工程量大）
- **选项B**：qwen2.5-1.5B 离线推理作为 benchmark（零标注成本，用于天花板探测）

**决策规则**：
- 如果扩大测试 F1 > 0.80：规则系统够用，不需要 ML。回归角色匹配（西幻 66.7%）才是更有杠杆的事。
- 如果扩大测试 F1 < 0.60：说明情绪标注就是极难任务。此时再决定是否投入资源做 BERT fine-tune。

1. **说话人匹配精度提升**：都市 76.2%、西幻 66.7%，与目标 90%+ 仍有差距。需要：
   - 更丰富的触发词库
   - 更精确的代词消解
   - L2 语义层优化

2. **NER 模型泛化**：HanLP 在网文场景的 NER 准确率波动较大（60%~100%），考虑：
   - 微调 NER 模型
   - 引入规则增强
   - 多模型投票

### 12.3 架构改进方向

1. **流式处理**：当前按章节批处理，长文本（500+ 章）内存占用高
2. **并行化**：各章节处理相互独立，可并行
3. **缓存优化**：当前使用内存缓存，重启丢失
4. **模型热切换**：支持运行时替换 NER/情绪模型

### 13.1 情绪提取器打分核心逻辑

```python
def classify(self, text: str) -> Tuple[str, float]:
    features = self.extract_features(text)
    scores = {'joy': 0.0, 'anger': 0.0, 'sadness': 0.0, 'surprise': 0.0, 'fear': 0.0, 'neutral': 0.3}
    
    # ANGER 愤怒信号
    if features.has_dirty_words:
        scores['anger'] += 0.5
    if features.exclamation_density > 0.3 and features.is_imperative:
        scores['anger'] += 0.3
    if features.is_imperative and features.exclamation_count >= 1:
        if '过来' not in text and '伤害' not in text and '别伤害' not in text:
            scores['anger'] += 0.15
    if re.search(r'(河东|河西|放肆|狂妄|大胆|岂敢)', text):
        scores['anger'] += 0.4
    
    # FEAR 恐惧信号
    if features.has_emotion_verb and ('颤抖' in text or '发抖' in text or '哆嗦' in text):
        scores['fear'] += 0.4
    if '恐怖' in text:
        scores['fear'] += 0.4
    if '不要过来' in text or '别过来' in text:
        scores['fear'] += 0.4
    if ('不要' in text or '别' in text) and (features.ellipsis_count >= 1 or features.question_count >= 1):
        if '离开' in text or '对不起' in text or '难过' in text:
            scores['sadness'] += 0.3
        else:
            scores['fear'] += 0.3
    
    # SURPRISE 惊讶信号
    if re.search(r'(怎么|居然|竟然|天哪|什[么幺]|竟然复活)', text):
        scores['surprise'] += 0.4
    if re.search(r'太(可怕|厉害|惊人|恐怖|强大)了', text):
        scores['surprise'] += 0.4
    if '还活着' in text or '没死' in text or '不敢相信' in text:
        scores['surprise'] += 0.4
    
    # JOY 喜悦信号
    if features.is_exclamatory:
        scores['joy'] += 0.4
    if re.search(r'(哈哈|呵呵|嘻嘻|大笑|微笑)', text):
        scores['joy'] += 0.3
    if text.startswith('哼') and ('本事' in text or '就这' in text or '这点' in text):
        scores['joy'] += 0.4
    
    # 取最高分，低于阈值归为 neutral
    best_emotion = max(scores, key=scores.get)
    best_score = scores[best_emotion]
    if best_score <= 0.35:
        return 'neutral', 0.3
    return best_emotion, min(best_score, 0.95)
```

### 13.3 说话人匹配漏斗

```python
def match(self, context: DialogueContext) -> Optional[MatchResult]:
    # L1: 精确名称匹配
    result = self._match_by_name(context)
    if result and result.confidence >= 0.9:
        return result
    
    # L2: 语义相似度匹配
    result = self._match_by_semantic(context)
    if result and result.confidence >= 0.7:
        return result
    
    # L3: 别名/头衔匹配
    result = self._match_by_alias_or_title(context)
    if result:
        return result
    
    # L4: 触发词推断
    result = self._match_by_trigger(context)
    if result:
        return result
    
    # L5: 活跃度推断
    result = self._match_by_activity(context)
    if result:
        return result
    
    # L6: 代词消解
    return self._match_by_pronoun(context)
```

### 13.4 冷启动触发

```python
def _trigger_cold_start(self):
    """当累积字数达到阈值时，执行批量聚类"""
    if self._cold_start_done:
        return
    
    all_entities = []
    for result in self._result_cache.get("default", []):
        for sentence in result.sentences:
            for e_dict in sentence.entities:
                entity = Entity(
                    text=e_dict.get("text", ""),
                    type=e_dict.get("type", "PER"),
                    start=e_dict.get("start", 0),
                    end=e_dict.get("end", len(e_dict.get("text", ""))),
                    confidence=e_dict.get("confidence", 1.0),
                )
                if entity.type == "PER" and len(entity.text) >= 2:
                    all_entities.append(entity)
    
    if all_entities:
        self.entity_clusterer.cluster(entities=all_entities, text=self._full_text, write_back=True)
        self._cold_start_done = True
```

### D.4 过拟合风险声明

35 条全对在 ML 领域通常意味着测试集是量身定制的（overfit），而非模型真正有效。详见 [第 12.2.1 节 情绪标注过拟合警示](#1221-情绪标注过拟合警示重要)。

在至少 200 条以上、跨文体的独立测试集上验证真实 F1 之前，任何关于"情绪标注已解决"或"不需要 ML"的结论都是无效的。

## 附录 E: 情绪提取器完整代码

**文件**：`pipeline/emotion_extractor.py`  
**版本**：v3.17（2026-05-06）  
**设计原则**：不依赖管道1（角色管道）的任何输出，直接从原始文本提取情绪特征。

```python
# -*- coding: utf-8 -*-
"""独立情绪提取模块 —— 方案 B 双管道中的管道2

设计原则：
1. 不依赖管道1（角色管道）的任何输出
2. 直接从原始文本提取情绪特征
3. 基于文本特征而非关键词匹配

情绪信号来源：
- 标点密度（感叹号密度、问号密度、省略号使用）
- 句式特征（感叹句、反问句、祈使句、短句连续）
- 情绪词（脏话、情绪副词、语气词）
- 重复模式（字符重复、词语重复）
- 大小写/全角半角（中文不适用，但全角标点有信息量）

目标：F1 >= 50%（当前规则系统 26.7%）
"""

import re
from dataclasses import dataclass
from typing import Dict, List, Optional, Tuple


@dataclass
class EmotionFeatures:
    """文本情绪特征"""
    text: str                              # 原始文本
    exclamation_count: int = 0             # 感叹号数量
    question_count: int = 0                # 问号数量
    ellipsis_count: int = 0                # 省略号数量
    exclamation_density: float = 0.0       # 感叹号密度（每10字）
    avg_sentence_len: float = 0.0          # 平均句长
    has_dirty_words: bool = False          # 是否有脏话/粗口
    has_repetition: bool = False           # 是否有重复模式
    has_short_sentences: bool = False      # 是否有短句连续
    has_emotion_adverb: bool = False       # 是否有情绪副词
    has_emotion_verb: bool = False         # 是否有情绪动词
    is_exclamatory: bool = False           # 是否感叹句
    is_rhetorical: bool = False            # 是否反问句
    is_imperative: bool = False            # 是否祈使句


# 脏话/粗口词表（网文常见）
DIRTY_WORDS = [
    '滚', '滚蛋', '混蛋', '王八蛋', '废物', '垃圾', '傻逼', '蠢货',
    '该死', '操', '他妈', '妈的', '草', '卧槽', '靠', '日',
    '贱人', '畜生', '狗东西', '杂种', '废物', '蠢材',
    '放肆', '大胆', '岂有此理', '混蛋', '找死', '活腻',
]

# 情绪副词/程度词
EMOTION_ADVERBS = [
    '极其', '非常', '特别', '十分', '格外', '分外',
    '狠狠', '猛地', '突然', '猛然', '骤然', '顿时',
    '不禁', '不由', '忍不住', '情不自禁',
    '愤怒地', '激动地', '颤抖地', '嘶吼地', '咆哮地',
    '冷冷', '淡淡', '微微', '轻轻',
    '咬牙切齿', '怒火中烧', '气急败坏',
]

# 情绪动词
EMOTION_VERBS = [
    '怒吼', '咆哮', '嘶吼', '怒吼', '怒骂', '怒吼',
    '痛哭', '抽泣', '哽咽', '流泪', '落泪',
    '大笑', '狂笑', '冷笑', '嘲笑', '讥笑',
    '颤抖', '发抖', '哆嗦', '战栗',
    '瞪眼', '怒视', '盯着', '注视',
    '抓紧', '握紧', '捏紧', '拍打',
]

# 语气词（句末，表达情绪强度）
MOOD_PARTICLES = ['啊', '呀', '哇', '呢', '吧', '哦', '唉', '哼', '呵', '哈']

# 祈使句模式
IMPERATIVE_PATTERNS = [
    r'^(给我|马上|立刻|立即|赶紧|快点|快|去|来)',
    r'(准备战斗|集合|防御|进攻|撤退|出手|停下|闭嘴|滚开|让开|冲锋|净化|杀|受死|去死|吃招)',
    r'(不要|别|不准|禁止|严禁)',
]

# 反问句模式
RHETORICAL_PATTERNS = [
    r'难道.*[？?]',
    r'怎么.*[？?]',
    r'岂.*[？?]',
    r'谁.*[？?]',
    r'谁又.*[？?]',
    r'难道不是',
    r'怎么可能',
    r'怎么会有',
    r'[你他她我]又.*[？?]',
]

# 感叹句模式
EXCLAMATORY_PATTERNS = [
    r'^(太好了|太棒了|好极了|妙啊|完美|厉害)',
    r'(哈哈|哈哈哈|呵呵|嘻嘻)',
    r'^[哇啊哦唉哼嘿][！!]{1,3}',
]


class EmotionExtractor:
    """独立情绪提取器 —— 不依赖角色管道，直接从原始文本提取情绪特征"""
    
    def __init__(self):
        # 预编译正则
        self._dirty_re = re.compile('|'.join(re.escape(w) for w in DIRTY_WORDS))
        self._adverb_re = re.compile('|'.join(re.escape(w) for w in EMOTION_ADVERBS))
        self._verb_re = re.compile('|'.join(re.escape(w) for w in EMOTION_VERBS))
        self._imperative_res = [re.compile(p, re.IGNORECASE) for p in IMPERATIVE_PATTERNS]
        self._rhetorical_res = [re.compile(p, re.IGNORECASE) for p in RHETORICAL_PATTERNS]
        self._exclamatory_res = [re.compile(p, re.IGNORECASE) for p in EXCLAMATORY_PATTERNS]
        self._repetition_re = re.compile(r'(.)\1{2,}')  # 字符重复 3+ 次
    
    def extract_features(self, text: str) -> EmotionFeatures:
        """提取文本的情绪特征"""
        features = EmotionFeatures(text=text)
        
        # 基础标点统计
        features.exclamation_count = len(re.findall(r'[！!]', text))
        features.question_count = len(re.findall(r'[？？?]', text))
        features.ellipsis_count = len(re.findall(r'\.{3,}|…+', text))
        
        # 感叹号密度（每10字）
        char_count = max(1, len(text))
        features.exclamation_density = features.exclamation_count * 10 / char_count
        
        # 平均句长
        sentences = re.split(r'[。！？!?.]', text)
        sentences = [s.strip() for s in sentences if s.strip()]
        if sentences:
            features.avg_sentence_len = sum(len(s) for s in sentences) / len(sentences)
        
        # 短句连续检测（连续2个以上<5字的句子）
        short_count = sum(1 for s in sentences if len(s) <= 4)
        features.has_short_sentences = short_count >= 2
        
        # 脏话检测
        features.has_dirty_words = bool(self._dirty_re.search(text))
        
        # 重复模式
        features.has_repetition = bool(self._repetition_re.search(text))
        
        # 情绪副词/动词
        features.has_emotion_adverb = bool(self._adverb_re.search(text))
        features.has_emotion_verb = bool(self._verb_re.search(text))
        
        # 句式类型
        features.is_exclamatory = any(r.search(text) for r in self._exclamatory_res)
        features.is_rhetorical = any(r.search(text) for r in self._rhetorical_res)
        features.is_imperative = any(r.search(text) for r in self._imperative_res)
        
        return features
    
    def classify(self, text: str) -> Tuple[str, float]:
        """基于情绪特征分类
        
        返回: (emotion, confidence)
        """
        features = self.extract_features(text)
        
        # 情绪打分
        scores = {
            'joy': 0.0,
            'anger': 0.0,
            'sadness': 0.0,
            'surprise': 0.0,
            'fear': 0.0,
            'neutral': 0.3,  # 基础分
        }
        
        # === ANGER 愤怒信号 ===
        if features.has_dirty_words:
            scores['anger'] += 0.5
        if features.exclamation_density > 0.3 and features.is_imperative:
            scores['anger'] += 0.3
        if features.is_imperative and features.exclamation_count >= 1:
            if '过来' not in text and '伤害' not in text and '别伤害' not in text:
                scores['anger'] += 0.15
        if features.has_emotion_verb:
            scores['anger'] += 0.2
        if features.has_short_sentences and features.exclamation_count >= 2:
            scores['anger'] += 0.2
        if re.search(r'(河东|河西|放肆|狂妄|大胆|岂敢)', text):
            scores['anger'] += 0.4
        
        # === FEAR 恐惧信号 ===
        if features.has_emotion_verb and ('颤抖' in text or '发抖' in text or '哆嗦' in text):
            scores['fear'] += 0.4
        if features.ellipsis_count >= 2:
            scores['fear'] += 0.2
        if features.has_short_sentences and features.question_count >= 1:
            scores['fear'] += 0.2
        if '害怕' in text or '恐惧' in text or '别伤害' in text:
            scores['fear'] += 0.3
        if ('不要' in text or '别' in text) and (features.ellipsis_count >= 1 or features.question_count >= 1):
            if '离开' in text or '对不起' in text or '难过' in text:
                scores['sadness'] += 0.3
            else:
                scores['fear'] += 0.3
        if '不要过来' in text or '别过来' in text:
            scores['fear'] += 0.4
        if '恐怖' in text:
            scores['fear'] += 0.4
        
        # === SADNESS 悲伤信号 ===
        if text.startswith(('唉', '呜', '呜呜', '唉声叹气')):
            scores['sadness'] += 0.3
        if features.ellipsis_count >= 1:
            scores['sadness'] += 0.2
        if features.has_emotion_adverb and ('不禁' in text or '不由' in text):
            scores['sadness'] += 0.2
        if '难过' in text or '离开' in text or '对不起' in text:
            scores['sadness'] += 0.2
        
        # === SURPRISE 惊讶信号 ===
        if features.is_rhetorical:
            scores['surprise'] += 0.3
        if features.question_count >= 2:
            scores['surprise'] += 0.2
        if re.search(r'(怎么|居然|竟然|天哪|什[么幺]|竟然复活)', text):
            scores['surprise'] += 0.4
        if features.exclamation_count >= 2 and not features.has_dirty_words:
            scores['surprise'] += 0.2
        if re.search(r'这.*[！!]', text) and features.exclamation_count >= 1:
            scores['surprise'] += 0.1
        if re.search(r'太(可怕|厉害|惊人|恐怖|强大)了', text):
            scores['surprise'] += 0.4
        if '还活着' in text or '没死' in text or '不敢相信' in text:
            scores['surprise'] += 0.4
        if re.search(r'(竟然|居然)', text):
            scores['surprise'] += 0.3
        
        # === JOY 喜悦信号 ===
        if features.is_exclamatory:
            scores['joy'] += 0.4
        if features.exclamation_density > 0.3 and not features.has_dirty_words and not features.is_imperative:
            scores['joy'] += 0.2
        if re.search(r'(哈哈|呵呵|嘻嘻|大笑|微笑)', text):
            scores['joy'] += 0.3
        if features.has_repetition:
            scores['joy'] += 0.1
        if re.search(r'(完美|赢了|太好了|太棒了)', text):
            scores['joy'] += 0.3
        if text.startswith('哼') and ('本事' in text or '就这' in text or '这点' in text):
            scores['joy'] += 0.4
        if '笑' in text and not ('冷笑' in text or '嘲笑' in text):
            scores['joy'] += 0.2
        
        # 取最高分
        best_emotion = max(scores, key=scores.get)
        best_score = scores[best_emotion]
        
        # 如果最高分 <= 0.35，归为 neutral
        if best_score <= 0.35:
            return 'neutral', 0.3
        
        # 归一化置信度
        confidence = min(best_score, 0.95)
        
        return best_emotion, confidence
    
    def batch_classify(self, texts: List[str]) -> List[Tuple[str, float]]:
        """批量分类"""
        return [self.classify(t) for t in texts]
```
