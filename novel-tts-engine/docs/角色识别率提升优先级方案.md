# 角色识别率提升优先级方案

**文档编号**: PLAN-2026-002

**日期**: 2026-05-09  
**编制人**: AI Assistant  
**关联需求**: BR-001 (角色识别准确率提升)  
**目标**: 将角色识别率从 63% 提升至 78-85%

---

## 核心判断

**当前角色识别率 63% 是系统地基**。不解决此问题,后续所有功能(内心独白音色、引号分类增强、对话轮替识别等)都是空中楼阁。

### 当前痛点诊断

| 痛点 | 影响 | 当前表现 | 根因 |
|------|------|---------|------|
| P1: HanLP 误合并 | 所有题材 | "萧炎冷"被识别为角色名 | 统计式NER缺乏边界感知 |
| P2: 单字称呼不稳定 | 都市/修仙 | "老陈"被识别为"陈" | 过滤规则过严,缺少称呼词典 |
| P3: 西幻译名变体 | 西幻题材 | "哈利"/"波特"/"哈利波特"碎片化 | 无译名知识库,聚类阈值过高 |
| P9: "未知"角色过多 | 无引导词对话 | 连续对话全部标记为"未知" | 漏斗匹配失败后无回退机制 |
| P8: 长距离关联丢失 | 长篇小说 | 跨章角色状态丢失 | 章节级处理隔离,无跨章追踪 |
