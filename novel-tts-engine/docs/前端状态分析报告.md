## 2.1 编辑模式现状：形同虚设

编辑模式是**核心痛点**。完整代码审查后发现，编辑模式只有以下实现：

### 已实现的代码

| 组件 | 实现 | 位置 |
|------|------|------|
| **状态字段** | `editMode: false` | `store.js:L23` |
| **切换方法** | `toggleEditMode()` | `app.js:L410-L412` |
| **Action 处理器** | `'toggle-edit-mode'` | `app.js:L107` |
| **HTML 开关** | `#edit-toggle` | `index.html:L127` |

### 缺失的功能

| 功能 | 是否实现 | 应该做什么 |
|------|:---:|-----------|
| 段落文本编辑 | ❌ 完全没有 | 点击段落后可编辑文本，保存修改 |
| 段落插入 | ❌ 虚假实现 | `insert-segment-after` 只显示 toast "请先进入编辑模式" |
| 段落删除 | ❌ 没有 | 批量模式可以删除，但编辑模式不行 |
| 段落重排序 | ❌ 没有 | 拖拽排序段落 |
| 情绪修改 | ❌ 没有 | 编辑模式下修改段落情绪标签 |
| 说话人修改 | ❌ 没有 | 编辑模式下修改段落说话人 |
| 编辑模式视觉反馈 | ❌ 没有 | CSS 中没有任何 `edit-mode` 相关样式 |
| 编辑模式工具栏 | ❌ 没有 | 工具栏按钮不因编辑模式而改变 |

### 代码证据

```javascript
// app.js:L122 — 插入段落的虚假实现
'insert-segment-after': () => this.showToast('请先进入编辑模式', 'info'),
```

```javascript
// app.js:L410-L412 — toggleEditMode 只切换状态，不改变 UI
toggleEditMode() {
  this.store.dispatch(s => ({ ...s, editMode: !s.editMode }));
}
```

```css
/* style.css — 完全没有 editMode 相关样式 */
/* 搜索 "edit-mode|editMode" 结果: 0 匹配 */
```

### 结论

编辑模式当前只有一层**空壳**：状态字段 + 切换方法 + HTML 开关按钮，但**没有任何实际功能**。

## 2.2 编辑模式应该有的功能

| # | 功能 | 优先级 | 说明 |
|---|------|:---:|------|
| 1 | **段落文本编辑** | P0 | 双击段落进入编辑，textarea 修改文本 |
| 2 | **段落类型修改** | P0 | 下拉选择：旁白/对话/拟声词 |
| 3 | **说话人修改** | P0 | 下拉选择已有角色或新建 |
| 4 | **情绪修改** | P1 | 下拉选择情绪标签 |
| 5 | **段落插入** | P1 | 在选定段落后插入新段落 |
| 6 | **段落删除** | P1 | 右键菜单或编辑模式删除按钮 |
| 7 | **段落拖拽排序** | P2 | HTML5 Drag & Drop |
| 8 | **编辑模式视觉反馈** | P1 | 段落出现编辑图标、边框颜色变化 |
| 9 | **编辑模式工具栏** | P1 | 显示插入、删除、撤销、重做按钮 |
| 10 | **保存修改** | P0 | 同步到后端或本地缓存 |

## 2.3 编辑模式问题根因

```
状态字段 (editMode: boolean)
        │
        ▼
   toggleEditMode()  ← 只切换 boolean
        │
        ▼
   views.js::renderSegments()  ← 不接受 editMode 参数
        │
        ▼
   渲染的段落没有任何可编辑元素
```

**断裂点**：`editMode` 状态从未传递给 `views.js` 的渲染方法，也没有任何组件监听这个状态变化。

### 对比：批量模式有相似问题

```
batchMode 状态
        │
        ├── 有 HTML 按钮（✅）
        ├── 有 JS 逻辑（✅ _toggleBatch, _batchChangeType, _batchDelete）
        │
        └── 但 views.js::renderSegments() 不接受 batchSelected 参数
            └── 无法显示勾选框
            └── 无法高亮选中项
```

**模式问题**：`views.js` 的渲染方法没有接入所有状态字段。

### 修复路径

```
1. 修改 renderSegments() 签名：
   renderSegments(segments, selectedIndex, fragmentMode, ttsCache, chapterIndex,
                  editMode, batchMode, batchSelected)
   
2. 在 app.js 的 _renderContent() 中传递 editMode 和 batchMode 状态

3. 编辑模式下，每个段落显示：
   - 可点击的编辑图标（铅笔）
   - 双击段落进入编辑（contenteditable 或 textarea）
   - 段落操作菜单（类型、说话人、情绪）
   
4. 保存修改：
   - 更新 store 中的 segments
   - 压入 undoStack
   - 可选：同步到后端
```
