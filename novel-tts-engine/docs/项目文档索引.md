### 3.2 核心算法实现

#### 3.2.1 说话人匹配策略链（优先级从高到低）

```
1. 上下文推理（前后文综合分析）→ confidence 0.30~0.95
2. 显式说话提示（"XXX说"）     → confidence 1.00
3. 精确名称匹配                → confidence 1.00
4. 别名匹配                    → confidence 0.90
5. 称呼匹配（"少爷"、"将军"）  → confidence 0.80~0.95
6. 语义相似度（向量排名）       → confidence 0.60~0.80
7. 触发词匹配                  → confidence 0.65~0.70
8. 称呼推断                    → confidence 0.40~0.60
```

核心代码：[speaker_matcher.py](file:///d:/trae/novel-tts-engine/pipeline/speaker_matcher.py#L478-L549) `match_speaker()` 方法

#### 3.2.2 情绪标注三层体系

```
L1 粗分类（3类）: neutral / excited / subdued
L2 细分类（6类）: joy / anger / sadness / surprise / fear / neutral
L3 情感向量（8维）: [happiness, anger, sadness, fear, disgust, melancholy, surprise, calm]
```

信号来源：标点密度、句式特征、情绪词、重复模式、否定词检测

核心代码：[emotion_extractor.py](file:///d:/trae/novel-tts-engine/pipeline/emotion_extractor.py#L342-L643) `classify()` 方法

#### 3.2.3 NER规则增强管线

```
HanLP NER → 西方文体检测 → 西方名字合并 → 前缀称呼检测 → 
职业称呼检测 → 组织后缀检测 → 姓氏组合检测 → 
虚假人名过滤 → 实体黑名单过滤 → 章节标题过滤
```

核心代码：[nlp_basics.py](file:///d:/trae/novel-tts-engine/pipeline/nlp_basics.py#L372-L432) `_enhance_entities()` 方法

#### 3.2.4 流水线调度流程

```
Step 1: 章节划分 (ChapterSplitter)
Step 2: NER分析 (NLPBasics)
  Step 2.1: 上下文多样性验证 (ContextDiversityValidator)
  Step 2.2: 说话角色过滤 (SpeakerRoleFilter)
Step 3: 实体链接 (EntityLinker)
Step 5: 说话人匹配 (SpeakerMatcher)
Step 6: 情绪标注 (EmotionExtractor + EmotionTagger)
```

核心代码：[pipeline_runner.py](file:///d:/trae/novel-tts-engine/pipeline/pipeline_runner.py#L159-L251) `analyze_chapters()` 方法
