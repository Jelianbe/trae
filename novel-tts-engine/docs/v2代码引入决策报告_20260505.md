### 3.3 脏话词边界 Bug 根因

v2 的正则：
```python
_SINGLE_CHAR_DIRTY_RE = re.compile(
    r'(?:^|[^一-龥])(?:滚|草|靠|日)(?:[^一-龥]|$)'
)
```

要求脏字前后必须是非中文字符，导致嵌入中文句子的脏字无法匹配。

| 文本 | v1 | v2 | 正确 |
|------|-----|-----|------|
| "草" | anger | anger | anger ✅ |
| "草木" | neutral | neutral | neutral ✅ |
| "你给我滚出去" | anger | **neutral** | anger ❌ |
| "我，我草" | anger | **neutral** | anger ❌ |

## 六、综合评估

### 6.1 v2 的优势

1. **叙事文本处理更准确**：信号守卫系统减少了叙事文本被误判为 anger 的问题
2. **sadness/fear/surprise 识别提升**：词典扩展和信号扩展在真实小说中有正面效果
3. **设计规范合理**：遵循"通则推理"原则，有明确的"不做"清单

### 6.2 v2 的问题

1. **脏话词边界 bug**：导致明确 anger 场景漏判，在自建测试集和小说中均有体现
2. **否定词处理引入误判**：1 条回归案例表明否定词逻辑可能过于激进
3. **anger 过度下降**：在小说中 anger 占比大幅下降（斗破 -6.0%，闺蜜 -4.5%），可能矫枉过正

### 6.3 关键矛盾

**100 条 GT 测试集 vs 198 条自建测试集的数据差异**：

| 数据源 | v1 L2 | v2 L2 | 变化 |
|--------|-------|-------|------|
| 客观（100条 GT） | 29.0% | 27.0% | **-2.0%** |
| 自建（198条） | 39.9% | 54.0% | +15.2% |

差异巨大。**客观数据显示 v2 没有提升，自建数据显示大幅提升。** 这种差异提示 v2 的开发过程可能对其自建测试集产生了过拟合。

## 七、引入建议

### 7.1 情绪提取器：有条件引入

**当前客观评估结果不满足无条件的引入条件**（L2 从 29.0% 降至 27.0%）。

**建议**：先修复以下 bug，再重新评估。

#### 必须修复

1. **脏话词边界正则 bug**（高优先级）
   ```python
   # 当前（有问题）：
   _SINGLE_CHAR_DIRTY_RE = re.compile(
       r'(?:^|[^一-龥])(?:滚|草|靠|日)(?:[^一-龥]|$)'
   )
   
   # 修复方案：
   _SINGLE_CHAR_DIRTY_RE = re.compile(
       r'(?<![一-龥])(?:滚|草|靠|日)(?![一-龥])|'
       r'(?:滚|草|靠|日)(?![一-龥])'
   )
   ```

2. **否定词处理误杀**（中优先级）
   - 案例："我警告过你不要靠近" → anger 被误判为 neutral
   - 建议：检查否定词处理的触发条件，避免在已有明确 anger 信号时被压制

#### 修复后验证标准

- 100 条 GT 测试集 L2 不低于 29.0%（当前 v1 水平）
- 4 部本地小说中 anger 场景无漏判
- 保持 sadness/fear/surprise 识别提升

- `speaker_matcher_v2.py`：未在客观数据上验证
- `dialogue_classifier_v2.py`：未在客观数据上验证
