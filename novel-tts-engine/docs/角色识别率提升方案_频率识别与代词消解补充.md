#### 方法1: `discover_compound_entities` - 发现复合实体

**文件**: [context_diversity_validator.py#L542-710](file:///d:/trae/novel-tts-engine/pipeline/context_diversity_validator.py#L542-L710)

**功能**: 从全文扫描中发现"字A+字B"组合模式（如"药老"）

**工作原理**:
```
输入: 全文 + 单字PER实体列表（如"药"、"萧"、"云"）

流程:
  1. 收集所有单字PER实体
  2. 统计"单字+后继字"组合出现在说话动词前面的次数
  3. 计算字符紧密度（单字后面紧跟某字的比例）
  4. 如果"药老说道"出现5次，而"药师说道"不出现
     且"药"后面紧跟"老"的比例≥70%
  5. → "药老"是真正的复合实体

输出: 新发现的组合实体列表
```

**关键算法**: 字符紧密度（借鉴WBA思想）
- 对于单字PER"药"，统计其后面紧跟"老"的比例
- 如果紧密度高（如70%），则"药老"很可能是真正的复合实体
- 结合边界词命中率综合判断

**示例**:
```
原文:
  "药老说道" 出现5次
  "药师说道" 出现0次
  "药"后面紧跟"老"的比例: 80%

结果:
  → 发现复合实体"药老"
  → 置信度: 0.85
```

#### 方法4: `_detect_mis_merged_entities` - 检测误合并

**文件**: [context_diversity_validator.py#L166-250](file:///d:/trae/novel-tts-engine/pipeline/context_diversity_validator.py#L166-L250)

**功能**: 基于统计的结构压缩率检测，识别HanLP误合并的实体

**工作原理**:
```
输入: 实体列表 + 全文统计

流程:
  对于每个PER实体A（如"萧炎冷"）:
```

#### 方法5: `_calculate_confidence_from_stats` - 根据统计计算置信度

**文件**: [context_diversity_validator.py#L866-920](file:///d:/trae/novel-tts-engine/pipeline/context_diversity_validator.py#L866-L920)

**功能**: 根据上下文多样性计算实体置信度

**判定规则**:
```
- 总出现次数 < 3           → 0.3（低频噪声）
- 出现次数 ≥ 3，右邻字种类 ≤ 1  → 0.2（固定搭配片段）
- 出现次数 ≥ 3，右邻字种类 ≥ 2  → 维持原置信度
- 出现次数 ≥ 5，右邻字种类 ≥ 3  → max(原置信度, 0.8)（高置信实体）
- 出现次数 ≥ 5，右邻字种类 ≥ 3，章节分布 ≥ 2 → 最低0.8（跨章高频实体）
```

## 二、"他说到"代词消解应对策略

### 2.1 问题定义

**问题**: 当文本中出现"他说到"、"她问道"等代词+说话动词时，系统需要判断"他/她"指代的是哪个具体角色。

**挑战**:
1. 代词本身不包含角色信息
2. 同一上下文中可能有多个同性别角色
3. 代词指代可能跨越多个段落

### 2.2 当前实现概览

**位置**: [pronoun_resolver.py](file:///d:/trae/novel-tts-engine/pipeline/pronoun_resolver.py)

系统已实现基础的代词消解机制，基于**就近原则+性别匹配**。

#### 代词集合（封闭集合）

```python
PRONOUNS = {
    '他': 'male',           # 男性单数

    '他们': 'male_plural',  # 男性复数
    '她们': 'female_plural',# 女性复数

    '其': 'neutral',        # 中性（文言）
```

**符合核心原则**: 中文人称代词是封闭集合，数量有限，硬编码此集合是合理的。

#### 消解策略

**策略1: 局部窗口性别匹配** ([pronoun_resolver.py#L59-80](file:///d:/trae/novel-tts-engine/pipeline/pronoun_resolver.py#L59-L80))

```
流程:
  1. 从最近的说话人中倒序查找
  2. 找第一个性别匹配的角色
  3. 如果找到 → 返回该角色（置信度0.85）
  4. 如果无匹配 → 返回None

示例:
  最近说话人: ["萧炎", "药老", "薰儿"]
  代词: "他" (male)
```

### 2.3 当前策略的局限性

| 场景 | 当前处理 | 问题 |
|------|---------|------|
| 单个同性别角色 | 就近原则匹配 | ✅ 正常 |
| 多个同性别角色 | 返回最近活跃 | ⚠️ 可能错误 |

### 2.4 应对策略方案

#### 策略A: 强化就近原则（短期，P1优先级）

**改动范围**: `pronoun_resolver.py`

**方案**:
1. **扩大上下文窗口**: 从5个说话人到10个说话人
2. **增加角色活跃度权重**: 最近发言的角色优先级更高
3. **增加共现关系权重**: 与对话内容中提及的角色共现频次高的优先

**代码示例**:
```python
def resolve_in_local_window(self, gender: str, recent_speakers: List[str], 
                            dialogue_text: str = None) -> Optional[MatchResult]:
    """在局部窗口内解析代词（强化版）"""
    if not recent_speakers:
        return None
    
    # 扩大窗口到10个说话人
    window = recent_speakers[-10:]
    
    # 计算活跃度权重（最近发言的权重更高）
    speaker_weights = {}
    for i, speaker in enumerate(window):
        weight = (i + 1) / len(window)  # 线性权重
        speaker_weights[speaker] = weight
    
    # 如果有对话内容，增加共现权重
    if dialogue_text:
        for speaker in speaker_weights:
            if speaker in dialogue_text:
                speaker_weights[speaker] += 0.3  # 共现加分
    
    # 找性别匹配且权重最高的
    best_speaker = None
    best_weight = 0
    for speaker in reversed(window):
        char = self.char_manager.get_character_by_name(speaker)
        if char and char.gender == gender:
            w = speaker_weights.get(speaker, 0)
            if w > best_weight:
                best_weight = w
                best_speaker = speaker
    
    if best_speaker:
        return MatchResult(
            character=self.char_manager.get_character_by_name(best_speaker),
            confidence=0.85,
            match_type='pronoun_local_window_enhanced'
        )
    
    return None
```

```python
class DialogueTurnDetector:
    """对话轮替检测器"""
    
    def __init__(self):
        self.recent_speakers = []  # 最近说话人历史
        self.turn_pattern = []     # 轮替模式
    
    def detect_turn(self, current_speaker: str) -> Optional[str]:
        """
        检测当前是否是对话轮替
        
        Returns:
            如果检测到轮替，返回应该说话的角色名
            否则返回None
        """
        self.recent_speakers.append(current_speaker)
        if len(self.recent_speakers) > 10:
            self.recent_speakers.pop(0)
        
        # 检测A-B-A-B模式（至少3轮）
        if len(self.recent_speakers) >= 6:
            last_6 = self.recent_speakers[-6:]
            
            # 检查是否是A-B-A-B-A-B模式
            if (last_6[0] == last_6[2] == last_6[4] and
                last_6[1] == last_6[3] == last_6[5] and
                last_6[0] != last_6[1]):
                
                # 检测到轮替，返回下一个应该说话的角色
                return last_6[0] if last_6[-1] == last_6[1] else last_6[1]
        
        return None
```
