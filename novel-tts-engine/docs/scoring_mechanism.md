# Novel-TTS-Engine 分析功能评分机制 v2.0

## 一、评分维度与权重

### 总分计算公式

```
总分 = Σ(维度得分 × 权重) × 100 - 错误惩罚
```

### 维度权重分配

| 维度 | 权重 | 说明 |
|-----|------|------|
| 召回率 (Recall) | 25% | 正确识别数 / 应识别总数 |
| 精确率 (Precision) | 25% | 正确识别数 / 实际识别总数 |
| F1分数 | 15% | 召回率与精确率的调和平均 |
| 识别速度 | 10% | 每秒处理字符数 |
| 格式准确率 | 15% | 输出格式正确性 |
| 文本覆盖率 | 10% | 已处理文本 / 总文本 |

## 二、错误惩罚机制（新增）

### 错误类型定义

| 错误类型 | 定义 | 示例 |
|---------|------|------|
| **漏识别** | 应识别但未识别 | 期望"赵家"，实际未识别 |
| **误识别** | 不应识别但被识别 | 期望无，实际识别"王" |
| **错识别** | 识别结果类型错误 | 期望"赵家"为ORG，实际识别为PER |
| **位置错误** | 位置信息不正确 | 章节位置重叠 |

### 惩罚规则

| 错误类型 | 惩罚分值 | 说明 |
|---------|---------|------|
| 漏识别 | -3分/个 | 影响召回率 |
| 误识别 | -2分/个 | 影响精确率 |
| 错识别 | -2分/个 | 影响准确性 |
| 位置重叠 | -5分/处 | 严重bug |
| 内容丢失 | -5分/1% | 覆盖率问题 |
| 内容重复 | -10分/处 | 严重bug |

### 惩罚上限

- 单项惩罚上限：-20分
- 总惩罚上限：-30分

## 三、综合评分等级

| 总分 | 等级 | 说明 |
|------|------|------|
| 90-100 | A+ 优秀 | 完全满足生产要求 |
| 80-90 | A 良好 | 满足生产要求，可优化 |
| 70-80 | B 合格 | 基本满足要求，需改进 |
| 60-70 | C 待改进 | 部分功能不达标 |
| < 60 | D 不合格 | 需要重大改进 |

## 五、各模块最低通过标准

### 章节划分模块

| 维度 | 目标值 | 最低值 |
|-----|--------|--------|
| 召回率 | ≥ 95% | ≥ 90% |
| 精确率 | ≥ 95% | ≥ 90% |
| 覆盖率 | 100% | ≥ 95% |
| 位置重叠 | 0处 | 0处 |

| 维度 | 目标值 | 最低值 |

| 精确率 | ≥ 85% | ≥ 70% |
| 漏识别数 | 0 | ≤ 3 |
| 误识别数 | 0 | ≤ 5 |

|-----|--------|--------|
