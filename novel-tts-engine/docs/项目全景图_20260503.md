## 一、项目目标

将小说文本自动处理为 **TTS 引擎可用的结构化数据**，为有声书制作提供一键式预处理。

### 最终交付物

```
原始小说文本 → Novel-TTS-Engine → JSON/SSML/音频 → TTS 播放
```

## 八、快速开始

### 安装

```bash
uv venv .venv --python 3.11
.venv\Scripts\activate
uv pip install -r requirements.txt
```

### 运行

```bash
streamlit run frontend/app.py
```

### 测试

```bash
pytest tests/ -v
```
