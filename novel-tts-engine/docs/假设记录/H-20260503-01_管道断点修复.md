## 改动内容

修复 SpeakerRoleFilter 的 L2 补偿过度提升问题，限制 L2 补偿不能超过原始置信度的 1.5 倍。

## 影响机制

**因果推理**：
1. `ContextDiversityValidator` 将统计验证不可靠的实体降级为低置信度（如 0.3）
2. `SpeakerRoleFilter` 的 L2 补偿机制根据对话场景次数提升置信度
3. 旧代码中 L2 补偿可以直接将 0.3 提升到 0.65 或 0.8，覆盖了统计验证的降级结果
4. 限制 L2 补偿不超过原始值的 1.5 倍后，统计验证的降级结果能够正确传递到最终过滤环节

## 预期效果

- **指标**: 斗破苍穹 NER F1
- **当前基线**: 85.7
- **目标值**: ≥92.3
- **其他约束**: 三份基线文本（都市、西幻、修仙）NER 不降

## 验证方式

运行斗破苍穹 NER 评估脚本，对比改动前后的 F1 和 False Positives。

## 回退条件

如果斗破 NER 下降≥2分，或任一基线文本 NER 下降≥2分，立即回退。

✅ **接受**，合并改动

### 原因

1. 斗破 NER F1 从 85.7 提升到 92.3，超过目标值 6.6 分
2. "萧炎冷"误报被正确过滤
3. 管道一致性得到保障，统计验证降级结果不会被后续组件覆盖
4. 创建 `test_pipeline_consistency.py` 单元测试，防止未来违反此原则
