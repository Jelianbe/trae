### 改动内容

在长文本测试解析层增加两项改进：
1. **`[对话]` 占位符**：将含引号的行保留到 context_before 中，但引号内容替换为 `[对话]`
2. **连续对话逻辑**：检测连续纯对话行，继承上一个有旁白的说话人

### 影响机制

**改动1：[对话] 占位符**
```
原逻辑：
  "赵总监揉了揉太阳穴："客户那边..." " → 跳过
  context_before = 更前面的非引号行

新逻辑：
  "赵总监揉了揉太阳穴：[对话]" → 保留
  context_before = "...赵总监揉了揉太阳穴：[对话]。焦虑的李经理..."
```
这修正了约 7 条错误——当 context_before 保留引号行的旁白前缀时，语境角色优先能正确匹配到角色名。

**改动2：连续对话逻辑（用户提出的三种模式）**
```
模式1（ABAB型）: A有旁白说 → B有旁白回 → A有旁白说 → 正常识别
模式2（AAAA型）: A有旁白说 → 无旁白纯对话 → 无旁白纯对话 → 都继承A
模式3（AAAAB型）: A有旁白说 → 无旁白纯对话 → B有旁白说 → 从B开始继承B
```

当 `context_before` 中没有有效线索时（纯对话行），如果上一行的说话人已确定，当前行默认继承该说话人。

### 预期效果

- 长文本准确率: 81.2% → 目标 ≥ 90%（+8.8%）
- 改动1 修正 ~7 条（context_before 修复）
- 改动2 修正 ~5-6 条（连续对话继承）
- 短文本准确率: 不降（改动1在测试解析层，改动2不影响短文本测试逻辑）

### 可证伪条件

1. 长文本准确率下降超过 2% → 假设不成立，回退
2. 改动1导致短文本准确率下降超过 2% → 假设不成立，回退
3. 改动2引入新的错误模式（误判连续对话）→ 分析原因后调整
4. 长文本准确率提升 < 1% → 假设收益不足，记录教训

1. `python tests/test_urban_long_text.py` → 对比 81.2%
2. `python tests/baseline_rules_speaker.py` → 对比 75.3%
3. 分析每类错误的变化分布

### 回退条件

- 短文本准确率 < 73.3%
