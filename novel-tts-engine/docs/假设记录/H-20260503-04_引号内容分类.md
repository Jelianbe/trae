## 改动内容

实现 `QuotationClassifier` 引号内容分类器，区分对话、书面内容、内心独白等不同类型的引号文本。

## 影响机制

**背景**：
- 当前系统将引号内的文本一律视为对话
- 但石碑刻字、书信内容、内心独白等并非角色声带发出的声音
- TTS 引擎需要用不同的方式处理这些文本类型

**因果推理**：
1. 在 `pipeline/` 目录下新建 `quotation_classifier.py`
2. 提取所有引号内文本，通过多维度特征判断类型
3. 分类为 `WRITTEN` 和 `THOUGHT` 的文本打上特殊标签
4. TTS 引擎根据标签使用不同的声音模型或处理方式

## 预期效果

- **指标**: 引号内容分类准确率
- **当前基线**: 0%（未实现分类，全部视为对话）
- **目标值**: ≥90% 分类准确率
- **其他约束**: 不影响现有说话人识别模块的稳定性

## 四类引号场景

| 类别 | 典型例子 | TTS处理方式 |
|------|----------|-------------|
| **对话** | 萧炎道："我会回来的。" | 角色配音 |
| **书面内容** | 石碑上刻着"斗之力，三段" | 旁白/念读音效 |
| **内心独白** | 他心想："我肯定完蛋了。" | 混响/小声模型 |
| **回忆/转述** | 他说："昨天他说'没问题'" | 整段由A配音或手动干预 |

## 验证方式

运行分类器测试脚本，验证：
1. 石碑内容正确分类为 `WRITTEN` ✅
2. 内心独白正确分类为 `THOUGHT` ✅
3. 真实对话正确分类为 `DIALOGUE` ✅
4. 不影响现有 NER F1 指标 ✅

## 回退条件

如果分类器导致 NER F1 下降≥2分，或引入新的误分类，回退到当前行为（全部视为对话）。

## 实施计划

### 第一步：实现 `QuotationClassifier` 类 ✅
- 在 `pipeline/` 目录下新建 `quotation_classifier.py`
- 实现 `classify` 方法，返回 `DIALOGUE`, `WRITTEN`, `THOUGHT`, `UNKNOWN`
- 采用综合评分公式：score = keyword_length * 10 - distance

### 第二步：在 `PipelineRunner` 中集成 ✅
- 在 `_process_chapter` 中调用分类器
- 为 `WRITTEN` 和 `THOUGHT` 打标签
- `SentenceData` 新增 `quotation_type` 字段
- 特殊类型自动设置 `speaker="Narrator"`

### 第三步：对齐 TTS 输出 ✅
- JSON 导出新增 `quotation_type` 字段
- TTS 引擎可根据 `quotation_type` 选择不同声音模型

### 决策

✅ 采纳并保留

### 原因

1. 分类器采用多维度特征分析（关键词、动词、上下文窗口），不依赖硬编码规则
2. 综合评分公式（score = keyword_length * 10 - distance）兼顾特异性和距离
3. 不影响现有NER和说话人识别模块的稳定性
4. 为TTS引擎提供了区分不同引号类型的能力
