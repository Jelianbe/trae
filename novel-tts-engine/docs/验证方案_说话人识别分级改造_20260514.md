## 四、失败处理预案

| 失败场景 | 处理方式 |
|---------|---------|
| pytest 出现新增 FAILED | 标记为"新增回归"，排查 Phase 1-3 代码，修复后重跑 |
| Hybrid 模式管道崩溃 | 检查 `_ensure_llm_loaded()` 是否异常，降级路径是否执行 |
| 章节缓存未清空 | 检查 PipelineRunner._process_chapter() 中 `cache.clear()` 是否执行 |
| build_candidate_list() 返回空 | 检查 project_id 是否正确传递、数据库中有无角色记录 |
| LLM Prompt 格式错误 | 检查 `_build_llm_prompt()` 输出字符串，对比 Few-Shot 示例格式 |
| benchmark 准确率低于预期 | 检查测试数据是否被修改、模型路径是否正确 |
