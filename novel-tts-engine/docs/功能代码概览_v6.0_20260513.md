## 一、系统架构总览

### 1.1 核心数据流

```
输入文本（章节序列）
    │
    ▼
┌─────────────────────────────────────────┐
│  Step 1: 章节划分 (ChapterSplitter)      │
│  输入: 完整小说文本                        │
│  输出: [(title, content), ...]           │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Step 2: NER + 上下文多样性验证           │
│  ├─ HanLP NER (人名/地名/组织)            │
│  ├─ ContextDiversityValidator (过滤)      │
│  └─ SpeakerRoleFilter (仅保留对话实体)     │
│  输出: List[(text, entity_type)]         │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Step 3: 实体链接 (EntityLinker)          │
│  输入: NER 实体列表                       │
│  输出: List[LinkedEntity]                │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Step 4: 说话人匹配 (SpeakerMatcher)      │
│  多策略级联:                              │
│  ├─ 上下文推理 (extract_context_speakers) │
│  ├─ 说话人提示词 (extract_speaker_hint)   │
│  ├─ 代词消解 (match_by_pronoun)          │
│  ├─ 角色库匹配 (match_by_name)            │
│  ├─ 语义排序 (match_by_semantic)          │
│  └─ 触发词匹配 (match_by_trigger_words)   │
│  输出: (speaker, confidence, match_type)  │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Step 5: 情绪标注 (EmotionExtractor)      │
│  ├─ 三层标注: L1(粗) → L2(细) → L3(向量)  │
│  ├─ 上下文情感传递 (prev_emotion)         │
│  └─ 双管道独立（不依赖角色管道）            │
│  输出: EmotionResult                     │
└─────────────────┬───────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────┐
│  Step 6: 结果缓存 (CacheManager)          │
│  输出: List[ChapterResult]               │
└─────────────────────────────────────────┘
```

### 1.2 冷启动回填机制

```
前 3000 字 (COLD_START_CHARS_THRESHOLD)
    │ 累积句子，speaker="未知"
    ▼
冷启动触发
    │
    ├─ 1. 角色画像构建 (build_cold_start_portraits)
    │     └─ 全文扫描: 共现分析/头衔匹配/对话模式
    │
    └─ 2. 批量回填 (backfill_unknown_speakers)
          └─ 逐句: 从对话文本推理说话人
               └─ 成功 → 更新 speaker
               └─ 失败 → 保持"未知"
```

## 二、模块详细结构

### 2.1 pipeline_runner.py — 流水线调度器

**类/数据结构**:
| 名称 | 类型 | 说明 |
|------|------|------|
| `PipelineState` | Enum | IDLE / RUNNING / PAUSED / DONE / ERROR |
| `ProgressInfo` | dataclass | current_step, current_chapter, total_chapters, progress_percent |
| `FragmentData` | dataclass | text, type (dialogue/narration/onomatopoeia), speaker |
| `SentenceData` | dataclass | text, type, speaker, emotion, emotion_class, emotion_vector, entities, fragments |
| `ChapterResult` | dataclass | chapter_id, title, volume, sentences, statistics |
| `PipelineRunner` | class | 核心调度器 |

**关键方法**:

| 方法 | 签名 | 说明 |
|------|------|------|
| `analyze_chapters` | `(text, start, end, force, cache_key, progress_callback) → List[ChapterResult]` | 主入口，6步流水线 |
| `_process_chapter` | `(title, content, chapter_id) → ChapterResult` | 单章处理，含冷启动触发 |
| `_extract_entities` | `(text, entities_with_attrs, linked_entities, sentence_text, sentence_type) → List[dict]` | 构建句子实体属性 |
| `export_json` | `(results, pretty) → str` | JSON 导出 |
| `export_ssml` | `(results) → str` | SSML 导出 |

**错误处理**:
- try/except/finally 包裹整个流水线执行
- 冷启动失败不阻塞主流程
- 输入验证：空文本、超长文本抛 ValueError

### 2.2 speaker_matcher.py — 说话人匹配器

**类/数据结构**:
| 名称 | 类型 | 说明 |
|------|------|------|
| `DialogueContext` | dataclass | text, speaker_hint, prev_speaker, mentioned_characters, chapter_id, context_before, context_after |
| `MatchResult` | dataclass | character, confidence, match_type |
| `SpeakerMatcher` | class | 多策略级联匹配 |

**匹配策略流水线** (match_speaker):
```
1. 上下文推理 (_extract_context_speakers)
   ├─ 代词消解 (PRONOUNS → gender → candidate)
   ├─ NER 提取 (HanLP NR 标签)
   ├─ 角色库直接匹配:
   │   ├─ 声音指示词附近 (walked/sighed 等)
   │   ├─ 说话动词附近 (说/道/问等)
   │   ├─ 复合说话动词 (苦笑道/点点头说)
   │   ├─ 冒号后主语 (XX说："...")
   │   └─ 动作暗示 (walked/sighed 等附近)
   ├─ 描述性角色提取 (将军/丞相/青年等)
   └─ 自称推断 (我/本座/朕 附近)
   
2. 说话人提示词匹配 (extract_speaker_hint)
   └─ XX道/XX说 格式，贪婪匹配1-6字名字

3. 代词消解 (match_by_pronoun)
   └─ 他/她 → 性别 → 候选角色

4. 角色库匹配 (match_by_name/alias/title)
   └─ 精确匹配 → 模糊匹配 → 别名匹配

5. 语义排序 (match_by_semantic) — 已禁用 (L2)
   └─ 余弦相似度排序

6. 触发词匹配 (match_by_trigger_words)
   └─ 头衔/动作/称呼触发词
```

**群体说话人检测**:
| 模式 | 正则 | 输出 |
|------|------|------|
| 数字+人 | `\d+人` | `GROUP:N` |
| 群体指示词 | `众人/大家/群臣` 等 | `GROUP:CROWD` |

**错误处理**:
- NER 分析 try/except 降级
- 临时角色注册失败 → 返回 None + 记录警告
- HanLP 不可用 → 降级到关键词匹配

### 2.3 dialogue_boundary_detector.py — 对话边界检测

**三策略并行评分**:

| 策略 | 逻辑 | 权重 | 一票否决 |
|------|------|------|---------|
| 1. 说话动词锚定 | 引号前后15字内是否有说话动词 | 60% | 强匹配时一票通过 |
| 2. 内容结构分析 | 纯名词短语/单字叹号/无标点字词 | 30% | 否 |
| 3. 引号模式抑制 | 书本/碑文/书信引用模式 | -20% | 抑制信号 → 降低置信度 |

**关键常量** (已外置/有来源注释):
- `_QUOTE_TYPES`: 4种中文引号对 (GB/T 15834-2011)
- `_BOOK_QUOTE_KEYWORDS`: ~25条书本引用关键词
- `_PROPER_NOUN_SUFFIXES`: ~50条专有名词后缀（建筑/地理/组织/武器/修仙）
- `ANCHOR_WINDOW`: 15 (已外置到 config.py)

### 2.4 emotion_extractor.py — 情绪提取器

**三层标注体系**:

| 层级 | 名称 | 取值 | 说明 |
|------|------|------|------|
| L1 | emotion_class | neutral / excited / subdued | 粗分类，映射到 Index-TTS 2 接口 |
| L2 | emotion_label | joy / anger / sadness / surprise / fear / neutral / unknown | 细分类，Ekman 六情绪 |
| L3 | emotion_vector | 8维浮点向量 | happiness/anger/sadness/fear/disgust/melancholy/surprise/calm |

**打分信号**:
| 信号 | 权重 | 示例 |
|------|------|------|
| 脏话检测 | anger +5~10 | 他妈的/混蛋/滚 |
| 标点密度 | fear +3~5 | ！！！/！！！ |
| 情绪副词 | joy/anger ±2~4 | 愤怒地/欣喜地 |
| 特殊笑类 | anger/sadness +5 | 冷笑→anger, 苦笑→sadness |
| 上下文传递 | 继承前句 | 前句置信度≥0.3 且当前最高≤0.25 |

**关键配置**:
- `UNKNOWN_SCORE_THRESHOLD = 0.15`（低于此值判为 unknown）
- `UNKNOWN_MIN_TEXT_LENGTH = 5`（短文本直接 unknown）
- `EMOTION_EXTRACT_WINDOW = 60`（提取窗口大小）

### 2.5 nlp_basics.py — NLP 基础模块

**核心功能**:
| 函数 | 说明 |

### 2.6 character_manager.py — 角色管理器

**数据库模式**:
```sql
CREATE TABLE IF NOT EXISTS characters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_id TEXT NOT NULL DEFAULT '',
    name TEXT NOT NULL,
    aliases TEXT DEFAULT '[]',
    gender TEXT DEFAULT 'unknown',
    first_appearance TEXT DEFAULT NULL,
    vector BLOB,
    is_locked INTEGER DEFAULT 0,
    UNIQUE(name, project_id)
)
```

**关键方法**:
| 方法 | 说明 |
|------|------|
| `find_or_create(name, project_id, context, chapter_id, min_confidence)` | 查找或创建角色（主入口） |
| `infer_gender(name, context)` | 性别推断：头衔后缀匹配 + 上下文暗示词统计 |
| `merge_characters(primary_id, secondary_id)` | 角色合并（别名迁移） |

**线程安全**: `threading.local()` 连接池 + WAL 模式 + 事务管理

## 五、代码逻辑流程图

### 5.1 单句处理流程

```
输入: "他冷冷地说道"
    │
    ▼
┌─ 类型检测 ─────────────┐
│ is_dialogue_quote?     │
│ → "是" (引号内容)       │
│ → "否" (旁白)           │
└───────────┬────────────┘
            │
            ▼
┌─ NER 分析 ─────────────┐
│ HanLP NER              │
│ → PER: 他 (代词)        │
│ 上下文多样性验证         │
│ → 过滤低置信度实体       │
│ 说话角色过滤            │
│ → 仅保留对话附近实体     │
└───────────┬────────────┘
            │
            ▼
┌─ 实体链接 ─────────────┐
│ 精确匹配 → 核心名提取   │
│ → "他" → 代词消解       │
└───────────┬────────────┘
            │
            ▼
┌─ 说话人匹配 ───────────┐
│ 1. 上下文推理            │
│ 2. 说话人提示词          │
│ 3. 代词消解 → "男性"    │
│ 4. 角色库匹配            │
│ → speaker = "艾德温"    │
│   confidence = 0.8      │
└───────────┬────────────┘
            │
            ▼
┌─ 情绪标注 ─────────────┐
│ 多信号打分:             │
│ "冷冷地" → anger +3     │
│ 上下文传递: prev=joy    │
│ → emotion = "anger"     │
│   confidence = 0.65     │
└───────────┬────────────┘
            │
            ▼
输出: SentenceData {
    text: "他冷冷地说道",
    type: "dialogue",
    speaker: "艾德温",
    emotion: "anger",
    confidence: 0.65,
    emotion_vector: [0.1, 0.7, 0.1, 0.05, 0.0, 0.02, 0.03, 0.0]
}
```

```

│ ├─ 头衔匹配:            │
│ │   "将军" → 候选人      │
│ └─ 对话模式:            │
│     XX道/XX说 → 说话人   │
│                         │
│ 输出: {                 │
│   "张三": {aliases: [...]}, │
│   "李将军": {aliases: ["李"]}, │
│ }                       │
└───────────┬────────────┘
            │
            ▼
┌─ 批量回填 ─────────────┐
│ 逐句处理未知说话人:      │
│ ├─ 从对话文本推理        │

│ ├─ 成功 → 更新 speaker   │

│                         │
│ 统计:                   │
│ 回填成功: X/17          │
│ 保持未知: Y/17          │
└────────────────────────┘
```
