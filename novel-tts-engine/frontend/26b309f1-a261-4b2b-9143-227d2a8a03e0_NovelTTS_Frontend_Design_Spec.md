## 一、产品概述

NovelTTS Cloud 是一个**小说转语音（TTS）平台**的前端界面。用户导入小说文本后，系统自动识别对话、旁白、角色，用户可对每个文本片段进行精细化的语音参数调节，最终生成高质量的有声读物。

### 核心用户流程

```
导入小说 → 自动分析（识别角色/对话/旁白） → 逐段调节参数 → 生成音频
```

### 设计原则

1. **分段独立编辑**：每个文本片段（segment）是独立可操作的最小单元
2. **填色而非改结构**：编辑操作只改变类型标记和参数，不修改原文内容
3. **所见即所得**：正文区域直接展示编辑效果，无需切换视图
4. **暗色主题**：专业工具感，减少长时间使用的视觉疲劳

#### 4.3.1 左栏 — 章节树

- **书名标题**
- **章节搜索框**
- **章节树**：按卷分组，可折叠/展开
  - 每章显示状态图标：✓ 已完成 / ⏳ 分析中 / ○ 未分析
  - 点击章节切换正文内容
- **分析控制区**：
  - 「开始分析」按钮（展开分析选项）
  - 分析范围：全部章节 / 指定范围 / 仅未分析
  - 分析进度条
- **折叠按钮** + **拖拽调节宽度**（180px ~ 500px）

#### 4.3.2 中栏 — 正文内容区

**工具栏**：
- 当前章节标题
- 编辑模式开关（胶囊按钮，激活时变色）
- 字号调节（A- / A+，范围 12px ~ 24px）
- 全屏按钮

**正文区域**（核心）：

正文由多个 **Segment** 组成。Segment 是最小的独立编辑单元。

```
数据结构：
Segment {
  id: string,          // 唯一标识
  type: string,        // narration | dialogue | inner | onomatopoeia
  text: string,        // 文本内容
  speaker: string|null, // 说话人（旁白为 null）
  params: {
    speed: number,     // 语速 0.5 ~ 2.0
    volume: number,    // 音量 0 ~ 100
    pitch: number,     // 音调 -12 ~ 12
    emotion: string    // 情绪标签（可选）
  }
}
```

**Segment 视觉样式**：

| 类型 | 样式 | 说明 |
|------|------|------|
| `narration` | 默认文字，无特殊背景 | 旁白 |
| `dialogue` | 浅色角色背景 + 说话人标签 | 对话 |
| `inner` | 浅黄背景 + 斜体 | 内心独白 |
| `onomatopoeia` | 主题色 + 斜体 + 加粗 | 拟声词 |

**Segment 交互**：

1. **非编辑模式**（默认）：
   - 点击任意 segment → 在该 segment 正下方展开 **参数编辑栏**
   - 参数编辑栏包含：语速/音量/音调滑块 + 试听按钮 + 关闭按钮
   - 对话类型额外显示：说话人下拉、情绪按钮
   - 旁白类型额外显示：语调选择（正常/柔和/严肃/轻快）
   - 拟声词类型额外显示：音效选择（回声/混响/升调/降调）

2. **编辑模式**（开启后）：
   - 点击任意 segment → 在该 segment 正下方展开 **类型编辑栏**
   - 类型编辑栏包含：
     - 类型切换按钮组：[对话] [旁白] [内心] [拟声]
     - 说话人选择下拉（旁白类型不显示）
   - 切换类型时**只改变标记，不修改原文内容**（填色逻辑）
   - 同样支持文字编辑（contenteditable）

**关键交互规则**：
- 同一行中，对话和旁白是**独立的 segment**，可以分别点击编辑
- 例如：`「对话1」旁白描写「对话2」` → 3 个独立 segment
- 点击 segment A 的编辑栏不会影响 segment B
- 任何时刻只有一个编辑栏处于展开状态

**底部音频播放器**：
- 播放/暂停按钮
- 进度条（可点击跳转）
- 时间显示
- 语速控制（0.5x ~ 2.0x）

#### 4.3.3 右栏 — 角色与统计

**角色列表**（可折叠）：

## 八、交互细节

### 8.1 面板折叠

- 左栏和右栏可独立折叠
- 折叠后收缩为 ~40px 窄条
- 中间内容区自动扩展

### 8.2 拖拽调节面板宽度

- 左栏：180px ~ 500px
- 右栏：200px ~ 450px
- 拖拽时显示手柄高亮

### 8.3 Segment 编辑

- 点击 segment → 编辑栏紧跟在 segment 下方展开（动画 slideDown）
- 再次点击同一 segment → 关闭编辑栏
- 点击其他 segment → 关闭当前编辑栏，打开新的
- 点击正文空白处 → 关闭编辑栏

### 8.4 编辑模式

- 开启后 segment 可 contenteditable（直接编辑文字）
- 同时显示类型切换按钮
- 关闭编辑模式时自动关闭所有编辑栏

### 8.5 角色高亮

- 点击右栏角色 → 正文中对应该角色的对话高亮显示
- 再次点击取消高亮

### 8.6 章节切换

- 点击左栏章节 → 正文内容切换
- 角色统计和章节统计同步更新
- 当前章节高亮显示

## 九、拟声词设计

拟声词作为特殊的 segment 类型处理：

- **视觉**：主题色 + 斜体 + 加粗
- **参数栏**：显示音效选择（回声/混响/升调/降调）替代情绪按钮
- **音量默认值**：95（比普通对话更高）
- **示例**：「轰隆——」「嗖——」「啪嗒」
