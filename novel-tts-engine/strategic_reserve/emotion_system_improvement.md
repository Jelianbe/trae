# 情绪标注系统改进

> 版本: v1.0  
> 日期: 2026-05-08  
> 入库原因: 规则系统和 LLM 都只能做到 30% 左右准确率，已达瓶颈

## 当前状态
- 规则系统 L2(6 类) 准确率：32%
- 规则系统 L1(3 类) 准确率：33%
- Qwen2.5-1.5B L1 准确率：26%
- 3 类简化未能提升准确率（仅 +1%）
- EmotionExtractor 在 35 条 GT 上 F1=1.000（过拟合风险）

## 根因分析
1. **上下文不足**：单句分类丢失跨句情绪线索
2. **模型太小**：1.5B LLM 无法理解复杂情绪
3. **规则覆盖有限**：情绪信号词表无法穷尽
4. **分类本身困难**：情绪标注是 NLP 领域公认难题

## 潜在改进方向
1. **长上下文**：使用段落级（5-10 句）而非单句分类
2. **更大模型**：7B+ LLM fine-tune 情绪标注任务
3. **多模态**：结合 TTS 音频特征反馈优化标注
4. **用户标注**：允许用户手动修正情绪标签，积累标注数据

## 启动条件
- Index-TTS 集成完成且验证通过
- 用户反馈 TTS 情绪表达单调
- 有足够资源（GPU + 标注数据）支持 fine-tune

## 当前策略
保留现有规则系统作为基础情绪标注，不投入新开发资源。
