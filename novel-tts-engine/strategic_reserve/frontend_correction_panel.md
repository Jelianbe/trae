# 前端半自动修正反馈面板

> 版本: v1.0
> 日期: 2026-05-08
> 来源: 历史评审记录五
> 状态: 纯概念，未进入代码阶段

## 方案描述
在前端提供角色修正功能：
- 用户可手动修改句子的说话人分配
- 修正后的数据可保存到数据库
- 支持批量修正和修正历史查看
- 修正数据可用于训练/优化 NER 模型

## 当前状态
- store.js 中没有 corrections 数组
- views.js 中没有修正按钮
- 后端没有接收修正数据的 API
- 数据库没有存储修正的表结构

## 预期收益
- 用户可修正角色识别错误
- 积累标注数据用于模型优化
- 提升用户对工具的信心

## 启动条件
- 核心角色识别准确率稳定
- MVP 验证通过，用户需要手动微调能力
- 有明确的修正数据使用场景

## 技术要点
- 前端需要修正 UI（下拉选择说话人）
- 后端需要新 API 端点接收修正
- 数据库需要 corrections 表
- 修正数据需要版本管理
