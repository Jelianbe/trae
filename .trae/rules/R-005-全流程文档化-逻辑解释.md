# R-005: 全流程文档化 - 逻辑解释

## 规则内容
为什么选这个算法，数据结构这样设计的理由，用简洁的注释或一个 decisions.md 文件记录。检查关键算法和数据结构是否有注释或决策记录。

## 触发场景
当进行以下操作时自动触发：
- 实现核心算法
- 设计新的数据结构
- 进行架构决策
- 创建新模块
- 进行影响较大的重构

## 决策文档要求
每条决策必须包含：
```
## [决策标题]
- 日期：[YYYY-MM-DD]
- 问题：[要解决的问题]
- 方案：[选择的方案]
- 理由：[为什么选择这个方案]
- 备选方案：[其他考虑的方案及放弃原因]
```

## 需要记录的场景
- 为什么选择这个算法而不是另一个
- 数据结构这样设计的理由
- 为什么采用这个架构
- 技术选型的考量
- 性能优化的决策

## 输出位置
优先使用以下位置之一：
1. 代码内的注释（简洁）
2. `docs/decisions.md`（详细）
3. `docs/adr.md`（架构决策记录）

## 优先级
常规优先级 - 保障质量与协作
