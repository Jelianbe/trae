# R-002: 依赖锁定机制

## 规则内容
开发一个任务时，如果状态检查发现它依赖的"上游任务"不是 [已审核] 状态，AI 必须立刻停止，并报警提示："任务[下游任务]依赖的上游任务[上游任务]状态为[未完成]，无法启动。"自动扫描 `Depends On` 字段中引用的所有任务，若上游任务状态非 [已审核]，立即阻止状态变更并报警。

## 触发场景
当AI或用户进行以下操作时自动触发：
- 输入"开始任务"、"启动任务"
- 尝试将任务状态改为 [进行中]
- 创建或修改任务的 Depends On 字段

## 错误处理流程
```
1. 检测到下游任务 X 依赖上游任务 Y
2. 检查 Y 的状态
3. 如果 Y ≠ [已审核]：
   - 立即停止操作
   - 输出错误："任务 X 依赖的上游任务 Y 状态为 [当前状态]，无法启动"
   - 阻止状态变更
4. 只有当所有上游任务都是 [已审核] 状态时，才允许启动
```

## 优先级
高优先级 - 保障项目稳定性
