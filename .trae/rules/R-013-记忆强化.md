# R-013: "记忆"强化

## 规则内容
在每个阶段结束时，AI需要为用户生成一个简短的阶段小结。小结内容必须包含：阶段目标、完成情况、关键决策、遗留问题、下一阶段计划。

## 触发场景
当进行以下操作时自动触发：
- 阶段里程碑达成
- 开发阶段完成
- 准备进入下一阶段
- 完成阶段内所有任务
- 进行阶段总结

## 阶段小结模板
```markdown
## 阶段小结 - [阶段名称]

### 阶段目标
[阶段开始时设定的目标]

### 完成情况
- ✅ 已完成：[列出已完成的任务]
- ❌ 未完成：[列出未完成的任务及原因]

### 关键决策
1. [决策1] - 理由：[简要理由]
2. [决策2] - 理由：[简要理由]

### 遗留问题
1. [问题1] - 影响：[影响说明]
2. [问题2] - 影响：[影响说明]

### 下一阶段计划
- 目标：[下一阶段目标]
- 准备开始的任务：[任务列表]
- 依赖条件：[进入下一阶段的前提]
```

## 五要素检查
每个阶段小结必须包含：
1. ✅ **阶段目标** - 阶段开始时设定的目标
2. ✅ **完成情况** - 任务完成情况分析
3. ✅ **关键决策** - 阶段内的重要技术决策
4. ✅ **遗留问题** - 未解决的问题及风险
5. ✅ **下一阶段计划** - 进入下一阶段的准备

## 输出位置
- 主文件：`docs/phase-summary.md`
- 或在 `docs/` 目录下创建单独的阶段文件

## 优先级
常规优先级 - 保障质量与协作
