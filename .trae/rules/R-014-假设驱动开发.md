# R-014: 假设驱动开发

## 规则内容
算法改动前填写假设模板，改动后验证并记录结果。

## 触发
**L3** - 算法改动、架构优化时触发。配置修改、简单bug修复跳过。

## 四步循环
```
明确目标 → 提出假设 → 设计实验 → 接受/拒绝
```

## 决策矩阵
| 情况 | 决策 |
|------|------|
| 目标达成，基线不降 | ✅ 接受 |
| 目标未达成，基线也降 | ❌ 回退 |

## 投资类型
- 速赢：短期可验证
- 战略投资：消除技术债务

## 检查
□ 是否填写了假设模板？
□ 是否运行了验证实验？
