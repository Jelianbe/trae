# R-003: 里程碑节点管理

## 规则内容
在每个开发阶段结束，必须设置一个里程碑节点。该节点是阶段内所有核心任务点 [已审核] 的集合。只有达成里程碑，才能开启下一阶段。里程碑未达成时阻止下一阶段任务启动。

## 触发场景
当进行以下操作时自动触发：
- 完成阶段内最后一个任务
- 尝试开始下一阶段任务
- 进行阶段性审核
- 里程碑验证检查

## 里程碑检查清单
```
阶段结束时检查：
□ 所有核心任务状态 = [已审核]
□ 所有依赖关系已解决
□ 里程碑总结已生成
□ 下一阶段准备就绪

未达成时：
- 列出未完成的任务
- 阻止进入下一阶段
- 提示需要完成的任务
```

## 优先级
中优先级 - 保障阶段推进
