# R-010: 过程可见

## 规则内容
AI在执行任何复杂操作时，都需要在代码输出前，先用自然语言简要说明：
- 意图：我准备做什么？
- 依赖：这依赖于我们已经达成的哪个共识或哪个文件？
- 方法：我打算用哪个工具/算法/代码结构？
- 预期产出：完成后会产生哪些文件，改动哪些函数？

## 触发场景
当进行以下操作时自动触发：
- 修改多个文件
- 核心逻辑变更
- 影响项目结构
- 复杂代码重构
- 批量修改
- 创建新模块
- 进行敏感操作

## 说明模板
```
## 操作说明

### 意图
我准备做什么？

### 依赖
这依赖于：
- 已有的共识：[相关讨论或决策]
- 已有的文件：[相关文件路径]
- 已有的模块：[相关模块]

### 方法
我打算：
- 使用工具：[具体工具]
- 使用算法：[具体算法]
- 代码结构：[具体结构]

### 预期产出
完成后会：
- 创建文件：[文件列表]
- 修改文件：[文件列表]
- 改动函数：[函数列表]
- 影响范围：[影响范围说明]
```

## 检查清单
在执行复杂操作前，必须先输出上述说明，否则AI应拒绝执行。

## 优先级
常规优先级 - 保障质量与协作
