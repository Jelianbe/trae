## 任务管理模板

### 任务状态机
```
[待开始] → [进行中] → [已完成] → [已审核]
                ↓
           [阻塞中] → [进行中]
```

```markdown

[阶段名称]

- [ ] T-001: [任务名称] - 状态: [已审核]

1. [标准1]
2. [标准2]

### 里程碑状态
- [ ] 未达成 / 已达成 / 已审核

[YYYY-MM-DD]
```

## 假设驱动开发模板

### 假设记录模板
```markdown
## 假设记录 #YYYYMMDD-序号

**假设编号**: H-YYYYMMDD-XX
**提出日期**: YYYY-MM-DD
**状态**: 进行中 / 已接受 / 已拒绝
**投资类型**: 速赢 / 战略投资

### 改动内容
（一句话说清改了什么）

### 影响机制
（因果推理：为什么这个改动会导致预期效果）

### 预期效果
- 指标：___
- 当前基线：___
- 目标值：___

### 验证方式
（如何验证这个假设）

### 回退条件
（满足什么条件时立即回退）

### 实验结果
- 结果数据：___
- 决策: 接受 / 拒绝
- 原因: ___
```

### 决策矩阵
| 情况 | 决策 |
|------|------|
| 目标达成，基线不降 | ✅ 接受，合并改动 |
| 目标达成，但某基线降了 | ⚠️ 拒绝，分析降分原因 |
| 目标未达成，基线不降 | ⚠️ 拒绝，记录教训 |
| 目标未达成，基线也降了 | ❌ 立即回退 |

## 战略储备库模板

### 储备方案模板
```markdown
## 储备方案 #YYYYMMDD-序号

**方案名称**: ___
**入库日期**: YYYY-MM-DD
**投资类型**: 战略投资
**入库原因**: ___

### 当前障碍
（为什么短期指标不足以支持立即实施）

### 启动条件
（满足什么条件时，应该重新激活这个方案）
- 条件1：___
- 条件2：___

### 预期收益
（实施后预期带来的结构性改善）
```

### 结构性健康指标
| 指标 | 定义 | 目标方向 |
|------|------|---------|
| 硬编码密度 | 代码中硬编码词表的数量 | 趋近于零 |
| 统计覆盖率 | 通过统计验证确认的实体比例 | 趋近于100% |
| 管道纯净度 | 数据在各模块间一致传递的比例 | 趋近于100% |
| 文体泛化方差 | 不同文体得分的标准差 | 趋近于零 |
| 技术债务率 | 代码中TODO/FIXME/HACK标记密度 | 趋近于零 |
