# R-001: 原子化与状态管理

## 规则内容
任务必须是不可再分的原子操作。状态值：[待开始]、[进行中]、[已完成]、[已审核]、[阻塞中]。

## 触发
**L2** - 编辑 TASKS.md 时触发。

## 状态机
```
[待开始] → [进行中] → [已完成] → [已审核]
                ↓
           [阻塞中] → [进行中]
```

## 检查
□ 状态值是否合法？
□ 任务是否足够细化？

## 优先级
中
