## 一、项目概览

### 1.1 项目基本信息

| 项目 | 内容 |
|------|------|
| **项目名称** | Novel-TTS-Engine |
| **项目类型** | 本地小说文本智能解析引擎 |
| **技术栈** | Python 3.10+, FastAPI, Streamlit, SQLite |
| **核心依赖** | HanLP, FastText, BGE-small ONNX |
| **目标用户** | 有声书制作人员、小说创作者、TTS开发者 |

### 1.2 核心目标

1. 对话/旁白/拟声词分类准确率 ≥ 85%
2. 角色识别与说话人匹配准确率 ≥ 95%（明确对话）
3. 情绪标注（六种基础情绪）
4. 输出结构化JSON，可直接对接TTS引擎
5. 纯本地运行，运行时RAM峰值 ≤ 3GB
